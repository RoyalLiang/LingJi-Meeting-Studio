# 使用加密链接分享会议

本页对应 v0.2.22 新增的客户端加密分享。请使用新版客户端及已更新的官网服务；发布状态见版本说明。设计依据见客户端加密分享 ADR。

## 创建与阅读

1. 在客户端打开会议的**分享**窗口。
2. 选择**仅纪要及引用原文**，或明确选择**纪要与全部转录**。原音不上传。
3. 展开并核对完整预览，勾选分享确认，点击**生成加密分享链接**。无需登录官网。预览内容或范围变化后，需要重新确认。
4. 复制完整链接。接收者在浏览器中解密阅读，不需要安装客户端。

链接 24 小时有效，内容为固定快照；后续编辑不自动扩大或更新分享。完整链接的 `#` 片段包含解密密钥，不要拆开或公开到无关位置。缺少密钥时，官网不能恢复内容。

## 撤销与重试

在原会议的分享窗口查看、复制或撤销有效链接。发生超时可重试原请求，不重新加密或创建重复分享；客户端重启后可从本机资料库恢复管理。未完成的上传也可在列表中重试或撤销。内容已经变化时，应重新确认后创建新链接。撤销结果未确认时，本机保留管理凭据供重试。

删除本机会议不会自动撤销公网内容，请在删除前先撤销链接。撤销阻止后续读取，并清空官网当前正文，不能删除他人已保存的副本。阅读页定期核对链接状态，重新进入前台时也会核对；不是远程擦除能力。

## 容量与数据位置

明文限额为 700 KiB，超过时可缩小范围或导出离线 HTML。匿名上传每来源每小时最多创建 20 次，全站每 24 小时最多创建 2,000 次（含撤销占位记录），触发限额时稍后重试。

桌面本机后台加密后只向官网发送密文封包和随机能力凭据，不发送明文、会议标题、记录 ID 或解密密钥。密钥与撤销凭据保存在本机资料库；官网仅保存随机凭据的哈希。自建 Web 由自建 Record API 执行加密，仍需信任部署方。

原始录音、模型密钥和未选中的笔记不在分享结构内。**导出明文备份**得到的 JSON 文件没有加密，按普通敏感文档管理，不要与加密链接混淆。

## 维护者启用

官网 Worker 需要 D1 绑定及 `0002_encrypted_shares.sql`。现有部署脚本使用 Wrangler 按迁移目录增量执行；新链路不依赖 GitHub 登录配置。客户端由本机后台连接固定的官网地址，前端不向任意第三方发送内容。

旧 OAuth 发布接口与旧分享链接兼容保留，没有因此开放旧明文匿名上传。官网 `/manage` 只提供旧链接的查看和撤销，客户端也保留旧链接管理入口。验证应分别记录本地 SQLite/HTTP、真实浏览器、本机客户端和公网 D1/Worker 结果。
