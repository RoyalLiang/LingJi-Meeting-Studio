# 自动识别多语种与词表纠错

新建记录默认“自动识别”。原文保留讲话使用的语言，开启本场“自动翻译”后，确认片段统一翻译为选择的目标语言。同句中英混用也会完整翻译，不因主语种标签与目标相同而跳过。

## 选择识别和翻译服务

- 内置 SenseVoice 自动识别普通话、英语、日语、韩语、粤语。界面只提供实际生效的自动模式；段落显示模型返回的原音批次语种。一个标签不代表词级语言检测，人工修改后的文本也不会重新标注为另一语种。
- 外部 FunASR 自动模式发送 `language=auto`，兼容转录接口省略固定语言；服务端是否支持对应语种，以部署模型为准。
- Deepgram 自动模式使用 `language=multi`。豆包按已有端点能力自动识别，`bigmodel_async` 不发送固定语言，不能据此宣称覆盖任意语种。
- 其他服务的固定识别语言可在新建时选择，也可在暂停且待处理音频已排空后切换。切换不重跑历史录音。

设置中的**翻译模型**默认“自动选择”：有专用翻译配置或使用官方方舟端点时采用豆包 Seed；其余复用当前文字模型和协议。也可明确选择“当前文字模型”或“豆包 Seed 专用翻译”。专用服务地址不同且没有配置对应密钥时，不会把文字模型密钥发送过去。

自动翻译只影响当前记录。失败时保留原文，界面可重试；切换目标或修改原文后，过期请求不能覆盖新结果。开启翻译会把已有及后续确认原文发送到选择的模型，关闭面板不等于关闭翻译。

## 保存常见词语集与名称集

在“设置与诊断 → 转录词表”选择范围：“通用 · 所有会议”保存账户通用词表，工作目录或“未归档会议”保存额外词表。识别与纠错使用通用词表和当前目录词表，不读取其他账户的词表。

每行先写正确词形，可用 `|` 追加已知误识别写法：

```text
Redis Sentinel | Redis 森提诺
聆记 | 灵记
王晓明 | 王小明
```

常见词语集适合业务术语、技术词和缩写；名称集适合人名、组织名、产品名。每次保存两集合计最多 200 条，每项最多 50 个 Unicode 字符、8 个别名，每个文本框最多 12000 字符。

保存不会改写已有转录。豆包从相关正确词形中选择提示，与既有手填热词共用 100 字预算；Deepgram Nova-3 使用 keyterm，兼容转录接口使用 prompt。通用词表较大时，优先选择出现在标题、笔记或最近发言中的词。正在进行的豆包连接使用建立时的提示，新提示在后续连接生效。SenseVoice 和外部 FunASR 不宣称支持该热词输入，仍可使用后续候选纠错。

## 确认候选后修订原文

展开会议内的**逐字记录与纠错**：

1. 点“检查词表纠错”，在本机根据明确别名找候选；英文别名不会匹配到其他单词内部。
2. 若只有正确词形、没有已知误识别写法，可点“使用模型检查（发送原文与词表）”。这会向已配置文字模型发送最近最多 20 段、合计 16000 字符的未人工编辑原文及当前词表，结合相邻发言生成候选。
3. 核对显示的原文与替换词，必要时回放原音，再“确认替换”或“忽略”。同段有多个不重叠候选时可一次确认本段全部；逐项确认也会保留其余候选。

本地别名检查覆盖最近 120 段，并显示与全场段数的差异；模型只使用上述受限窗口。更早的内容可在逐字记录中手动编辑。不执行模糊同音全局替换，也不保证词表中的每个名称都应该替换当前发言。

确认会保存识别原文与版本，递增转录修订并重新翻译。后续普通人工编辑受保护，词表不会覆盖它；旧版纪要继续引用原冻结版本，重新整理才使用新文本。候选与原文或词表版本不符时要求重新检查。
