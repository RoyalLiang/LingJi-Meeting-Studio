# 网络代理

已发布安装包在**设置 → 网络**配置代理。当前源码将入口移到**设置 → 模型与转录**底部的**网络连接**，使用页头的**保存设置**统一保存；此迁移尚未包含在已发布安装包中。设置、音频备份及词表的待保存内容依次处理；网络保存失败会保留草稿并阻止后续保存。新设置供后续新连接使用。正在进行的录音、转录或下载连接沿用原连接；不要求为切换代理中断录音。

- **系统代理**是默认值。桌面后台读取系统代理；源码启动读取运行 API 和 worker 的主机设置。
- **自定义代理**支持 `http://127.0.0.1:7890`、`https://proxy.example.com:8443`、`socks5://127.0.0.1:1080`。需要认证时单独填写用户名、密码。SOCKS5 的目标域名由代理解析。
- **不使用代理**让应用直接连接外部服务。

应用的模型 HTTP 请求、语音 WebSocket、飞书连接和桌面客户端更新使用此设置。本机 API、录音传输和本地模型的回环地址始终直连。设置不修改操作系统，也不改变浏览器外链、Git 或 SSH 的独立配置。

代理配置保存在当前数据目录的 `network-proxy.json`，文件权限为仅当前用户读写。读取设置的 API 不返回密码；留空保留相同地址和用户名的已存密码，可通过**清除密码**显式删除。代理连接或认证失败会报错，不自动改为直连。

## 系统代理来源

应用优先使用 `HTTP_PROXY`、`HTTPS_PROXY`、`ALL_PROXY` 和 `NO_PROXY`（也支持小写）。没有代理环境变量时读取 macOS 网络代理、Windows 当前用户 Internet Settings 或 Linux GNOME 代理。系统设置缓存十五秒，后续连接会重新读取。

支持显式 PAC 地址及其代理顺序和 DIRECT 规则。只有 WPAD 自动发现、没有显式 PAC 地址时会提示改用自定义代理。Linux 非 GNOME 桌面可使用代理环境变量或自定义地址。系统凭证库中的代理密码不会被自动读取，需要认证时使用自定义代理。

服务器部署中，公网连接器仍保留原有 DNS 地址限制；该限制不因代理配置而放宽。桌面账户按原有连接器规则访问其允许的私有网络。

## 验证边界

本地自动化覆盖 HTTP CONNECT/认证、SOCKS5 远端 DNS、WebSocket、PAC 路径及故障切换、本机绕过、密码保护和原生更新隧道。真实企业代理、各系统账户的认证策略及设备上的系统代理行为仍需单独验证。
