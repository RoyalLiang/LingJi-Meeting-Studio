# 音源检测与智能纪要

核查日期：2026-10-12。这里区分代码实现、本地隔离测试与实体设备验证。

## 采集故障的证据

最初只读快照中，一条已结束录音的 76 个音频包均处理完成，但没有转录。约 74.91 秒 PCM 的 RMS、峰值和非零样本数均为 0，说明该次采集上传的是静音，不能据此判定 ASR 服务失效。

用户随后继续测试，记录水位已变化。按 Source 逐一复核：两个麦克风来源的标签为 `Microsoft Teams Audio Device (Virtual)`，均没有转录；后续共享来源的标签为 `System Audio`，已有 19 个转录片段。早先读取“最后一个来源”得到 System Audio，不能把这个标签归到先前的麦克风来源。这里只记录元数据，不保存用户会议正文。

## 已实现的采集修复

- 默认“会议录音”分别申请共享音频与麦克风；也可选择仅麦克风或仅共享音频。共享音频成功但麦克风授权失败时保留共享录制，并说明如何补加麦克风。
- 麦克风自动模式识别常见虚拟、回环设备；存在已识别实体麦克风时优先使用。设备标签可能在授权后才出现，因此授权后再次核对。可用的手动选择优先，不覆盖用户明确选择。
- 实际 PCM 按来源显示音量、静音持续时间、轨道静音、停止和音频上下文暂停状态。持续 5 秒静音给出检查提示；恢复声音后提示自动恢复。诊断不丢弃音频。
- 设置页提供 8 秒本地麦克风试音，不上传；结束、取消和关闭均释放媒体与音频上下文。
- 排队数量明确称为“音频包”，不再表示为待识别语音段落。处理完毕但没有语音时明确提示检查音源。
- 首个来源只有静音时，不再抢占说话人编号的起始归属；首次有效发言才建立来源与编号。同一来源 A→B→A 仍复用 1→2→1。不同来源缺少声学匹配证据时保留待确认，不能自动认定是同一个人。

浏览器不能仅凭麦克风权限获取扬声器输出。共享选择器中需选择带音频的来源并启用共享音频；系统全局声音能否共享仍取决于操作系统和浏览器。代码请求共享音频，只处理音轨，不上传画面。

## 已实现的纪要视图

参考用户提供的飞书截图，保留既有松绿色与玻璃风格，增加四个视图：

- **AI 视图**：按连续讨论主题形成可折叠树，使用不同背景与连接线区分主题，保留来源引用。没有被主题覆盖的要点进入“其他讨论要点”，不会丢弃。
- **发言人总结**：按会内稳定 speakerId 展示，服务端校验每个引用属于对应身份与转录版本。旧纪要缺少模型总结时只展示明确标注的“原文摘录”；未知声音不被编造成新身份。
- **关键决策**：模型只输出已达成决定；提议、问题、否定和待定事项不能当成决定。行动保留人工确认与下载流程。
- **正文**：保留修订、版本、导出、人工编辑保护。切换视图不会丢失未保存的编辑草稿。

桌面默认按需展开侧栏，并提供展开阅读按钮；手机使用独立纪要面板与内部滚动。四个标签支持键盘切换。主题、发言人和决定的引用使用纪要冻结的证据快照。

模型协议新增可选 `speakerSummaries` 和 `decisions`，兼容旧纪要。模型输出通过结构、重复身份、身份与证据版本校验后才提交。自动生成、会中流式草稿和会后正式版沿用既有任务调度，用户无需自行编写提示词。流式中间文字尚未通过最终结构校验，界面仍标注为草稿。

## 验证与边界

83 项 Node 回归通过；ESLint、TypeScript、Web 构建和文档链接检查通过。新增覆盖虚拟设备选择、静音诊断、首个静音来源、主题覆盖、旧纪要兼容、错人引用与本地模型响应提交。

隔离浏览器测试使用合成语音替代实体媒体输入，经过实际 CaptureController、AudioWorklet、IndexedDB、API、真实豆包和 SSE，页面显示转录与“说话人 1”。共享轨道的静音与麦克风轨道分别诊断。测试没有打开实体麦克风，也不能证明操作系统全局共享音频权限可用。

新纪要模型契约通过本机测试服务验证。截图使用虚构会议与预置纪要，证明布局和交互；不能作为当前远程 HTTP 模型成功生成新字段的证据。现有 HTTP 模型配置保持原样，本轮未向该地址发送密钥或会议内容。

浏览器验收包括 1280×720、1680×1000 桌面以及 390×844 手机布局：外层无滚动溢出，侧栏不与内容重叠，展开阅读、发言人/决策视图和冻结原文引用可用。证据保存在 gitignored `.agent-runtime/`：

- `browser-capture-real-asr-evidence.json`：合成语音的真实 ASR 链路元数据。
- `minutes-topic-tree-desktop.jpg`、`minutes-topic-tree-mobile.jpg`：主题树布局。
- `minutes-speakers-desktop.jpg`、`minutes-decisions-desktop.jpg`：发言人与决策视图。

实体麦克风、设备热插拔、系统扬声器共享、长时间休眠和真实多人会议质量仍需设备矩阵实测。
