# 工作目录与历史会议分析

更新：2026-10-12。视觉方向已经用户确认；以下实现事实来自当前代码和本地验收。

## 先把会议放在一起

侧栏的内置选项只保留「所有会议」，也可切换自己创建的工作目录。旧的 `workspace=inbox` 页面链接会转到「所有会议」。目录名称最长 80 字，说明最长 240 字，每个账户最多 50 个目录。一条会议同时只属于一个目录；旧记录没有目录字段时视为未归档。

在目录内快速记录或提前准备会议，新记录会继承该目录。标题仍可留空，会后再填。会议详情中的「归档」用于单条移动；首页底部的会议列表可以多选后批量归档，也可以移回未归档。正在录音的会议需先暂停或结束再移动，防止录制过程中切换范围。目录支持改名和修改说明，本轮没有增加删除目录或团队协作权限。

归档只改 `workspaceId` 和记录事件，不改 Source、音频身份、转录版本、人工纪要、保留期或分享权限。API 在同一事务内验证所有选中会议的所有权和录音状态；任何一条不符合条件，整批回滚。SQLite 重启后的归属保存已验证，Postgres 路径仍待真实集成。

## 首页中的数字怎么算

所有统计仅覆盖当前账户、当前范围、未删除且未到期的会议。统计不读取外部账单，也不跨会议合并匿名说话人。

| 展示项 | 口径 |
| --- | --- |
| 会议数 | 当前范围可访问的会议，含待开始和暂停记录 |
| 会议时长 | 根据来源时间轴与已接收采样位置计算最长结束点；并行麦克风和共享音轨只计一次，继续录音接在原时间轴之后 |
| 多音轨音频量 | 单独保存采样总量口径，不充当会议时长；导入文字没有虚构的音频时长 |
| 纪要覆盖 | 有已保存正式纪要的会议数 / 当前范围会议数；转录更新后的旧纪要另标待更新 |
| 讨论节奏 | 北京时间近 30 个自然日，按创建日期计会议数；少于 3 场时使用简洁列表 |
| 主题分布 | 已保存纪要中的主题名称，经 NFKC、空白和大小写规范化后精确归并，每主题每会议只计一次；这不是模型语义聚类 |
| 历史摘要 | 最近有内容的 20 场会议，优先现有纪要，没有纪要则明确标为原文摘录 |
| 决策与行动 | 有有效片段引用的已保存纪要字段，按会议内同文去重；最多返回每类最近 50 项，页面展示最近 8 项及总数 |

统计、历史摘要和来源标签无需云端调用。点击来源可回到会议；标签提示保留转录与纪要版本。来源引用存在不证明语义正确，行动候选也不代表任务已执行或已完成。

## 按需生成跨会议洞察

点击「分析历史会议」才会把当前范围内**已结束且有转录**的会议文字与纪要发送到已配置模型。仅打开目录不会触发模型分析。当前配置继续支持 Responses 和 Chat Completions，不覆盖用户已选的协议、地址或密钥。

输入按最近会议优先，正文总预算 48,000 字符，每场最多 6,000 字符。页面展示纳入场数 / 可分析场数及是否节选。统计仍覆盖全部可访问会议，模型洞察的覆盖范围另行说明，不能把局部结果解释为全量结论。

工作目录分析使用独立 worker lane，和音频、会中纪要、意图、翻译分开轮询。供应商 SSE 增量先累计，再每 250 毫秒至多写一次草稿；前端运行时约每秒读取最新概览，空闲时每 15 秒刷新。草稿只显示正在生成的摘要文字，最终结果经结构与会议版本引用校验后才展示为共同主题、关键决策、行动候选和待确认事项。

每个范围只保存最近一次运行。任务具有 runId、租约和 fence；重复提交正在进行且输入相同的任务复用原运行。停止要求匹配 runId，立即取消发布；工作线程约 750 毫秒检查一次取消和内容变化，并中止 HTTP 请求。供应商已经消耗的费用不能保证撤回。

人工纪要不会被跨会议分析改写。会议移动、删除、到期、标题、转录、笔记或纪要版本变化后，接口立即隐藏旧分析和草稿；下一次工作循环清空任务内的旧快照和结果。模型输出引用了不存在的会议或错误版本时拒绝发布，不静默补齐来源，也不产生外发行动。

## 阅读与标识

全局系统标识采用已选的「声音成章」透明 PNG；登录、侧栏、加载、分享和 favicon 复用同一文件。深色主题使用浅底标识容器。PNG 原稿仍不是矢量定稿。

搜索框位于右侧容器顶部中央，搜索范围保持当前目录；只保留外层焦点提示。右边缘「顶部」在内容滚动超过 320px 后出现，点击后暂停纪要跟随，避免新内容把阅读位置拉回底部；可用「回到最新纪要」恢复。减少动态偏好使用即时定位。手机按钮避开固定账户工具条。

## 本地证据与边界

- 本轮新增 8 项回归，覆盖目录范围隔离、旧记录未归档、并行时长、统计与旧纪要标记、输入预算和引用拒绝、原子批量回滚、SQLite 重启、分析取消、删除后失效，以及真实本地 Responses SSE 累计与上游取消。
- 隔离浏览器只使用虚构会议、合成采集入口和本地假密钥模型：已验证目录创建与改名、无标题会议继承目录、单条/批量归档、覆盖变化、旧结果隐藏、流式草稿及运行中停止。
- 视觉证据：[桌面首页](../evidence/workspaces/desktop.jpg)、[手机首页](../evidence/workspaces/mobile.jpg)、[深色首页](../evidence/workspaces/dark-mobile.jpg)。图中会议与模型结论均为虚构验收数据。
- 未执行真实远程模型质量评测、Postgres 事务集成或大规模长历史性能验证。真实录音与 VPN 连通性按用户要求保留原边界，本轮没有调整转录重试配置或重放用户原音。

代码入口：`packages/records/src/workspaces.mjs` 管统计与分析契约，`workspace-routes.mjs` 管访问和归档，`workspace-worker.mjs` 管分析生命周期，`WorkspaceHome` 与 `WorkspaceDialogs` 管展示和交互。Generic Repository 沿用已有 JSON 聚合存储；领域名词见根目录 `CONTEXT.md`。
