# 使用内置技能导入飞书云文档

在会议的 **导出 → 飞书云文档** 中勾选纪要画板，检查冻结预览后确认创建。正文、原生总结、顶部总览画板和勾选的引用保存在同一份文档；已有机器人配置继续使用。

内置的 `meeting-minutes/20261106` 来自用户提供的 `meeting-minutes-optimized.zip`。原包 12 个文件和逐文件 SHA-256 保存在 `services/records/src/data/skills/meeting-minutes/` 的清单中。运行时使用 JavaScript 适配，不执行附件中的命令，也不要求用户安装 Python。原始 Python 编译器保留供离线对照。

## 内容与权限

适配支持 12 类卡片：流程、分支、指标、分栏、表格、状态表、时间线、方案比较、行动清单、决策引用、风险矩阵和漏斗。应用已保存纪要按现有结构映射，保留人工修订、完整中文、原始数值和引用编号；不额外调用模型、不编造负责人或日期。纪要中只有数值原文时以表格保留，不推算为 KPI 或漏斗比例。

新版渲染器 `meeting-minutes/20261106-native-v2` 使用飞书原生分区和分组组织内容。流程使用吸附箭头，拓扑使用入口、判断菱形和分支；时间线使用节点和连线；数据与状态表使用原生表格及合并单元格；行动按来源状态排列为看板。表格每列保留最小可读宽度，多列内容扩展画布，可以缩放查看。所有图形、文字和表格均可在飞书画板中编辑。

可编辑图形、文字和相互引用的连接线在同一次请求中写入。按飞书接口限制预检 3000 个节点，并沿用本地 500KB 上限；超限在创建文档前报错，不截断正文。冻结导出的来源记录内置技能版本。原生总结与详细正文沿用现有实现。

外发仍只使用自建应用身份和已加密的本机配置。选择成员云文档时，在内容写完后沿用已有转交操作。开启技能不会获得额外外发权限；自动导出仍需原有独立授权。部分失败保留文档与阶段，不自动新建第二份。

## 已验证与边界

2026-11-06 的链路证据包含本地回归、12 类卡片、真实机器人创建和成员转交结果。合成样例已在飞书打开查看；这不证明真实会议的识别或纪要准确率。

原生画板浅色内容不会跟随飞书文档主题自动切换；聆记原有深色画板选项继续保留。附件原版 HTML 的网页交互不作为飞书原生能力。

12 类合成卡片已通过真实机器人创建，并在飞书逐类检查渲染；见原生画板验证。这覆盖示例布局，不代表真实长会议或超宽表的阅读验收。

## 真实纪要自动路由

新版渲染器 `meeting-minutes/20261106-routed-v3` 按纪要已有类型自动选择事实分栏、决策、行动、风险和待确认表，并将长内容分页为多块原生画板。标题使用普通原生文字，避免默认分区标签。无法独立拆分的单条内容保留完整，不为满足页面高度截断。

已发布十二类示例不等同于真实纪要自动路由验收；本次修订的本地与真实云端证据见真实纪要路由修订。

`meeting-minutes/20261106-overview-v4` 将默认导出改为顶部单画板摘要，完整文字、表格和引用继续放在正文。根据原文选择条件流程、前置关系、时间线或主题关系；风险矩阵使用原有等级与确认状态，未评级不推断。画板为有显示数量的摘录，不把全部主题扩成多张画板。十二类手工 DSL 编译器继续用于已有模板；它不决定实际纪要默认布局。见设计约束。
