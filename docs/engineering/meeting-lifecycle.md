# 快速记录、暂停与结束会议

本轮解决先填标题才能开始、结束后误追加到旧会议、音源信息过多，以及逐字记录宽度与密度的问题。转录连接故障由用户确认与 VPN 有关，按要求跳过；本轮没有修改供应商地址、密钥、代理或失败重试状态。

## 用户流程

- **快速记录 / 即刻聆记**：直接创建未命名会议并申请麦克风与共享来源权限。创建记录的网络请求不会推迟原始点击中的权限申请。标题不必预填。
- **提前准备会议**：保留语言、留存和自动纪要选项，标题同样可空。
- **暂停 / 结束**：录音时打开收尾面板。暂停后回到同一会议继续；结束后保留本场内容，下一次通过“开启新会议”创建独立记录。
- **会后标题**：未命名记录在转录排空后提取关键词命名，已校验的AI终稿可优化自动名称；可在收尾面板填写或编辑，人工标题不会覆盖。列表包含创建时间，便于区分多条未命名会议。
- **音频来源**：主界面仅显示“我的声音 / 会议声音”、接入状态及小型音量条。设备名称、完整信号诊断、缺失来源与重试入口集中在来源面板。

新录音默认保留原音，无需勾选；快速记录默认留存30天，原音随记录到期清理。ASR＋LLM 模式配置了纪要模型时开启自动纪要，可在纪要面板关闭。豆包音频和 OpenAI Realtime 模式也直接开始未命名记录，但自动音频纪要默认关闭；在“整理设置”明确允许发送本场原音后开启。浏览器仍要求用户确认共享来源，网站无法静默选择系统扬声器。暂停会释放当前音轨，继续时重新申请来源。

## 会议与采集状态

| 状态 | 可用动作 | 记录归属 |
| --- | --- | --- |
| idle | 开始采集、修改标题、导入 | 当前会议 |
| recording | 暂停、结束、补接缺失来源 | 当前会议 |
| paused | 继续、结束、开启新会议 | 继续属于本场；新建属于另一场 |
| sealed | 等待音频补传与转录、开启新会议 | 当前会议已结束，不再添加音轨 |
| completed | 阅读、改标题、纪要与分享、开启新会议 | 当前会议已结束，不再添加音轨 |

`POST /records/:id/pause` 与 `seal` 使用相同的完整音源清单。先验证所有来源，再统一停止，避免部分音轨被错误封存。原有 `record/session/source/epoch/sequence`、哈希幂等、缺片修复和停止排空约束保留。

暂停不会把会议变成已完成。已封存来源的识别可以继续，自动纪要仍可整理已有发言。继续时建立新的连续采集会话；同一次继续中的麦克风与共享音轨使用相同的 `timelineOffsetMs`。时间轴按上一采集段最长音轨衔接，不叠加平行音轨，也不计暂停的墙钟时间。普通转录、说话人发言、重复结果匹配和实时草稿统一应用偏移。旧来源没有该字段时按零处理。

若暂停时仍有缺片，允许按封存清单补传；在尾部音频持久化前暂不能继续，防止新采集段时间轴重叠。结束会议仍等待全部清单与转录排空。`completed` 拒绝新音轨，重复结束保持幂等。

说话人哈希仍保留在会议内。新的采集音轨不会把供应商局部说话人编号直接当作上一音轨的同一个人；无法确认的身份仍需人工归属。本轮未增加跨音轨声纹识别。

## 逐字记录排版

移除逐字记录的 880px 居中宽度限制，正文与主题分组占满可用内容区。正文从 14px 调整到 13px，行高从 1.95 调整到 1.7；发言块上下内边距从 16px 调整到 9px，分组间距从 20px 调整到 12px。说话人头像与元信息同步收紧，实时草稿采用相同的正文密度。主题背景、引用、编辑、自动跟随与上翻历史行为保留。

## 验证与证据边界

100 项 Node 回归、ESLint、TypeScript、Web 生产构建和 46 份文档检查通过。API 与处理器已在无采集、无模型任务时重载；健康检查返回 SQLite / filesystem 正常，原有失败音频的尝试次数未重置。

- 领域回归覆盖已结束会议禁止追加、暂停后继续、平行音轨时间轴、缺片补传、重复封存、ASR 完成边界、说话人重放与人工编辑保护。
- HTTP 集成覆盖无标题创建、持久暂停、继续、结束、会后改名与新记录 ID。采集回归覆盖新记录创建之前的权限申请，以及创建失败后的音轨释放。
- 隔离浏览器使用虚构会议、合成音轨和不启用处理器的测试 API，验证快速开始、暂停后刷新继续、会后改名、新会议分流及手机双音源摘要。没有向实际 ASR 或模型发送本轮测试内容。
- 宽屏实测逐字记录与内容区均为 1052px；390px 手机页面均为 350px，正文为 13px，无横向溢出。手机双音源摘要包含分隔留白共 44px 高。
- 实体设备、真实在线会议、长时间暂停与断网期间的持续补传仍未作为本轮验收证据。当前 VPN 连接边界与远程 HTTP 模型边界保留。
