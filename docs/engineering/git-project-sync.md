# Git 项目同步

当前，可在“扩展中心 → 自动化 → Git 项目同步”设置会后归档。当前支持 GitLab 与自托管 GitLab。

## 配置与范围

填写 HTTPS root 分组地址及独立访问令牌，检查连接后选择已启用的 Skill、固定版本和可选 MCP 读取工具，填写整理提示词、归档目录及 Workspace 映射。Skill 安装来源可以是个人仓库；同步 root 必须是分组，两者不是同一个配置。

项目目录只遍历该分组及其后代，不接收共享进来的分组外项目。标题必须明确包含唯一项目名称或用户确认的别名；或会议位于绑定唯一项目的 Workspace。二者满足其一即可；多个标题命中、标题与 Workspace 冲突、项目移出 root 或已归档时暂停。英文名称按词边界匹配，过短别名不接受。

先检查同步范围，再勾选未来会议的自动发送授权并保存。只自动处理开启规则后结束、最终纪要已就绪的会议；已有历史纪要需要在范围预览中手动同步。修改来源不会无提示重新外发，需手动核对。

默认新建归档分支和 Merge Request；直接提交默认分支需要另行勾选确认。令牌需要可读取分组、项目、默认分支，以及创建提交和 MR 的权限；仓库分支保护仍生效。更新连接后，对失败任务显式点击“核对并重试”。

## 内容与执行

Agent 使用现有 Pi 底座，阶段任务使用 pi-durable + SQLite，进度重启后可恢复。MCP 只开放已选定的读取工具，不能扩大 Git 写入范围；模型不接收 Git 令牌。

每次归档生成原纪要 Markdown、AI 整理结果及来源清单。人工修改保留在原纪要中，不由模型覆盖。默认只向模型发送纪要及所引用的转录片段；笔记需另行选择，原音和未引用的完整转录不发送。文件日期按规则保存的浏览器时区计算；API 未指定时区时使用 UTC。

目录包含会议 ID、纪要修订和归档版本，不覆盖已有不同内容。来源清单记录纪要与转录版本、引用、Skill/MCP 版本和模型配置摘要。凭据加密保存在本机 secret store，不出现在界面回执与来源文件中。

## 进度、失败与恢复

任务窗口显示五个真实阶段：归属检查、读取来源、Agent 整理、提交分支、创建并核对 MR。运行时显示动效，遵循系统“减少动态效果”设置，不使用虚构耗时百分比。可在安全边界暂停和恢复；已送出的请求可能已被远端接受。

应用内显示失败通知与任务历史。权限不足提示更新连接；来源或权限版本变化暂停；429 最多进行三次持久化退避；不确定的写入先核对同一分支、文件和 MR，不能直接重复提交。已合并且分支被删除时，通过默认分支现存内容恢复回执。只有远端提交或 MR 核对成功才显示“已同步”。

本地来源删除或到期后，停止后续写入并清除本地任务正文；已经提交到 Git 的内容不会因此自动删除。请通过项目的正常审查流程管理远端副本。历史任务超过 1000 条仍分页清理。

## 验证范围

本轮证据记录真实 Pi/pi-durable 与隔离 GitLab API 测试、实际浏览器截图和发布状态。尚未使用用户真实项目 root 执行写入，也未验证真实模型、真实 MCP 或实体安装后的长时间运行。


## 组合多个 Skill

在扩展中心安装并启用独立 Skill 或顶层 Skill 集合，再到 Git 项目同步的 **使用 Skills** 勾选所需项目。集合可与其他 Skill 同时选择，重复指引只加载一次。Agent 使用 Pi/pi-durable，按任务需要读取已选集合内的指引。

私有来源首次检查成功后会加密保存令牌，同一账户与仓库可留空复用。点击 Skill 名称查看已安装版本的 Markdown，集合详情可切换子 Skill。检查更新或重新安装后需要再次启用；旧任务不能继续使用已变化的版本。

## 继续已暂停或中断的同步

任务窗口直接显示过程与用量。继续操作会自动复核已保存设置；“范围检查”用于预览目标，不是恢复任务的门禁。配置变化时，在尚未写入远端的前提下采用新配置继续；待回复的问题会保留，回复后进入新 Agent。已进入写入的任务先对账，不能因模型变化重建第二份归档。
