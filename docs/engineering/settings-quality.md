# 保持设置稳定，并为转录提供正确术语

v0.1.36 起，文字分窗与服务基址行为以[纪要效率与配置说明](minutes-efficiency.md)为准；音频分窗保持两分钟，以下历史设计不作为文字分窗的新限制。

核查日期：2026-10-12。以下区分当前代码、本机验收与供应商质量边界。

## 填写完整模型接口

模型地址按填写值保存、读取并发起请求。`/v1`、自定义路径、查询参数和尾斜杠不会被自动补全；切换 Responses / Chat Completions 只改变请求体。地址为空时不回填默认地址。首次没有任何配置时仍显示已有默认值。

此前仅保存原始地址，读取时却调用 `chatEndpoint` 改写路径，导致关闭重开和请求时出现不同地址。回归覆盖保存响应、重读、协议切换以及真实请求边界；未改写本机现有服务配置。过去只填基础地址的配置需要维护者明确填写完整接口。

## 只通过关闭按钮退出设置

设置弹窗忽略遮罩、弹窗空白和 Esc 关闭操作。关闭按钮仍可使用鼠标或键盘激活。其他弹窗保持原有关闭行为；设置内选择器的 Esc 只关闭选项，不改变后方纪要面板。

输入框和自定义选择器以单层边框颜色表示焦点，移除外层深绿色 outline 与阴影。搜索框由容器边框表示焦点；普通按钮保留键盘焦点提示。

## 保存时保留当前操作位置

服务保存不禁用整张表单、不改变按钮文字、宽度或透明度。使用请求锁防止重复提交；可以继续编辑，响应只回写未被再次修改的字段，密钥也遵守同一规则。成功和失败通过 toast 提示，不插入会移动内容的错误段落。多个操作的 toast 只显示最新一条，避免重叠。

同步翻译立即显示新的选择，等待响应期间保持控件外观；失败回退并提示。只更新对应记录字段，不触发工作台全局 busy 或刷新列表。

浏览器复现时，旧保存按钮宽度从 108px 变成 82px，透明度从 1 变成 0.48；旧翻译选项在等待请求时跳回原值。修复后按钮始终为 108px、透明度为 1，弹窗和地址输入节点保持不变；无用户滚动时 scrollTop 保持 541.5。

## 为豆包识别配置术语

在**容易识别错误的词语**中填写正确写法，例如“聆记，Redis Sentinel”。支持中英文逗号和分号，去重后总长最多 100 字，每词最多 50 字；填写空值可清除。限制用于控制流式上下文体积，并非对供应商 token 数的精确计算。应只填写会用到的专有名词。

术语经 `request.corpus.context` 中的 JSON 字符串传入 `hotwords`。短批次与持续识别共用参数，并在使用 `bigmodel_async` 的中英文短批次补充 `enable_nonstream`；持续识别原有二遍识别和说话人参数保留。错误配置在创建连接前拒绝，不让 socket 回调中的异常退出 worker。

这些参数依据[豆包流式识别文档](https://docs.volcengine.com/docs/6561/1354869?lang=zh)。二遍识别需要支持它的优化接口；既有默认 `bigmodel_async` 属于该路径。没有自动更换资源版本、密钥或供应商，也没有用模型重写已保存转录。设置在下一次识别连接生效；不会中断当前连接。

**尚未验证：**本轮使用本地协议 fixture，没有调用真实 ASR，也没有收到用户的原话/错例对照，因此不能声称真实会议错字率已经降低。术语配置提供可验证的改进手段，实际 CER、专业词和多人噪声环境仍需同一音频前后对照。

## 本机登录恢复与验证范围

用户报告无法登录时，浏览器显示登录及 bootstrap 均为 200，随后 `/api/workspaces` 返回 404。运行中的 API 尚未加载另一批工作目录改动，新前端因此退回登录页。仅重启已核对的本机 API 与 worker，保留 SQLite 和配置；两个本机地址都已通过实际开发账户按钮进入工作台，工作目录接口返回 200。没有改动密码或用户数据。另复现并修复了失败后同页重试成功仍残留旧 not_found 提示的问题：重新 bootstrap 前清空过期错误。

仅含本轮暂存变更的独立快照 `npm test` 104 项通过，当前工作区 112 项通过；ESLint、TypeScript、Web 构建和文档引用检查通过。测试数量包含工作区并行的工作目录改动，本轮提交只包含设置与识别术语相关文件或差异。

隔离浏览器以本地虚构 API 响应验证关闭操作、焦点样式、慢保存、重复提交、新草稿保护、失败反馈、翻译回退、单 toast，以及 390×844 浅深主题布局。未启用麦克风、屏幕共享或外部模型。日志与截图位于 gitignored `.agent-runtime/settings-quality/`。
