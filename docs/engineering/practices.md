# 用可恢复链路和可核对证据推进实现

2026-10-11。本文给出实现与验收实践，不表示对应功能已经完成。先读 [当前状态](current-state.md) 与 [目标架构](../design/architecture.md)。

## 本地启动与基线检查

使用项目当前已安装的 Node/npm；`package.json` 声明 npm@10.8.1，但没有 engines 约束。本轮测试运行环境是 Node 22.14.0；不要把它误当长期支持策略。新成员按 lockfile 安装依赖：

```bash
npm ci
```

分别运行以下三个进程：

```bash
npm run dev:api
```

```bash
npm run dev:gateway
```

```bash
npm run dev:web
```

访问 `http://127.0.0.1:3000`。默认内存和 mock 只用于开发；在界面与测试输出标明模拟结果。AI worker 当前是占位，不把 `npm run dev:ai` 的启动日志当成纪要能力。

`npm test` 是当前本地回归入口。Go 实验独立运行 `cd services/engine-go` 后 `go test ./...`；默认 3010 与 Node 网关相同，不要同时以默认端口运行两个入口。

当前 lint/typecheck 脚本只 echo TODO。计划接入真实工具前，不能将这些脚本的零退出码记作静态检查通过。Postgres 模式的 `pg` 包已在 transcript-api workspace 声明；全仓安装应包含该依赖。启用还需要数据库、环境配置与迁移，本轮没有执行这条集成路径。

## 优先验证不可静默丢失的契约

| 验收场景 | 可观察结果 |
| --- | --- |
| 音频相同身份重传 | 返回原持久 ACK；不重复输入或计数 |
| 相同身份但内容不同 | 明确冲突，不覆盖原音频 |
| ACK 返回前后进程崩溃 | 已 ACK 内容可恢复；未 ACK 可安全重传 |
| seal 先于最后几块 | 显示等待缺口，允许封口范围内补传 |
| final 已计算但提交失败 | 不推进“已保存”，恢复后重投递 |
| SSE 断线并重启网关 | 从 cursor 补历史，重复事件不重复显示 |
| cursor 超出保留范围 | 明确重新 bootstrap，不伪装完整续读 |
| ASR 限流、掉线、尾部迟到 | 独立呈现处理状态和缺口，翻译/纪要不拖垮原音保存 |
| 修改已被引用的转录 | 创建新版本；旧纪要 stale，旧引用可核对 |
| LLM 重复、乱序、超时 | 同输入幂等；旧 attempt 不能覆盖较新结果 |
| 人工改稿与 AI 重生成并发 | 保留人工输入，出现冲突提示或新草稿 |
| 删除后旧音频补传或 worker 完成 | generation 拒绝旧写入，记录不复活 |

这些测试穿过模块 interface 断言结果，避免只测试内部函数调用次数。内存 adapter 适合状态逻辑；持久 ACK、事务、outbox 和崩溃恢复必须使用真实数据库与可故障对象存储 adapter。

## 用浏览器矩阵验证声音来源

先评估 Chrome/Edge 在 Windows/macOS 上的首版支持范围，再扩展 Firefox/Safari；此处是测试计划，不是发布支持承诺。每项记录 OS/浏览器版本、输入来源、权限选择、实际音轨、音量、编码与最终结果。

- 拒绝/取消权限，无设备、设备被占用、静音、换设备。
- 共享标签页有/无“共享音频”，共享窗口/屏幕没有音轨，用户结束共享。
- 浏览器音轨与麦克风同时录制的回声、重复远端声音和时钟漂移。
- 用户点击后的瞬时权限要求；异步创建会议不能使授权调用失去用户手势。
- 60/120 分钟录制、后台标签页、锁屏、睡眠、网络切换、刷新和恢复。
- IndexedDB 配额不足、缓存写入失败、浏览器清理存储、多标签并发录制。
- 无原音长期留存时的临时缓冲清理；源音删除后回听入口正确降级。

自动化合成音轨用于确定性流程，物理设备与真实会议用于能力和质量验证，两者分开报告。未经授权不采集用户真实会议。

## 先建样本，再设置识别与纪要门槛

样本建议覆盖中文、英文与混语，远程会议、访谈、课堂与个人记录；按设备、噪声、口音、重叠说话、术语和会议时长分桶。先用少量明确授权样本校准标注流程，再扩大；不能把样本数提议当统计充分性证明。

标注保留真实转录、时间范围、说话人、术语、实际决议/未决讨论、行动责任与日期是否明确。记录人工评审者及分歧。样本用途、保留与删除受独立授权约束，不把生产内容自动用于训练。

分别报告 CER/WER、术语召回、说话人错误、首字/定稿延迟、输入缺口和纪要断言支持率；中文不用仅按空格分词的 WER。摘要评价除了引用存在，还要检查引用是否支持结论、有没有遗漏反对意见、是否猜出责任人或日期。真实错误按识别、分段、检索、推理、合并、展示归因。

## 观测用户等待和恢复水位

核心 trace 标识：recordId、sessionId、sourceId、epoch、chunkId、providerAttempt、jobId、transcriptRevision；日志只记录必要元数据，不默认输出原音、完整转录或密钥。

记录时间点：采样 → 本地缓存提交 → 上传 → durable ACK → provider 输出 → final 提交 → SSE 到达 → 纪要可读。跨机时钟不能直接相减，应使用校准、服务端跨度及客户端单调时间分别分析。

指标包括 pendingAudioSeconds、contiguousAck、missingRanges、outboxLag、workerLeaseAge、staleSummaryCount、providerErrorRate、costPerAudioMinute。按来源/设备/模型/网络分桶，避免平均值掩盖少数会议丢失。

## 显式计算容量、成本与隐私代价

16kHz、16bit、mono PCM 的输入量为 `16000 × 2 = 32000 bytes/s`，一小时约 **115.2 MB（109.9 MiB）**。200ms 一块约 6.4KB、每秒 5 次；100 个并发单源约 500 块/秒和 3.2MB/s 原始载荷，双源约翻倍。以上是算术估算，未计协议、索引、重传或压缩，不是容量压测成绩。

成本模型：

```text
每会议成本 = 各 ASR 来源的计费分钟 × 单价
           + 翻译/实时要点调用
           + 纪要输入/输出 token × 对应单价
           + 音频存储时长 × 容量单价
           + 流量、数据库、计算、重试与运维分摊
```

价格参数使用实际供应商当期合同；本轮不凭 DeepPage 售价倒推其成本或本项目毛利。多源、重放、失败重试可能重复计费，需观测而非假设免费。免费额度、用户硬上限、最大会长、并发限制、重试预算和成本提醒在试点前确定。

## 每次交付说清证据层级

交付包含：修改范围、用户结果、执行过的检查、未验证条件、迁移/回滚方式。依次区分源码、纯逻辑测试、内存链路、真实数据库、浏览器自动化、物理音频、真实 provider、部署和生产。

功能开关按用户可理解能力启用。数据库迁移先兼容读写再切换；旧接口停止前保留观察期与恢复路径。签发、分享、删除、外部行动都保留操作者与执行结果；不因文档写好了就推定已上线。
