# 导出到飞书并管理远程扩展

2026-11-01。v0.2.10 已发布测试版，五项 CI 与附件 API 元数据核对通过，见发布回执。基于 v0.2.9；历史原型不代表真实接入结果。本页区分已实现流程、本地验证和待真实服务验收的部分。

当前飞书方案已按用户确认调整为官方 SDK 长连接与应用身份，详见[配置与验收](feishu-sdk.md)。用户 OAuth、回调中继和用户令牌已从本轮候选移除；v0.2.10 的历史发布记录保持原样。

## 配置飞书协同并导出

在 **扩展中心 → 自动化 → 协同工具** 点击飞书卡片，填写自己的企业自建应用 App ID 与 App Secret。开通所列应用权限并发布后保存；聆记自动建立并保持 SDK 长连接。右侧滑块控制能力启停，关闭后保留凭据并停止连接与外发。

无需重定向 URL、个人用户授权、公网域名或事件接收服务器。在飞书后台的 **事件与回调** 选择 **使用长连接接收事件**，保持聆记运行后验证并保存。云文档 API 由同一官方 SDK 以应用身份调用。

会议的 **导出 → 飞书云文档** 支持先预览标题、笔记及引用范围，再确认新建文档。文档归应用；目标目录须由应用创建，留空放入应用根目录。个人账户能否打开取决于已有协作者权限，聆记不自动扩大分享范围。

回执保留文档 ID、权威 URL、来源版本和状态。创建超时显示“结果待核对”，创建后写入失败显示“部分完成”；同一请求不自动再创建。本地删除会议不删除已导出的文档。

凭据由后台加密保存，本机密钥文件 `integrations.key` 不进入模型、纪要或安装包。SDK 在内存中处理应用令牌缓存与续取；旧用户访问/刷新令牌在升级时清除。备份后台目录时按凭据备份管理。

## 显式开启会后自动导出

在飞书能力在线时，选择目标目录、是否包含已保存笔记和引用原文，确认未来纪要的发送范围后开启。只处理之后结束且完成最终纪要的会议，已有已结束会议不补发。后台需持续运行；断线期间暂停，SDK 恢复后继续核对最终纪要与回执，避免重复创建。

修改应用凭据或停用后重新启用能力，需要重新确认自动导出范围。关闭自动导出不会撤回已创建的飞书文档，也不会取消已经发出的创建请求。

## 从 GitHub 安装并管理文本 Skill

打开 **扩展中心 → Skills → 从 GitHub 安装**，填写 GitHub 仓库 URL、Skill 目录和分支、标签或完整提交 SHA。先检查来源、指引和解析后的完整提交，再确认安装。安装后默认停用，启用后可在会议助手中选择。

当前支持 `SKILL.md` 的 `name`、`description` 和正文，以及最多 10 个直接链接的相对 Markdown 参考文件，合计最多 40000 字符。引用不得跳出 Skill 目录。固定的 Git 提交就是安装版本；检查更新会重新预览，新版本需再次确认并启用。

仅安装方法指引，不执行脚本、安装依赖、读取任意本机文件或改变工具权限。私有仓库可填写只允许目标仓库 Contents 读取权限的 GitHub 令牌；令牌由后台加密保存，同一账户检查该 Skill 更新时可留空复用。更换仓库或目录后需要重新提供令牌。不支持任意 ZIP 包、第三方可执行代码插件与嵌套参考资料的自动遍历。文本中要求额外能力时，当前宿主不因此提供这些能力。

升级、停用或移除会阻止未完成任务继续使用旧授权；已完成结果保留运行时版本。

## 连接 HTTP MCP 插件并逐项授权

打开 **扩展中心 → 插件 → 添加 MCP 服务**，填写服务名称、公开 HTTPS Streamable HTTP 端点和可选 Bearer token。连接时先完成初始化并读取工具清单，不执行工具。

只开放服务声明为只读的工具，用户逐项批准后才能启用。只读标记由服务提供方声明，不能代替对服务的信任判断。重新检查连接会更新工具版本并停用，需要重新批准。

每个会议助手任务还需单独选择插件并确认文字发送范围。模型只能调用该任务选择的插件和已批准工具；来源会议、Skill 与插件版本会再次核对。远程结果不能伪装成本地会议引用，飞书写入也不作为助手工具。

当前支持匿名或 Bearer 认证、JSON 与 SSE 响应；不支持 MCP OAuth 自动登录、stdio、本机进程、资源/提示订阅或第三方代码包。端点不接受 URL 内凭据、query token、重定向、IP 字面量或私网地址，当前使用标准 HTTPS 端口。桌面本机模式额外兼容 `198.18.0.0/15` 代理 fake-IP，并继续校验 TLS 主机名、固定已解析地址、拒绝重定向及其他私网地址。此时最终路由由本机代理决定，不宣称已验证最终目标属于公网。共享服务不启用此例外。

## 使用会议助手和 Pi 纪要

会议助手支持选择 1–8 场已转录会议、内置或已启用的远程 Skill、可选已保存笔记及至多 3 个已批准插件。运行前显示范围与发送对象；提供常用整理目标、真实读取进度、取消、历史结果和沿用范围再次提问。

结果独立保存，不写回原纪要；每项决策和行动候选继续校验会议、片段与修订。没有实际流式正文时不会展示模拟流式结果。

生产文字纪要生成已进入真实 Pi Harness。既有 worker 继续负责持久化窗口、排队、重试与人工稿保护；每个固定窗口在内存中运行 Pi，不另存重复的原始会议历史。原有供应商配置、结构校验、引用恢复、增量回调、取消和用量统计保持。规则提取、明确 fixture 和音频直接理解保留各自路径，不将它们描述成已完成 Pi 改造。
