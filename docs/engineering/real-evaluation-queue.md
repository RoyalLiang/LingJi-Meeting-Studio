# 建立真实识别样本的本地盲标队列

本轮已从授权的本机应用记录建立229条待盲标样本：转录80条、会议内容意图120条、助手工具路由29条。224条有原始采集音频，另外5条是未保留语音的助手请求文本。当前人工金标为0，没有运行模型，也没有得出准确率提升结论。脱敏批次与校验记录只保留数量、版本、摘要和验证结果。

样本、原音、基线、标注页和标注结果保留在本机私有目录，不进入Git，不随应用或Release分发。本轮是评测资料准备，应用版本维持v0.2.37。

## 先听原音，再建立人工参考

本地包中的 `review/index.html` 可离线打开。转录任务不显示已有ASR文本；标注者听音后填写参考稿、音频情况和备注。无法辨清时弃标，非语音可保留空参考稿。人名、专名的同音字不能按当前词表倒推，需在盲标后用独立材料核验。

会议内容意图逐项标注决定、行动候选、提议、问题、否定／撤回，允许同一发言有多类意图。“不存在”和“无法确定”分开。页面提供焦点发言的原音和最多两段前文；前文只来自焦点开始前已经结束的片段，不使用未来发言。

工具路由结合原请求来源、选定会议版本、工具范围与写入授权标注。24条会议背景样本用于观察把会议内容误当直接命令的问题；5条原始请求文本没有对应语音，不借用会议音频补配。6条普通助手请求按内容与选择范围共同去重为5条，5条自动化请求不混入直接用户请求子集。存储中的用户请求角色不证明操作者身份或输入设备。

输入会暂存在当前浏览器，支持导出标注JSON。页面不调用云端识别、教师模型、训练或外部工具，也不修改源记录。界面验证使用独立QA数据集和存储键，模拟标签不能导入真实队列。

## 按会议分组，保留独立评测分区

样本覆盖27条记录，分为16条校准样本和213条保留评测样本。分组考虑记录、采集会话、关联多会议请求和重复PCM；同组不跨分区。在本机既有学习轮次出现过的记录不进入新的保留集，本批最终未选中旧学习记录。

校准分区包含转录6条、会议意图9条、工具路由1条；保留分区分别为74、111、28条。先用校准样本明确标注口径，保留集参考稿和标签不能回流到词表、提示词或模型调参。这是数据分组与操作约定，没有实现独立文件权限隔离，也不能证明不存在其他训练来源。

词表对照基线固定为 `20261105.3`、2,088条。后续转录、会议内容意图、工具路由分别评分，不能用一个合成“准确率”代替。当前阶段只建立标注队列，不包含有词表／无词表的模型对照结果。

## 校验来源和导出的标签

私有包中的 `validate_pack.py` 核对冻结文件摘要、原音WAV/PCM摘要、16 kHz单声道格式、样点／分片覆盖、来源修订和留存期、分组隔离，以及ASR焦点原文没有出现在其他任务的可见焦点或前文中。

导出的标签绑定数据集版本、文件摘要、样本ID和输入哈希。审核状态需要标注者、盲标确认；带音频的样本还需要听音确认。会议意图标签须完整，工具选择不能超出原请求范围。错误数据集、过期输入哈希、重复标签、缺少标注者、未听音、无法辨清却填写转录参考、越权工具标签和QA导出混入均已验证会被拒绝。

勾选听音和填写标注者属于自述，不是身份认证或语义正确性证明。模板初始标签为空，结构校验通过也不会自动成为金标或产生模型分数。

## 本批覆盖与边界

原音累计约43分39秒，沿用已持久化的片段边界，未证明每条都是完整语义句。音源以系统音频为主：166条系统音频、58条麦克风音频。来源、非mock识别标识和有效PCM已核对，真人身份、媒体回放与业务会议归属需要人工听音确认。

源记录并非新录制的统一基准；采集时的应用版本未被持久化，不用当前v0.2.37倒填。本批不能代表完整的远场、方言、多人重叠或语音工具指令分布。直接请求仅5种上下文，不能据此推导总体工具路由准确率。

评测副本不会随应用删除操作自动清除。样本记录原留存截止时间，过期后页面不再列出、校验会拒绝；提前删除原记录或撤回使用范围时，也应同步停止使用和清理评测副本。
