# 当前能力与验证边界

当前源码目标版本为 **0.3.30**，尚待完成本轮发布验证。发布状态以 [GitHub Release](https://github.com/RoyalLiang/LingJi-Meeting-Studio/releases) 和对应 Actions 结果为准；本地检查通过不等于安装包已发布或目标设备已验收。

实时事件仅合并进行中的读取，不再复用已完成的空查询结果，避免刚提交的转录或纪要等待下一次恢复轮询。420px 及以下的会议操作按四列排列，560px 及以下的操作按钮保持 44px 触摸宽度。

说话人标注使用可拖动的独立浮窗，转录滚动不移动标注窗口。片段切换保留各自草稿；保存回执仅影响对应草稿。仅修改称谓时递增转录修订，以新纪要版本衔接当前引用，保留正文、历史快照、已有译文和知识库人工评审，不重新触发已完成会议的自动纪要。首页、扩展中心和设置在首次访问后保留页面状态，隐藏时暂停首页与助手任务的主要轮询。

工作台采用项目导航、悬浮主画布与上下文三栏；窄屏使用导航和上下文抽屉。会议保留纪要树、原文引用与录音状态，手记提供 Markdown 实时预览。会议操作集中为顶部图标，导出窗口提供纪要、完整备份、行动日历、工单候选和原音；分享保留独立确认。三个内容页维持工具栏高度并保存各自阅读位置。重点速览入口固定在窗口右边缘中线。录音时长与纪要用量固定在主画布底部，正文独立滚动；已移除并读及正常连接提示，离线和待保存音频仍保留。设置保存集中在页头，转录、纪要、学习、飞书、Git、MCP 与记录存储的检查结果分别归属对应模块；MCP 连接探测不会更改已有工具批准。共享 Toast 固定为 64px 悬浮提示，长文可展开，不参与主内容布局。

纪要生成过程默认收起。转录窗口按会议时长与字节量、模型和配置预算确定（4096–96000 字节）；超时后有界缩小失败窗口或汇总输入，复用已完成缓存，最低 4096 字节、最多八轮，仍失败时保留真实错误。普通 live 请求维持 120 秒，最终多窗汇总使用 360 秒有限时限，租约额外保留 60 秒。macOS 使用透明原生标题栏并跟随应用主题，保持系统窗口控制；设置入口收为顶部图标，扩展与助手进入项目导航。问答和知识卡片并入项目首页。首页概况、图表、统计与资料采用统一宽度，项目操作和计数使用轻量胶囊。已确认 Git 归档可从完整历史回执恢复任务状态，不重复请求模型或写入仓库；不完整写入在配置范围变化后引导核对。

声纹库按账户聚合原加密库，公开身份绑定原库及条目，保持账户隔离；旧版仅同意项目范围的特征需显式确认后才参与跨项目匹配。试听复核原音留存、片段版本及在途撤销。手记使用按需加载的单栏 Markdown 编辑内核，初始读取不改动草稿状态；图片继续仅显示替代文字。Git 主 Markdown 文件以会议名称和配置时区日期命名，归档版本使用独立子目录，保留禁止覆盖已有人工文件的护栏。

首页展示日／周／月／年场次及模型 Token；会议按创建日、Token 按实际请求回执日归组，缺失回执不估算，部分上报用 + 标识。最近七天柱状图位于周期统计上方，欢迎区压缩为一行概况；逐日标注日期、场次及会议时长（m/h）；仅悬停或键盘检查时显示轻背景。滚动条统一隐藏，保留滚轮、键盘和横向滚动。版本入口位于顶部 Logo 旁，项目导航固定，仅最近讨论列表滚动。自动化页在第三栏展示实际飞书／Git 任务、分页与详情；更多菜单使用顶层浮层，保留原有权限和确认流程。

自动录音仍需明确开启并选择会议应用。双向活动允许在最近 6 秒内分时上报，之后保持既有 4 秒启动确认；单向活动不启动，错误、采样断档和静默会清除活动证据。普通弹窗仅阻止自动启动，不阻止所属会议自动结束；自动结束沿用十秒无目标音频调用确认；封存暂时失败会保留所属会议重试，物理采集已停止时仍可完成封存。macOS CoreAudio 与 Windows WASAPI 是平台活动来源，真实会议和设备权限仍需分别验收。

## 已实现的工作流程

- 浏览器和桌面共用 Record API，保留 record/session/source/epoch/sequence、持久化确认、重传幂等及停止排空。桌面本机 PCM 直接落盘交给后台，主窗口可重建。
- 高频集合、纪要文档和任务按需读写；接收与本地草稿更新避免完整转录载入。SQLite FTS5／BM25 和 Postgres GIN 支持有界检索，通知唤醒与低频恢复共同调度。
- 本地 Zipformer 实时草稿、SenseVoice 最终修订、NN 说话人分离，以及主动同意的账户全局声纹库（旧项目条目需确认）。macOS 和支持版本 Windows 可选择应用音源；本机麦克风接入 SpeexDSP 处理。
- 转录与译文使用动态虚拟列表。支持格式的长音频按片段解码，缺少 AudioDecoder 时仅允许有界回退。
- 目录知识保留冻结引用、确认状态与待核对冲突；问答检索整个目录，使用有界相关会议并逐条引用，依据变化后阻止展示旧结果。
- 纪要、翻译、意图和分析可指定各角色模型。AI 输出与人工修订分别保存；飞书和 Git 复用任务内核及不确定写入对账，并提供统一连接器协议。

## 分开看待不同验证层

- 自动纪要首次在启用约 10 秒后、存在确认转录时排队；空白纪要会先显示生成中的文字，完整结果仍需结构与引用校验。重新整理保留已校验内容并显示局部状态，重点速览只展示当前重点。
- 长转录与译文每次挂载 60 段，可分页并搜索完整转录。暂停阅读和编辑时固定位置，最新内容可手动跟随。
- SQLite 高频集合、全文搜索及目录查询采用独立存储／投影；旧库首次迁移前自动备份。浏览器队列存储二进制音频，桌面本机优先提交 API 回执。详见[存储与性能边界](storage-and-performance.md)。

合成测试覆盖协议、SQLite 持久化、权限与任务恢复、渲染、安装包契约。原生 CI 分别验证 macOS、Windows 和 Ubuntu；Linux/Windows 安装包在 WGS 当前代码目录构建，macOS 在 GitHub Actions 构建。

浏览器原生采集、Postgres/S3、真实 ASR/LLM 的内容质量、供应商网关延迟、实体设备音源与长会话需要各自证据。词语候选和引用不能保证模型理解正确；新规则不会自动重处理已有纪要。

## 查找当前约定

使用、配置与运维入口见[文档导航](../README.md)。实现依据以当前源码和自动化检查为准；临时设计和过程回执保存在 gitignored `.agent-runtime/`，不混入产品说明。

首页 Token 活动图覆盖滚动 365 天，按实际模型请求回执时间（UTC+8 日界）统计。纪要、会议助手、自动任务、翻译、意图、项目分析及返回 Token 的音频模型使用同一请求账本；重试分别记录，流式累计回报取最大值，不重复累计父任务复制的子用量。计量切换前无可靠回执的历史不补造，未知显示破折号，部分上报用量以 + 标识。自动化侧栏保留紧凑任务行、异常状态和分页。

历史纪要中已保存的实际用量会与请求账本衔接。旧任务缺少逐次调用时间时，按任务创建至最后用量事件限定日期范围：同日回执进入热力图，跨日回执仅计入完整包含该范围的周期；跨升级续跑扣除新账本已知回执，缺失部分仍为未知，不生成每日估算。Token 活动采用系统配色的相对深浅分档，固定显示所选日期及紧凑用量。

主题按钮独立更新配色与原生外观，避免重新渲染整份会议；设置主界面随入口加载。转录主题只引入一次，声纹栏标题和保存区固定，中间内容独立滚动。

官网包含按系统选择的下载 tab；独立安装包通过官网同源地址从既有存储/CDN 提供，支持断点续传与摘要核对。该入口需要先配置实际下载源并发布完整版本目录，详见[官网下载运维](website-downloads.md)。源码实现、存储配置与公网验证分别核对，不能把本地合成下载视为已部署。
