# Pi 会议 agent 运行底座：本地接入

2026-10-31。用户已授权接入，明确要求「Pi 只是 agent 运行底座，现有所有能力继续保持」。本轮接通首条会议复盘任务链路；结果独立保存，不覆盖原会议纪要。仅本地，未推送、发布或替换已安装客户端。

## 当前实现

- 固定 `pi-durable`、`pi-ai`、`chord` 1.4.0，继续使用 Node 26.12.1。
- 新增真实扩展中心。会议助手确认所选文字及模型发送授权后，创建任务；任务页展示实际队列、执行、取消、失败和带引用结果。
- Pi Task 是调度、等待依赖、检查点、取消与恢复的事实来源。宿主没有第二套 worker 队列或任务状态数据库。
- 内置 `meeting-review@1` 仅注册 `read_selected_meeting`，没有编码命令、文件系统写入或外部发布工具。
- 模型桥复用既有 `completeModelJson` 适配层及模型配置；Pi 调用工具后再生成独立复盘。未配置模型明确失败，不静默切换 mock。
- 范围为 1–8 场会议、目标 1–2000 字、冻结材料总计不超过 60000 字符。超限明确拒绝。

## 现有能力保持

原有录音采集、传输/补传、转录、滚动与实时纪要、音频纪要、翻译、人工编辑、来源引用、笔记、导出、分享、学习评审、目录分析及客户端能力继续沿用既有模块和入口。没有将它们改成复盘 Skill，也没有移除既有 Provider。

`App` 只增加中心入口与按需加载；离开中心后恢复原会议页面。Pi 初始化失败仅影响 agent 接口（503），`bootstrap`、会议读写等原有服务继续运行；该故障路径已通过 HTTP 回归。

## 持久化与权限

`Record` 后端数据目录下新增：

- `meeting-agent.sqlite`：根 Pi 调度与授权/幂等索引，不含目标文字、会议标题、正文或结果。
- `meeting-agent-jobs/<jobKey>.sqlite`：每任务独立 Pi 会话，保存冻结材料、目标、工具上下文与结果。
- 单写者锁：同一数据目录只允许一个 agent Harness；私有任务 Harness 连正在打开的 Promise 也按 key 复用。

宿主在提交、工具读取、完成及 API 读取时核对所有权、删除/到期与版本。结果引用必须指向选定会议的真实片段与修订；来源变化标记 stale，人工纪要不会被覆盖。

相同 owner/requestId/内容返回原任务；不同内容使用同一 requestId 报冲突。取消显示实际 Pi 状态，模型请求收到 AbortSignal。崩溃恢复延续已提交检查点；只读模型请求在未提交边界可能重试并重复计费，不承诺外部调用 exactly-once。

启动、运行中默认每秒及 API 操作前检查来源。来源删除、到期或所有者变化时取消相关任务，关闭其 Harness 并删除私有 DB/WAL/SHM/journal；根保留无文字墓碑维持幂等。有效任务不被清除。逻辑记录和文件清理已验证，不等同于 SSD 擦除或备份删除。

## 接口与运行

沿用原 `/api` 认证和 CSRF：

| 接口 | 行为 |
| --- | --- |
| `GET /api/agent/tasks` | 当前账户任务 |
| `POST /api/agent/tasks` | 确认范围后提交，返回 202 |
| `GET /api/agent/tasks/:id` | 状态与独立结果 |
| `POST /api/agent/tasks/:id/cancel` | 原生取消 |

启动方式仍为 `npm run dev`；点击「扩展中心」，或开发/生产 Web 地址加 `?agent=1`。不需要启动独立 agent 服务。

旧的未发布单库实验格式不能自动转换，明确返回 `agent_storage_upgrade_required`，原会议功能继续可用。本轮旧格式仅用于临时合成实验，未处理用户数据目录。

## 当前边界

- 当前是内置会议复盘。外部 Skill 安装、MCP 连接、插件进程与自动化触发仍未接入；正式页不展示假安装、假连接或假任务。
- 当前可读结果在完成后显示，运行中没有可读流式草稿。不能把状态轮询称为模型文字流式。
- 飞书云文档导出方向保持，画板仍是云文档组件；本轮没有新增真实飞书外发。
- 新生产依赖展开增加约 72.62 MiB；未构建发布安装包，压缩包增量未测。后端准备脚本从根生产依赖递归复制，隔离目录启动已验证。
- 本轮核对发现原有 `protobufjs@8.0.0` 审计告警，基线与本轮版本相同，未作为 Pi 接入顺手升级。见验证记录中的适用前提与遗留项。
