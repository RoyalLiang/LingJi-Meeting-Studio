# 纪要完整性与说话人编号

2026-10-29，本轮实现。此前版本的“窗口处理完成”只说明输入窗口跑过，不能说明汇总保留了全部讨论。用户反馈所有版本均存在内容过少，本轮不再以某个旧版作为已知正确基线。

完整纪要在新任务运行期间继续显示；没有完整文档时才展示已验证的初步结果。人工修订优先。笔记或模板变化导致全量重算时，停止录音不会将首窗结果提升并替换旧完整文档；后台继续整理终稿。

多窗模型汇总保留最终结论及当前行动，同时在正文保留叶窗口中经过校验的讨论细节。项目标题、条目标签、主题提要、表格整行和时间线内容保留上下文；历史讨论以过程记录展示，不重新生成当前待办。纠错顺序依据各窗口的新证据，邻接上下文不能抬高旧纠错的时间。保留内容在最后本地合并，不再次送进模型；原输入预算、分窗缓存和层级汇总策略保留。

本地提取不再只保留前12段，也不会因命中一个行动而漏掉普通事实。多窗合并保留全文，当前规则行动候选仍按全文最近50项的既有规则产生。模型返回合法JSON但报告长度截断时也会失败，不提交残缺终稿。最终模型行动数量和证据权限校验没有放宽。

纪要中的说话人只显示“说话人1、说话人2、说话人3…”。正文、表格与发言人总结共用编号；不改写逐字记录或原有身份数据。没有可靠身份的内容仍显示未区分说话人，不推测归属。树形卡片的字体、颜色、圆角和间距未重新设计；表格来源图标恢复在各自行中显示。

已保存的短纪要不会仅因升级而自动扩写。打开对应会议并选择重新整理，可利用已有且仍有效的窗口缓存重新合并；缓存缺失或转录、配置变化时，需要重新调用模型。人工修订有既有确认保护，不能由后台自动覆盖。

本地验证包含结构化桩、完整应用界面及真实配置模型处理虚构文本。它们不能保证ASR本身没有遗漏，也不能证明模型在叶窗口中提取了所有语义事实。真实音频、70分钟现场会议及用户原记录重新整理的结果仍需现场验收。
