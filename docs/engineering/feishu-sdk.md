# 飞书协同：官方 SDK 长连接

v0.2.13 仅支持企业自建应用的 SDK 长连接与应用身份导出。用户授权、回调地址和公网中继已移除。部署与真实企业验收不由源码状态代替。

## 配置与开关

1. 在飞书开发者后台的企业自建应用中开通以下**应用权限**，发布版本并确认应用可用：

   ```text
   docx:document:create
   docx:document:write_only
   docx:document.block:convert
   drive:drive.metadata:readonly
   board:whiteboard:node:create
   docs:permission.member:transfer
   ```

2. 打开聆记 **扩展中心 → 自动化 → 协同工具**，点击飞书卡片填写 App ID、App Secret。只在本机输入 Secret。
3. 保存后能力自动启用，后台建立并保持长连接。飞书旁的绿色圆点表示 SDK socket 已连接，黄色表示连接或重连，红色表示异常；停用或未配置时为灰色。将指针停在圆点上可查看状态。
4. 在飞书 **事件与回调** 中选择截图所示的 **使用长连接接收事件**，验证并保存。无需重定向 URL、Webhook 地址、Verification Token 或 Encrypt Key。
5. 卡片右侧滑块停用后，连接和外发停止、凭据保留；重新启用会自动连接。应用退出会关闭 socket，重启后恢复已启用能力。

## 导出与权限

在会议 **导出 → 飞书云文档** 中预览范围，再确认新建文档。自动导出需另行确认未来最终纪要的发送范围；相同凭据保存保留已确认规则；修改凭据或停用后重新启用能力会使旧确认失效，避免补发已有会议。

文档归应用。创建接口支持的目标目录须由应用创建；留空写入应用根目录。请提前配置协作者或目标位置权限，个人用户可能无法打开应用根目录中的文档。选择“成员云文档”并填写成员飞书邮箱后，确认导出会在正文与可编辑画板写完后，将所有权转给该成员并移入其云空间。需要 `docs:permission.member:transfer`，且受企业策略与成员可见性限制；未选成员时不转移。

当前导出包含最终/会中纪要和勾选的原生纪要画板、笔记、引用，不含录音或会议助手的独立分析。写入成功的响应与文档 metadata 核对是本流程的验证层，不代表已验证所有个人账户的阅读权限。

## 界面反馈

协同卡片只显示工具名、健康圆点与能力滑块；连接详情通过圆点提示查看。导出执行后只显示当前阶段，完成后显示“导出完成”与文档入口。外发确认前仍显示冻结内容和目标范围。错误使用单行悬浮 toast，不占用布局；后台保留完整回执。

## 生命周期与性能

使用固定版本的官方 `@larksuiteoapi/node-sdk`，由 SDK 建立 WebSocket、重连，并以应用身份获取、缓存和续取调用令牌。长连接负责连接和事件通道，文档写入走同一 SDK 的 OpenAPI 客户端。

SDK 仅在配置了飞书能力后加载。后台恢复启用状态，前端离开或隐藏不会停止连接；配置页仅在前台轮询状态。关闭、配置变化和服务退出都会取消旧初始化及请求，过期操作不能关闭新配置的连接。

本机只持久化加密的 App Secret；旧用户访问/刷新令牌在迁移时清除。安装包不内置共享凭据。原中继资源退役不改变其他官网、分享、DNS 或数据服务。
