# 加密同步测试环境

此流程供 0.4 开发分支测试使用。从桌面侧栏底部的「本地空间」使用邮箱和密码注册或登录。新账号首次登录时，客户端自动创建加密资料库。之后在手机、网页或桌面用同一账号登录，即可自动解锁同步。

旧账号在能访问历史会议的设备上打开「升级账号，登录即同步」，验证当前密码并设置新密码。升级保留原资料库和会议密文，其他设备需更新客户端并用新密码登录。旧账号可用通行密钥、可信设备配对或恢复密钥先解锁。

在线后从「本地空间」登录并进入「个人中心」，可设置显示名称和当前设备的外观。启用「自动同步本机已完成的会议」后，客户端在后台同步这台电脑已完成会议的转录、纪要和手记，包括后续修订。收到的会议版本可选择恢复到本机。

设备解锁密钥加密保存在当前应用的数据配置中。云端保存密文和账号验证记录。OPAQUE 登录在客户端生成用于解开资料库的密钥材料。清除本机应用数据后，重新登录即可解锁已升级的账号。「备份与恢复」提供备份入口。普通桌面会议的原音、截图、连接器密钥和声纹数据保存在设备上。
## 启动独立的 HTTPS 实例

测试域使用 `https://lingji.rookiehouse.com`。DNS 指向独立同步 API 的 HTTPS 入口。反向代理只把这个域路由到独立 Web 服务，保留原始 `Host`。云端使用单独的 PostgreSQL 和记录目录，使用运行环境的 secret 注入方式配置数据库地址和会话密钥。

```sh
export NODE_ENV=production
export RECORD_SYNC_ORIGIN=https://lingji.rookiehouse.com
export RECORD_DATA_DIR=/path/to/isolated/sync-data
export RECORD_API_PORT=3030
export WEB_PORT=3000
export RECORD_API_URL=http://127.0.0.1:3030
npm run build:web
```

用独立进程分别运行 `npm run dev:records` 和 `node apps/web/src/production-server.mjs`。两个端口均监听本机，HTTPS 代理转发至 3000。同步服务不需要启用录音或转录 worker。生产模式启动时要求 `RECORD_DATABASE_URL` 和 `RECORD_SESSION_SECRET`。

同步 API 使用单实例。登录挑战由进程暂存，服务重启后进行中的登录需要重试。将 `RECORD_DATA_DIR/opaque-account.key` 纳入受限备份，与账号数据库一起恢复。该文件丢失会导致已升级账号无法通过密码验证。

## 在两台设备间验证

1. 在桌面「本地空间」中注册并同步一条合成会议。在空白客户端登录同一账号，确认自动解锁并可恢复该会议。用同一账号打开手机「快速记录」，确认登录后可直接开始录音。
2. 在测试域的浏览器登录后展开「备份与恢复」，选择「信任此浏览器」。锁定当前会话，再选择「验证此设备」。服务端验证 WebAuthn 的来源、RP ID、一次性挑战和用户验证。浏览器使用 PRF 派生密钥，仅上传包装后的密钥和公开凭据材料。若凭据不支持 PRF，可以用旧设备配对或恢复密钥解锁。[WebAuthn PRF](https://www.w3.org/TR/webauthn-3/#prf-extension)
3. 打开 macOS 桌面工作台，登录同一账号并同步一条合成会议。在「备份与恢复」中选择「配对新设备」。在 Windows 登录同一账号，展开「从旧设备配对」，读取二维码图片或输入配对码，再回到 macOS 确认访问。密钥用 OPAQUE 导出的会话材料包裹，中继按账号保存临时密文及握手帧。[OPAQUE RFC](https://www.rfc-editor.org/rfc/rfc9807.html)
4. 在 Windows 恢复该会议，核对转录、纪要引用和手记。用一个没有该本机数据目录或通行密钥的干净设备再验证 Recovery Kit，并确认用错密钥时会拒绝。

## 开发分支范围

客户端把选中的会议修订加密后存到本机待传队列，网络中断后可重试。服务端在同一账户的行锁内分配序号，按记录个数和字节限制分页。接收设备验证密文后，在一个本机事务中保存操作并推进游标。对同一会议各自编辑形成的并行修订可分别恢复。

客户端按需重试和拉取更新。同步保留逐次快照与分支修订。自动上传由本机个人中心开关控制，已有会议的恢复需要用户选择。设备单独撤销、换钥、云端历史清理及桌面会议原音同步仍待完成。

## 手机快速记录

用手机打开测试域的 `/quick-record`，从 iOS 的「添加到主屏幕」或 Android 浏览器的安装菜单添加应用。使用与电脑相同的新账号或已升级账号登录，即可开始录音。在设备首次成功加载后，断网时也可打开录音页。每次录音最多 5 分钟，结束后手机先加密保存，再在应用打开且联网时自动补传。

已登录且解锁的 PC 客户端会拉取录音，在本机解密并导入记录，并使用本机 SenseVoice 转录。打开该会议可以生成纪要、核对引用并按现有权限执行操作。向模型或外部工具发送数据仍按相应功能的授权。手机录音使用独立密文日志，试点上限为每账号 64 MiB 密文。
