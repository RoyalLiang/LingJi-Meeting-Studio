# Pi 版转录、纪要与重点全链路验证

2026-10-31。本地候选，未推送、打标签、发布或替换已安装程序。

## 结论与基线

将 Pi 研究提交 `b8dbdec` 与最新主线 `2a8275d`（v0.2.6）整合后，完成转录→滚动/最终纪要→重点→引用→原音访问→Pi 独立复盘的分层验证。当前样本和回归门禁内未发现未修复的功能或性能退化；这不等于全部供应商、真实设备和长会议已验收。

先前 Pi 研究分支落后主线，缺少主线的重点速览等近期实现，403 项旧测试不足以证明这些能力保持。本轮使用独立工作树 `dev_pi-chain-regression-20261031` 接入完整主线。原工作区的 IDE 和播放实验改动未纳入候选。

Pi 继续只管理 agent 任务。既有转录、纪要 worker、重点生成、播放、导出与分享流程沿用主线；复盘结果独立保存，不能覆盖原纪要或自动外发行动。

## 修复与覆盖

1. 恢复录音时扩展中心可能仍遮住会议工作区。在既有采集守卫通过后关闭 agent 中心，恢复会议控件。原生菜单/暂停恢复测试先失败再通过。
2. Pi 已完成任务的保留期检查曾每秒加载完整会议。改为批量读取轻量访问元数据，并以事务写入版本标识复用指纹计算；真实正文变化仍精确判定引用是否过期。无事件写入、删除、过期、归属变化和记录类型变化均有回归，保留权限收回与清理语义。2.2 秒空闲观察的整篇读取从 2–3 次降到 0，四次修复后观察均为 0。
3. 保留主线新功能，合并 Node 26 不兼容的测试转译入口及采集 fixture，未改变转录/纪要供应商行为。

## 性能对照

同机、同 Node 26.12.1，对照固定主线 `2a8275d`；本地小样本，不是生产 SLA。门槛在运行前声明，没有事后放宽。

### 宿主和调度

两轮交错执行 baseline→idle→loaded / loaded→idle→baseline，各路每轮预热 2 次、测量 12 次；供应商注入固定 15ms 延迟。真实仓库/worker/重点持久化，Pi loaded 路径同时运行 agent。以下为两轮较差的 p95，单位 ms。

| 指标 | 主线 | Pi loaded |
| --- | ---: | ---: |
| 服务就绪，已导入模块后 | 9.61 | 9.71 |
| 健康检查 HTTP | 1.66 | 1.75 |
| PCM 持久 ACK，域内调用 | 16.32 | 17.02 |
| 转录持久化 | 25.58 | 27.98 |
| 纪要与重点持久化 | 20.00 | 19.72 |
| 完整处理链 | 59.07 | 61.29 |
| 扣除供应商等待后的宿主开销 | 25.65 | 28.52 |

14 项时延检查及 1 项空闲读取检查共 15/15 通过。PCM ACK 这一项测量域内持久操作，不能称为 HTTP 上传耗时；真实 HTTP 上传另见下表。模块冷导入为主线约 39–41ms、Pi 约 127–134ms，即增加约 90ms；该成本单列，不能用服务就绪行掩盖，也不宣称 Pi 零开销或提升模型速度。

### 真实 SenseVoice ASR

相同模型、相同三段 PCM hash，经 loopback HTTP 上传→seal→原生 worker→转录持久化。两轮 AB/BA，各路径 2 个独立进程，每个进程 1 次冷样本和 4 次暖样本，总计每路 2 冷 + 8 暖。禁用自动纪要，不调用云端模型。

| 指标 | 主线 | Pi 候选 |
| --- | ---: | ---: |
| 暖 ASR p50 | 158.65 | 153.80 |
| 暖 ASR p95 | 163.30 | 161.17 |
| 冷 ASR，每进程首次调用范围 | 915.08–1053.95 | 895.10–986.89 |
| 暖 HTTP 上传 p95 | 11.18 | 12.15 |
| 暖上传至转录持久化全链 p95 | 196.15 | 191.83 |

4/4 预声明门禁通过，20/20 次结果逐字一致。差异在当前样本的调度/温度噪声范围内，不宣称加速。此前单次 1341/905ms 的冷暖混合观察不能用于性能结论。
