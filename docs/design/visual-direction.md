# 会议工作台的视觉方向

状态：用户已确认，纪要改为按需展开侧栏。2026-10-11。

使用 taste skill 的排版与细节约束，由 finesse-ui 的 product register 决定工作台结构。页面围绕录音、阅读转录、核对纪要展开。

你会看到：浅青灰背景、深墨色文字、松绿色主按钮。导航和工具栏使用半透明磨砂玻璃，长文本区提高底色不透明度。桌面采用左侧记录列表和主转录区，纪要由按钮按需展开；窄屏切换为单栏和底部操作区。深色主题采用青黑底色。

动态：录音时显示轻量声量反馈；保存、切换和展开使用短过渡。尊重减少动态与减少透明度设置。没有持续漂浮背景、滚动表演或自动轮播。

图片：无需摄影或装饰插画。可读的转录、来源状态和纪要证据就是主内容；图标采用组件库。

两个可能需要调整的方向：若浅色不适合长时间会议，可默认深色；若三栏显得拥挤，可把纪要改为按需展开的侧栏。

这是本项目首次 finesse 设计，没有既有轮换记录。设计坐标：product / sage + jade / floating workbench / feedback motion / frosted glass；SOUL=6，SPECTACLE=2，DENSITY=5。

验收：键盘可操作；焦点可见；录音/断网/失败状态不只依赖颜色；小屏不出现页面横向滚动；浅深主题对等；透明度关闭后仍有明确层级。关键录音按钮与长文本区域保持稳定对比度。
