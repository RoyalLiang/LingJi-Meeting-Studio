# 会议工作台的视觉方向

状态：沿用已确认的 sage/jade 视觉体系；2026-10-12 核对当前实现。主阅读区为智能会议纪要，实时翻译按需打开次级面板。

保留浅青灰背景、深墨色文字、松绿色主按钮和现有标识。导航与工具栏使用半透明磨砂玻璃，长文本区提高底色不透明度；深色主题使用青黑底色。字体沿用 Avenir Next、Segoe UI 与中文系统字体，正文以 14px、1.65 行高为基础，标题保持既有层级。设计坐标仍是 product / sage + jade / floating workbench / feedback motion / frosted glass。

**主阅读规则。** 桌面保留左侧会议列表，右侧容器顶部中央使用宽搜索框；主阅读内容依次呈现录音控制、紧凑纪要工具栏、连续主题树和引用表格、人工笔记。当前讨论固定在主容器底部，与阅读内容独立滚动。实时翻译使用次级面板，窄屏独立打开；表格在自身区域内横向滚动。

**证据规则。** 表格行和纪要结论提供原文来源。图表只表达实际纪要条目数量与引用覆盖，不用装饰性统计。当前讨论区在等待 agent 时显示轻量动效，随后显示模型草稿或已归纳要点；不以逐字转录或识别草稿替代模型总结。

**阅读跟随规则。** 会中更新可自动滚动；手动向上阅读、编辑或查看来源时暂停，并提供明确的恢复按钮。选择器只有选中项使用强调底色和勾选，悬停使用较弱的中性色，键盘焦点保持可见。选项之间保留 8px 留白，按钮悬停以底色反馈，避免额外阴影延伸到相邻块。菜单宽度和文字左边缘与触发框对齐，长目录名最多显示两行；归档目标与操作按钮之间保留明确间隔，手机按钮等宽排列。

保存、切换和展开使用短过渡，录音时保留轻量声量反馈。尊重减少动态与减少透明度设置。界面无需摄影或装饰插画；纪要、来源状态和证据是主内容，图标沿用组件库。

验收要求：键盘可操作；焦点可见；录音、断网和失败状态不只依赖颜色；小屏不出现页面横向滚动；浅深主题对等；关闭透明度后仍有明确层级；关键录音按钮和长文本保持稳定对比度。当前实现与验证边界见[智能纪要说明](../engineering/intelligent-minutes.md)。
