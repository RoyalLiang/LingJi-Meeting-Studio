# 纪要悬浮卡片与桌面细节修正

来源：用户对本任务交付前自审的追加要求，基线 `af6d800abfac51c56c8e638198801ab676ff4939` / v0.2.2。用户确认“1 分半”指自动纪要刷新间隔 90 秒。这里列验收目标，不代表所有平台已实测。

1. 重点速览覆盖在阅读区顶部居中，宽度为阅读区扣除两侧安全间距；开关不改变正文滚动区的位置、高度或滚动位置。
2. 自动纪要新会议默认 90 秒，前后端缺省一致；支持显式 90 秒，保留已有 15/30/60/120 秒选择及原来的首批早整理、暂停排空与终稿规则，不改旧记录的显式配置。
3. 会议重点入口是右侧垂直居中的 44px 图标按钮，打开卡片时淡出、关闭后淡入；隐藏时不能被点击或键盘聚焦。保留 Escape、关闭和焦点恢复，减少动态效果偏好生效。
4. macOS 菜单栏图标由 22pt 缩至 18pt，Windows/Linux 托盘资源和行为保留。
5. 移除“新发言已接收”等健康状态说明文字，保留真实识别、模型配置及处理失败提示。
6. 左侧版本号靠近顶部品牌标题；移除设置中的“当前已是最新版本”行，保留更新动作、下载进度与失败处理。
7. 设置中选定会议的“备份待传音频”入口保持稳定，不随每个包的排队/上传归零卸载；为空时给准确的无待传提示，不下载空文件、不声称服务端已保存、不删除队列内容。
8. AI 视图和只读正文不显示仅用于留证的“过程记录”项或空的讨论过程分支；修订编辑与持久化证据保持完整。
9. 缺少冻结快照时可从当前转录的精确片段修订恢复可靠说话人编号；有冻结快照时仍以冻结身份为准，不把新修订身份套到旧引用。缺少可靠身份或混合未知来源时不重复显示未知标签，也不编造声音身份。这里不新增本地声纹/分离模型。

验证：修改前实际 App 卡片占用约 280px 并令正文下移约 320px；目标为零几何变化。用 ego lite 实际 App 夹具核对桌面、窄屏、深色、按钮过渡与备份入口；执行回归、类型、lint、构建、原生 Mac 和独立评审，再通过既有后台 Actions 发布。当前任务已完成一次交付前自审并收到上述追加要求，不重复门禁。
