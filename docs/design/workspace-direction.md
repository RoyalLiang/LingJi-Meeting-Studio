# 工作目录首页方向

沿用已确认的松绿、浅青灰、玻璃导航与高不透明度正文区。用户已选择现有“声音成章”PNG 作为系统标识，不生成新的 logo。

首页在现有工作台内展开：顶部显示工作目录名称与新建/归档入口；一条紧凑统计带展示会议数、会议时长、纪要覆盖；中间展示近 30 天活动与主题分布；下方呈现历史摘要、关键决策、行动候选及最近会议。所有内容回链到原会议，空目录不展示虚构数据。

左侧增加工作目录选择与目录首页入口；旧会议默认未归档，可逐条或批量移动。手机采用单列，图表保留日期与数值说明。页面右侧提供回到顶部，纪要展开时避开侧栏。

AI 跨会议分析按需启动，显示处理状态、输入覆盖与可取消的流式草稿；统计与已有纪要汇总在未连接模型时也能使用。不会把本地汇总标为 AI 生成，不把行动候选标为已完成任务。

需要注意：少量会议时图表应保持克制；大量历史记录时必须明确分析覆盖范围。图片仅使用已选标识，其他内容以真实统计、图表和文本呈现。

设计坐标沿用产品工作台：sage-jade / humanist-system / floating-workbench / feedback-only / frosted-glass，SPECTACLE=2，DENSITY=6。作为同一产品扩展不轮换整体视觉。
