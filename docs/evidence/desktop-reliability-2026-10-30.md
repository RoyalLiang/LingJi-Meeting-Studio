# 桌面保存、设置、启动与悬浮框修复证据

状态：v0.2.2 已通过 GitHub Actions 发布，三平台安装包及更新清单完整下载核验通过。[发布回执](preview-v0.2.2-2026-10-30.md)。隔离工作树基于 v0.2.1 产品代码，原目录的 IDE 和播放实验未修改。[本轮范围与验收](../design/desktop-reliability-2026-10-30.md)。

## 已复现与已实现

- 旧 GET 快照可覆盖较新记录；旧结束响应也可直接绕过缓存，覆盖已经确认保存完成的事件。两种竞态均在实际 App 函数中复现，再改为完整快照统一按 cursor 接受；已清理状态同样防止回退。新增记录也进入相同缓存，避免切换时短暂丢失刚创建的记录。
- 默认列表在 bootstrap 已读取，却未用于显示，随后又经 180ms 防抖请求一次。现在直接显示该列表并跳过首次重复读取，筛选和目录切换保持实时请求。该收益属于三端共享前端，不能推算成三个平台的完整冷启动时间。
- 悬浮框麦克风图标与开启状态相反，实际组件回归由失败转通过；补测禁用和超过一小时的时钟。
- 设置中的服务、词表、设备表单采用 React memo 边界，保留组件自身的状态和更新。浏览器真实组件的合成父级刷新对照见下。
- 窗口缩为 340×42，工作区顶部 16 逻辑像素居中，保持原有置顶，移除拖动入口。纯几何测试覆盖负坐标显示器和 2× 缩放；原生冒烟增加实际宽度、顶部间距、中心偏差及人为移位后的恢复检查。复用既有每秒状态同步按工作区重算，位置不变时不写窗口位置，不新增计时器。首次跟随主窗、显示后跟随可见悬浮窗所在屏幕，避开 Linux 隐藏窗口的显示器查询回落主屏差异。
