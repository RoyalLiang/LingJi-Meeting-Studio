# v0.1.34 波形、设置与渲染本地验证

日期：2026-10-28，Asia/Shanghai。延续 v0.1.31 交付前自检后的用户修订；保留远端 v0.1.33 多语种及词表功能。源码与三平台发布状态以本轮发布回执为准。

## 波形与数据边界

同一合成 50 分钟、2500 个对象、固定每次读取延迟的 helper 对照：串行约 5867ms，八路约 858ms。真实本机 HTTP 服务另生成 2500 个独立压缩对象，共 91.55MiB 原始 PCM：首次 486ms、读取 2500 次；再次请求 10ms、读取 0 次。返回 192 个真实峰值；未用占位波形，也没有提前加载完整 WAV。

随机 PCM 与旧算法逐峰值一致；领先静音、读取异常、取消、缺块、权限与留存检查保留。缓存不出现在公共记录投影，音源/偏移变化会失效；重启可复用，删除与过期会清理。独立复核补测计算期间删除、到期、关闭原音留存、音源变化和手写笔记并发，无阻断。

这些是本机合成数据，不代表用户原 Windows 录音的实际耗时。

## 界面与更新

真实 App 组件与本地合成 API 的隔离浏览器验证：红色删除按钮最右、模板空态说明已移除、诊断图标位于标题右侧、字段同行、保存配置位于底栏最右、390px 无横向溢出；保存成功且没有页面异常。更新界面使用模拟原生状态检查单按钮、下载未就绪置灰及就绪标签；没有真实安装。

控制器单测验证显式操作可串联检查/下载/安装且双击不重复，安装仍经过录音和补传门禁；后台策略不会触发安装。独立设置、更新与波形回归 30 项通过。

## 渲染对照

相同合成页面、Chrome DevTools Protocol、同段两秒播放；Windows WebView2 样式由测试标记启用。不是原生 Windows GPU 内存计量。

| 指标 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 页面 DOM 节点 | 1098 | 716 |
| 波形矩形节点 | 384 | 0（改为两条路径） |
| 暂停后的合成层 | 22 | 13 |
| 暂停后的 will-change 合成原因 | 4 | 0 |
| 两秒样式计算 | 131ms | 16ms |
| 采样帧/停顿 | 121 / 0 | 121 / 0 |

缓冲边界红测先复现 `seeked` 错误重启动画，修正后就绪状态 2 时动画保持关闭、200ms 游标位移 0。暂停拖动结束边界先复现合成层未释放，显式拖动状态修正后 `data-animating=false`、`will-change=auto`；独立复验通过。

保留硬件加速，避免强制禁用 GPU。策略参考 [Microsoft WebView2 性能文档](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/performance)。本轮未增加运行时依赖、未改后台录音 Chromium 参数。
