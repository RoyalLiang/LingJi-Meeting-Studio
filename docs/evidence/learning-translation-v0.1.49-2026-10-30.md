# v0.1.49 学习评审、翻译与播放验证

实施基线为 v0.1.47 源码 `5c4e154743bf5dd4f8726f0af4d311a451acf7a2`；发布前合入 v0.1.48 安装器编译修复 `44d5941`。本轮在独立工作树实施，原工作区的 IDE 与播放实验改动未纳入。用户已确认按新版全流程设计实现，设计存于 `dev_learning-translation-design-20261029` 分支提交 `890f99e` 的 `docs/design/prototypes/learning-translation-20261029.html`。

## 已确认原因与修复

| 范围 | 原因与改动 | 验证证据 |
| --- | --- | --- |
| 学习服务 | 原入口仅按开关启用，后台缺服务仍入队失败。现在异步探测既有 SSH 目标的模型、运行时与依赖，30 秒缓存并合并并发探测；启动与普通 bootstrap 不等待探测。所有学习写入复核可用性；后台暂不可用延后重试，不消耗训练重试次数。 | 缓存、恢复、HTTP 503、无变更和延后重试测试。 |
| 待标注速度 | 旧准备路径等待二次识别、教师标注及基线推理。准备专用路径直接冻结原文候选与原音，不运行这些 GPU 步骤，保留 tokenizer 预算、哈希与输入身份校验。 | 准备路径测试确认无需教师或预测文件即可完成；不虚构实测秒数。 |
| 评审流程 | 复用标准 Modal、Button、Select 和 AudioPlayer；分组核听原音、五类意图、暂存、跳过、保存下一段、草稿关闭保护、训练前确认及真实样本计数。未标注的盲测样本隐藏模型答案。 | 合成会议 6 段、36 项任务，保存首段后进度变为 1/6；训练计划仅显示已存 1 条转录与 5 条意图，未运行训练。 |
| 实时翻译 | 历史翻译串行处理会阻塞新发言。当前 ASR 预览、最新确认句与历史翻译采用独立通道，慢确认句也不阻塞当前发言；预览最多每 2.5 秒发起，8 秒超时。租约、原文、语言、转录版本及 epoch 校验阻止过期写回。临时译文独立存放，不进入正式转录、纪要与训练。 | 原文追加、修订、新发言、暂停、切换目标、历史与最近确认句阻塞、确认句复用、失败句重试与过期请求测试。 |
| 分享 | 弹窗、HTML 导出、共享页面及服务输出统一为纪要。旧 full 链接也只返回纪要；新 full 请求被拒绝。冻结引用文本及共享 segments 不再输出。 | 新旧链接、输出字段、导出及原文抑制回归。已下载或转存的旧导出文件不能远程撤回。 |
| 播放进度 | 约 80ms 的媒体时钟回退曾把显示时钟重置到旧位置；两层相反 SVG 位移也增加边缘重绘。保留静态波形，采用裁切推进，仅明确 seek 或大幅偏差才重置时钟。 | 确定性负向抖动测试；合成原音可播放，DOM 中波形保持固定位置。实体 GPU 合成器是否消除用户可见闪烁尚无结论。 |

## 本地验证

Node 24.19.0（SQLite 3.53.3）运行 692 项回归全部通过；ESLint、TypeScript 和 Web 构建通过。系统 Node 22.14.0 的 SQLite 过旧，不作为桌面数据库验收环境。Web 构建仍有既有大分块提示。

真实产品页面以独立合成数据启动，核对桌面 1440×1000、手机 390×844、深色主题、服务失联禁用与自动恢复、标注保存及关闭保护、训练确认、仅纪要分享、翻译暂停后关闭重开和实时原文区域。窄屏文档宽度与视口同为 390px，无水平溢出。测试没有访问真实会议、调用真实模型或启动训练。

截图保存在本轮 Codex 可视化目录，文件名为 `implemented-learning-review.png`、`implemented-learning-mobile.png`、`implemented-learning-dark.png`、`implemented-learning-plan.png`、`implemented-share.png`、`implemented-translation.png`、`implemented-translation-mobile.png`、`implemented-service-unavailable.png`。它们是合成页面证据。

## 验证边界

真实 ASR 与翻译服务时延、学习 GPU 准备耗时、长会议资源用量、用户机器 WKWebView 的逐帧播放均未测量。实时预览会增加翻译请求，采用节流与超时限制，但这不证明供应商流式翻译。CI 原生测试、三平台构建和公开附件状态另记发布回执。
