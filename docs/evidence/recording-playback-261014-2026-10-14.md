# 261014 原音回放修复

当前 Alpha 17 的回放入口和 HTTP 原音接口都要求 `capture=completed`。会议封存后，`completed` 还需要全部 ASR 片段处理完成，因此完整保存的原音也被转录队列阻止。隔离回归复现了入口不可用和 HTTP 404；修复后，封存且完整持久化的音轨即可回放。

## 只读实际会议证据

261014 的状态是 `sealed` / `processing`，原音留存开启、没有清理，留存尚未到期。麦克风的 1,862 个音频对象和会议音轨的 1,861 个音频对象逐个通过解压、内容散列及样本长度检查，总计 3,723 个；无缺失、损坏、序列缺口或样本偏移间断。两源均已停止，持久化 watermark 与封存 lastSequence 一致。本机 Record API health 返回 200。

麦克风音轨包含 29,776,000 个 16kHz 样本，会议音轨包含 29,762,901 个样本。本轮没有播放、导出或外发真实会议音频，没有调整会议捕获或转录状态，也未调用真实供应商或重启当前客户端。

## 修复与验证

- 界面和 HTTP 接口均改为检查录音已停止、音轨完整持久化，不再依赖 ASR 完成。空音轨或缺包音轨仍不可播放，已经完整保存的另一音轨不受影响。
- 认证、所有权、到期、原音留存及清理限制保持生效。HTTP 另外核对音频序列与样本偏移连续性。
- 异步读取返回后重新检查响应是否关闭；取消或拖动切换后不写旧响应，背压等待会清理对端监听器。该取消回归在修复前观察到一次关闭后写入，修复后为零。
- 6 项定点回归覆盖 ASR 尚未完成时读取 WAV、Range 请求、取消读、缺包、留存、清理和认证；完整 290 项 Node 回归、ESLint、TypeScript 与 Web 构建通过。
- 浏览器使用两分钟静音 WAV 和与实际问题一致的 `sealed` / `processing` 状态。两轨均成功解码，duration=120、readyState=4、media error 为空；暂停、继续、刻度尺拖动定位正常。没有使用真实会议音频作为测试素材。

## 交付边界

修复进入 Alpha 18 安装包。Alpha 17 不会自动获得这段源码变更；本轮不执行现有客户端的覆盖安装。真实 261014 在更新后能否在原生 WebView 中实际回放，仍需安装后的验收；文件完整性证明与合成媒体播放验证不能代替实际声音核听。
