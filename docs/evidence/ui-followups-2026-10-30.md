- [旧版重点卡片](assets/ui-followups-20261030/before-open.png)占用约 280px，正文 y 从 93 移至 413.23；这是不同视口下的历史基线，不与新截图作像素重合比较。
- [桌面浅色](assets/ui-followups-20261030/final-desktop-light.png)、[桌面深色](assets/ui-followups-20261030/final-desktop-dark.png)：1280×800，正文开关前后 y93、高690；卡片宽940，阅读区宽972，两侧各16px。
- [窄屏浅色](assets/ui-followups-20261030/final-mobile-light.png)、[窄屏深色](assets/ui-followups-20261030/final-mobile-dark.png)：390×844，卡片宽374，两侧各8px，无横向溢出；正文开关前后位置和高度一致。
- 图标按钮 44×44，固定在右侧中线；开启时透明且禁用、退出键盘顺序，关闭后恢复。关闭按钮及 Escape 均实测；焦点在渲染帧后返回入口。减少动态效果偏好下动画与过渡均为零。
- [滚动保持](assets/ui-followups-20261030/scroll-preservation.json)：把夹具阅读区滚动至240px，实际点击开关后仍为240px，正文顶部仍为93，焦点返回。初次滚轮未移动阅读区是测试前置条件未满足；未将其记录为产品缺陷。
- [自动纪要默认90秒](assets/ui-followups-20261030/final-default90.png)：重启夹具服务后由实际 Record API 与设置选项同时确认；原有显式间隔保留。
- 备份入口在空队列点击前后均为1个、40px高，显示“当前没有待传音频。”且不下载空文件。真实队列备份保留数据的语义另由回归验证。
- 阅读页未再显示过程记录和未知身份占位；已知说话人仍保留。原始内容与编辑路径未删除。

## 保护与边界

只隐藏阅读视图的过程留证，不删除持久化或人工编辑内容。说话人映射只补齐精确修订，冻结快照优先；缺少可靠身份时省略重复占位，不生成虚构编号或真实姓名。备份空队列是显式无操作，真实备份仍保留原格式且不删除待传音频。

真实原始长会议波形、三端完整冷启动、实体设备与多屏混合DPI沿用 v0.2.2 的未验边界，不因本轮界面检查改标通过。交付前自审已由用户回应并追加本轮要求，不再重复。
