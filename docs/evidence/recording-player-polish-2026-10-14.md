# 播放圆点、焦点与标题栏修订

本轮对应用户的三项反馈：拖动点双层套圈、拖动时刻度区出现外框，以及会议操作按钮单独占据一行。仅调整 Web 布局与样式，没有改变音源选择、同步播放或松开后定位逻辑，没有读取或修改真实会议数据。

## 原因与修改

拖动点原来的边框叠加双层阴影形成套圈；现在使用单层实心圆，无边框或阴影。刻度区原来的焦点 outline 已移除，鼠标拖动也不出现外框；键盘焦点通过刻度颜色与圆点大小表示，方向键和 Home/End 操作保留。

上一版标题栏在容器宽度小于 1120px 时强制按钮区占满一行。现在标题独立展示，下方会议信息与操作按钮共享一行；按容器宽度缩减按钮左右间距和播放器宽度，避免长标题挤压元数据。空间不足时仍按内容自然换行，窄屏不能保证所有按钮和信息始终保持一行。

## 当前验证

- 295 项 Node 回归、ESLint、Web 类型检查通过；最终样式的 Web 构建通过。
- 隔离浏览器页面使用产品播放器、标题编辑控件、按钮与图标，按实际标题栏 DOM 和样式复现截图中的长标题及评审计数。
- 复现时圆点为 2px 边框及两层阴影，刻度焦点为实线 outline，按钮区与信息区不在同一行。修改后圆点边框为 0、阴影为 none；连续指针拖动期间刻度区的 outline 为 none、border 为 0。
- 两路 31 分钟静音 WAV 的一次 8 步拖动仍仅产生每路一次音频定位，两路继续播放且时间一致。键盘定位到 5 秒时，焦点可见，外框为 none，圆点通过 1.15 倍大小变化提示。
- 桌面验收内容宽度 934px：收起及展开播放器时，按钮与会议信息同行；展开后的按钮区为 44px 高。长标题完整展示，标题栏相对复现版本减少 33px。
- 明暗主题检查通过，375px 宽度没有横向溢出。窄窗口的自然换行属于布局降级，没有隐藏按钮或字段。

日志、浏览器前后计数、主题截图及隔离页面位于 gitignored 的 `.agent-runtime/player-polish-alpha20/`。此处是合成媒体与隔离布局验证，不是对真实客户端会议的端到端操作。

## 验证边界

原生 WebView 的实际缩放、系统文字大小与实体触屏尚未验证。没有替换用户正在运行的客户端、调用真实供应商或访问真实录音设备。
