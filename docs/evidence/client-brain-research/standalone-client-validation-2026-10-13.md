- 固定提交的独立源码副本：171 项 Node 回归、TypeScript 检查通过。12 项 Rust 回归、Clippy（禁止 warnings）、ESLint、Web 构建与文档检查通过。
- DMG 镜像、复制后应用的 ad-hoc 签名、arm64 架构和版本信息验证通过。
- 从 DMG 复制出的应用在空数据目录中启动独立 Record API 与 worker；开发 API 设置被忽略，诱捕开发后台收到 0 次请求。
- 应用重开后测试记录仍在，WebView 来源配置保持稳定；应用退出后其后台关闭。本机账户自动进入，开发账户和注册/登录接口关闭。
- 实际界面在空 profile 下显示“本机空间”“本机已连接”，没有登录表单。隔离预览进程及其后台已关闭，未开启采音设备或配置真实供应商。
- 已验证原格式音频兼容、压缩内容完整性、损坏检测、大小上限、事务回滚、记录重开、孤立临时文件清理与中断任务恢复。离线本地队列和 SSE 可继续工作，Web 离线行为保留。

运行时为 Node `24.21.0`、SQLite `3.53.4`，FTS5 可用。运行时压缩包经过固定官方 SHA-256 校验，每次从已验证压缩包重新提取；后端依赖在隔离目录中导入检查。发布脚本从固定 Git 提交构建，包内不包含项目 `.env`、开发数据库或供应商密钥。

样本为 120 分钟、7200 个音频片段元数据、1440 条转录和 10 次元数据修改；没有使用真实会议内容。

## 验证边界

本次没有验证真实采音、真实 ASR/LLM、真实长会话、全新 Mac 首次授权或其他操作系统安装包。后台异常退出后目前需要重新打开客户端。现有 Web/旧 Alpha 的数据和待传队列保留在原位置，没有自动迁移；首次使用须在客户端设置中单独配置供应商。

SQLite 和供应商配置没有应用层加密，文件权限不等于 Keychain 或加密备份。压缩不改变现有留存期限，也不能替代备份。存储取舍见[研究](../../research/client-local-storage-2026-10-13.md)及 [proposed ADR](../../adr/0013-standalone-client-storage.md)。
