# 签名更新与 GitHub 发版本地验收

日期：2026-10-13。范围是本地实现和隔离测试；未推送提交/标签、未创建远程 Release、未替换已安装 Alpha，未重启现有 API 或 worker。

## 已确认的更新场景

[原生更新证据](client-updater-smoke-2026-10-13.json)由 macOS arm64 的真实 Tauri/WKWebView 运行产生，使用官方 updater 2.13.3 与临时 Tauri 签名密钥：

| 场景 | 结果与证据边界 |
| --- | --- |
| 返回 HTML，清单格式错误 | 检查失败，不安装 |
| HTTP 204，无更新 | 状态为 current |
| 制品字节被篡改 | 官方验签拒绝 |
| 清单版本 9.9.10、可信签名版本 9.9.9 | 官方版本绑定拒绝 |
| 合法签名 9.9.9 | 下载验证通过；官方安装器实际替换临时替身 `.app` |

合法场景中 8 次不安全安装全部被阻止：界面录音、暂停、待传字节、待传片段（即使统计字节为零）、队列操作中、实际原生音源仍活跃、前端状态超过 4 秒，以及服务端会议仍暂停。结束服务端会议后才允许替身安装。

这些守卫场景通过既有 `smoke-test` 专用 IPC 注入前端状态，测试模式下隔离真实 React 的空闲状态上报，避免两个报告者互相覆盖。Rust 守卫、官方下载/安装器、代理认证与服务端接口均真实执行。它不证明生产界面操作全流程、真实应用重启或真实 OS 签名安装；测试入口和 HTTP 例外不会进入正式构建。

## 录音与离线补传没有新增回归

[重跑证据](native-client-update-regression-2026-10-13.json)使用真实 React、原生合成音源和 IndexedDB：暂停前保存 3 个片段，客户端重启后保留相同本地来源与队列，重新登录并重放 3 个持久化回执；原生 IPC 另产生 3 个持久化回执。SSE、CSRF 拒绝和 iframe 阻止也通过。

这是合成音源验证，没有打开真实音频设备，没有调用真实 ASR/LLM，也没有访问现有会议。真实系统采集、外放回声、长会话、休眠恢复、功耗和网络抖动仍需实机验收。

## 正式形态构建排除测试入口

[包启动证据](native-client-updater-package-2026-10-13.json)：macOS arm64 开发 `.app` 启动，内置 React 实际请求 bootstrap。可执行文件中未包含合成身份、更新测试 URL、替身安装路径或测试探针标记；测试环境变量未触发探针输出。可执行文件为 13,248,352 字节。

该包使用包含已提交菜单栏阶段的最终交付快照构建，没有安装到用户系统；未配置正式 updater 公钥/源，也未做 Developer ID 签名或公证。开发包启动不能替代可信已安装版本到新版本的升级验收。
