63 项浏览器检查覆盖：五页 × 六种宽度（1440、1280、1024、768、390、320）；三个抽屉 × 六种宽度；15 项交互与数据检查。检查同类行/卡片等高、控件同高、标题不折行、无横向溢出，以及抽屉正文不覆盖底部操作区。

交互检查包括搜索空态、Skill 启停、权限页、Esc 关闭、新建规则、放弃编辑、实际 API 会议列表、任务预览不执行、返回现有会议、来源修改仅确认提交，以及停用 Skill 后的规则约束。

首次测试的 localhost `listen EPERM` 来自沙箱限制，已在允许本地临时端口的环境重跑。DEV 入口引入后，认证 VM 夹具显式使用 `DEV=false`；同时修正默认 app-shell 的多余空格，原有认证断言保持通过。浏览器开发服务器在该卷上出现样式缓存未更新，最终重启后重跑检查与截图，未使用旧截图。
