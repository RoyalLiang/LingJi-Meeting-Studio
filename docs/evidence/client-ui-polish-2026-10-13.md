# 客户端界面细节验收

验证日期：2026-10-13。范围为客户端左上角 Logo、弹窗关闭按钮和选择框；保留既有会议行为。

## 实现

- Logo：从指定应用图标复用三段翡翠书页路径，单独提供紧凑 SVG，取消模糊滤镜，图形占比提高；Dock/安装包主图标继续使用指定原图。
- 关闭按钮：共享 Modal 与翻译、纪要侧栏使用同一组件。中央“×”保持方向，外圈齿轮在悬停或键盘焦点时旋转；触屏点击区域为 44px，减少动态效果偏好关闭旋转。提示条关闭和系统窗口控制不属于弹窗页面。
- 选择框：原生 popover 保持挂载以完成收起过渡，选中项使用固定勾选标记，悬停和键盘焦点与选中状态区分。保留 dialog 内 portal、隐藏表单值、disabled/readOnly 与方向键等操作。

## 本地验证

185 项 Node 回归、ESLint、TypeScript 和 Web 构建通过。隔离 Chromium 验证明暗主题的 1x/2x Logo、关闭按钮悬停与真实 Tab 焦点、减少动态效果、无布局位移，以及此前登录防重入、树形纪要、引用表格、工具栏和原音回放回归。原音使用合成 WAV。

独立选择框 harness 的 7 组交互通过：点击与表单值、方向键/Home/End/Enter/Escape/Tab、外点关闭、只读/禁用/空选项、弹窗 portal、390px 向上翻转与长标签、减少动态效果。关闭期间保留离散过渡，结束后隐藏；全程无过渡的降级模式也通过相同功能检查。

本机 Playwright 需要 WebKit 2336，已有版本为 2140，创建页面时报 `Unknown setting: PushAPIEnabled`，未安装或升级浏览器，因此原生 WebKit 动效尚未实测。该环境限制不视为 WebKit 验收通过。

浏览器证据位于 gitignored `.agent-runtime/tasks/20261013-ui-polish/` 和 `.agent-runtime/tasks/20261013-select-polish/`；可审阅的摘要保存在 [Alpha 8 验收数据](client-ui-polish-alpha8.json)。没有访问真实会议、打开真实音频设备或调用供应商。

## 安装包验收隔离

首次安装包验收遇到测试端口与当前运行客户端冲突。客户端对独立后台使用固定来源以保留 WebView 队列；测试临时目录也按默认值选择了同一端口，后台已启动但页面代理尚未就绪，读取 profile 因此失败。验收脚本为自己的临时 profile 预分配空闲端口，并有界等待配置与页面代理就绪；生产端口分配与离线来源策略保持原样。已有客户端、API 和 worker 不参与此验证。
