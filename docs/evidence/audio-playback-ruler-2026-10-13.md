# 原音播放控件本地验证

2026-10-13：工具栏原音入口使用纯播放图标；点击后原位展开暂停／继续、重置及刻度进度条。保留来源和时间的无障碍名称、悬停提示，不显示常态文字。多音源以来源图标区分，首次仅播放第一路。

播放中拖动会暂时暂停，松手后从选定位置继续；暂停时拖动保持暂停。重置暂停并回到开头。拖到末尾停止；滑块支持键盘微调。继续使用既有原音留存、处理完成和有效音源可用性规则。

本地验证：279 项 Node 回归、ESLint、TypeScript 和 Web 构建通过。隔离 Vite 服务使用 120 秒静音 WAV，在浏览器验证首次播放、暂停／继续、拖动、重置、键盘和末尾边界；桌面、390px 窄屏及深浅主题未出现横向溢出。测试页使用实际播放器组件和合成音频端点，未访问真实录音或供应商。

本轮没有打包、安装或替换正在使用的桌面客户端，未进行实体触屏或各系统 WebView 验收。
