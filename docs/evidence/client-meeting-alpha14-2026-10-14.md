# Alpha14 轻弹三点与麦克风入口验收

日期：2026-10-14。用户从三版交互预览中选择“轻弹三点”，幅度 6px，要求固定区域高度、减少动态效果支持，并将麦克风默认接入与免选择弹窗修复一并打包。

`CurrentDiscussion` 使用三个装饰性圆点，新发言或状态改变时按 85ms 间隔弹跳，两轮、每轮 520ms，最大上抬 6px。初始历史状态不重播。动画运行期间的新更新合并为当前活动，避免不断从起点重启；暂停、卸载及开启减少动态效果都会取消动画。文字不随圆点移动，不改变页面滚动位置。

外框固定为 108px，与选择预览一致；标题一行、状态最多两行。桌面与 320px 窄屏、浅深主题均验证无横向溢出，底部和阅读位置不跳动。没有增加转录或全量纪要计算，也没有额外后台请求。

麦克风入口修复已在 `a81ce02` 提交，详见[上一阶段验证](microphone-direct-and-motion-preview-2026-10-13.md)。新控制器默认启用麦克风和系统音频；有效显式设备、失效 ID 回退及用户关闭后的暂停恢复继续保留。点击开启或继续时的失败直接显示，不强制选择来源；主动打开的来源窗口仍可恢复接入。快速新建时全部音源失败的恢复窗口仍保留。真实权限拒绝、占用或硬件故障不伪装为录音成功。

实际 React 组件的 Chromium 检查 11/11：自然回弹、更新期间不重启动画、固定几何和阅读位置、暂停取消、实时减少动态效果、下一次实际更新才恢复、切换记录不重播、窄屏及卸载清理。原生 WKWebView 通过 CUA 真实点击进入前台，active/key/visible 与 DPR2 确认；6/6 检查覆盖自然矩阵推进、错峰、固定高度、有限播放和暂停中断。61 个动态帧的上抬范围为 -5.79351～0.96642px，按 50ms 采样未必落在精确峰值；配置峰值为 6px。未 seek、finish 或冻结动画来伪造自然推进。

原生夹具采用与实际组件一致的四个源码文件哈希，非持久 WebView profile、仅本机回环静态服务。窗口与服务器均已退出。原生验证是组件夹具，不代表完整正式客户端的实体麦克风、会议软件采音或系统授权流程。没有打开真实音源、调用真实供应商、修改系统授权或替换当前客户端。
