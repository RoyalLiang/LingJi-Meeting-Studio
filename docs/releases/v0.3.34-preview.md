# v0.3.34 测试版

## 本版变化

- 录音和翻译更新减少对长会议历史的重复读写，空闲后台任务按到期时间运行。
- 中文两字可直接检索会议与目录知识，目录问答可使用两字关键词。
- 修复翻译栏的多余边距、小屏弹窗切换及重点入口位置，恢复原文、译文与纪要的文本选取。
- 设置页按需加载，录音时钟和电平更新不再带动整个工作台刷新；小字号文字提高可读性。
- 音频导入可同时解码和上传，保持分片顺序与有界队列；保留的会后原音在后台归并，已有回放和备份引用继续有效。

## 下载与安装

支持 macOS 14.6+ Apple Silicon、Windows 10/11 x64、Ubuntu 22.04/24.04 x64。安装包与摘要以本版 Release 为准。

升级前结束录音、完成待保存音频、退出应用并备份数据。macOS 拖入 Applications；Windows 运行安装器；Ubuntu 使用 `sudo apt install ./Lingji-0.3.34-linux-amd64.deb`。

macOS 测试包使用 ad-hoc 签名，独立 Windows 安装包尚无商业 CA 签名。真实音频设备、供应商服务与旧数据迁移需分别验收。商店认证与独立安装包发布是不同渠道。
