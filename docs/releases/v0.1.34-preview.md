# 聆记 v0.1.34 公开测试版

发布日期：2026-10-28。优化长录音波形读取、设置操作布局与 Windows WebView2 渲染开销，并保留 v0.1.33 多语种及词表功能。五项 CI 与四个公开附件核验通过，详见[发布回执](../evidence/preview-v0.1.34-2026-10-28.md)。

## 版本改动与修复

- 长录音波形采用最多八路读取，按固定峰值区间扫描；成功结果随记录持久缓存。再次打开同一完整音源时不再解压扫描音频；缓存失效、删除和留存到期仍按原有权限与清理规则处理。
- 波形从 384 个矩形节点收为两条路径，播放位置只更新移动层。暂停、缓冲和拖动结束后释放动画及临时合成层；定位完成但仍缺少后续音频时不提前恢复动画。
- Windows 原生 WebView2 使用不透明表面，减少大面积背景模糊与常驻合成层；保留 GPU 加速、原有后台录音和补传行为。
- 删除图标移到记录工具栏最右侧并使用红色；移除纪要空态中的“选择模板”说明。
- 设置保存配置按钮放到最右侧；诊断下载改为标题旁的感叹号图标。模型 Key 字段改名为“模型Key”，字段说明与控件同行显示，窄屏仍可滚动查看全部设置。
- 更新策略右侧合并为一个操作按钮：“下载并更新”；自动下载尚未完成时按钮置灰，完整性校验通过后显示“立即更新”。移除独立的检查更新与打开安装包按钮；安装仍由用户点击触发，并核对录音和待传队列，自动下载不会自动安装。

## 安装与升级

结束录音、等待补传完成，再从托盘退出客户端并覆盖安装。v0.1.32 起可使用 Preview 更新通道；更早版本需手动安装。

- [Windows x64 安装器](https://github.com/RoyalLiang/LingJi-Meeting-Studio/releases/download/v0.1.34/Lingji-0.1.34-windows-x64-setup.exe)
- [macOS Apple Silicon DMG](https://github.com/RoyalLiang/LingJi-Meeting-Studio/releases/download/v0.1.34/Lingji-0.1.34-macos-arm64.dmg)，macOS 14.6+，内部 build 0.1.56。
- [Linux x64 DEB](https://github.com/RoyalLiang/LingJi-Meeting-Studio/releases/download/v0.1.34/Lingji-0.1.34-linux-amd64.deb)，Ubuntu 24.04。

Release 包含三个安装包与供客户端校验的 `preview-update.json`；校验值在 Release 正文。macOS 仍为 ad-hoc 签名且未公证，Windows 未代码签名；[系统信任说明](macos-trust.md)继续适用。

## 验证范围

[本地验证](../evidence/waveform-settings-v0.1.34-2026-10-28.md)记录合成 50 分钟 HTTP 波形基准、缓存重启与失效、设置保存/更新门禁、播放及动画释放断言。Chromium 对照中节点与样式计算减少，不能替代 Windows WebView2 显存实测。

真实用户录音的磁盘耗时、Windows GPU/显存/进程内存数值、真实会议与模型质量、全新电脑升级仍需单独验收。
