# 聆记 v0.1.15 测试版

版本：0.1.15；macOS bundle 0.1.37。状态：已发布；后台 verify/build/publish 成功，发布回执已补记。

新增可选 FunASR＋SenseVoice 本机或私有转录，按音源聚合原生短包，静音边界优先提交，并在暂停和结束时处理尾部。保留录音、转录版本、纪要引用、人工修订和原有模型模式。

安装包不附带 Python 或模型权重，首次使用需部署服务。见[配置与启动方式](https://github.com/RoyalLiang/LingJi-Meeting-Studio/blob/044f390777e5d26b31e2e4dca7b147a3e9d0f950/docs/engineering/funasr.md)。纪要继续使用已配置的豆包等模型；本地转录不代表云端纪要链路离线。

本轮覆盖和边界见[验证记录](../evidence/funasr-sensevoice-2026-10-24.md)。实体长会议、其他硬件和正式 Apple 信任分别验收；测试包沿用现有分发方式，不新增公证声明。
