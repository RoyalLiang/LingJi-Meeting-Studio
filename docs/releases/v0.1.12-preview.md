# 聆记 v0.1.12：暂离补齐与紧凑波形播放

已通过现有 GitHub Actions 发布 Apple Silicon 测试包，verify、build、publish 全部成功，五附件和 228 个源码摘要核对通过。见[发布核验回执](../evidence/preview-v0.1.12-2026-10-23.md)。

- 暂离后等待已保存的录音处理完，自动补齐已录内容；本场仍可恢复录制。结束并整理后生成终稿。
- 暂离补齐和终稿遇到模型超时、连接中断或 JSON 格式错误时，最多进行三次尝试；人工修订保持保护。暂离补齐使用四分钟模型预算，任务续租保持一致。
- 同一语音故障关闭提示后，重新打开 App 不再反复弹出。标题旁的提示图标可再次查看；手动重新处理或出现另一类错误时会展示新提示。
- 播放器支持点击或拖动波形定位，保留刻度、当前位置和前后 15 秒。移除右上跳转框和左下重复时间；倍速以播放键附近的紧凑图标菜单操作。
- 移除纪要区“自动整理已开启”和“音频直接…”的常驻说明，保留必要的授权设置、处理进度和真实错误提示。

旧 ASR 配额失败不会在切换模型后自动重送历史录音。需要继续处理的旧记录，仍须在授权原音处理后点击“重新处理”。模型配置沿用 [v0.1.7 配置说明](v0.1.7-preview.md)。

安装包为 Apple Silicon、macOS 14.6 及以上；App 0.1.12，bundle 0.1.34。测试版仍为 ad-hoc 签名、未公证，见[macOS 安全提示](macos-trust.md)。

[本轮复现与验证](../evidence/pause-catchup-controls-2026-10-23.md)。本轮未使用浏览器调试；真实供应商、真实设备长会议与新机器安装需要分别记录，不能由合成测试代替。

原生 App 的实际点击、拖动和视觉尺寸仍因锁屏未验收；本机包内启动已独立通过，两项验证分开记录。
