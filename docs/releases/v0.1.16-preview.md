# 聆记 v0.1.16 公开测试版

## 本版变化

- 新增 Windows 10/11 x64 安装器。欢迎、安装位置、完成三屏采用铺满窗口的浅色背景，支持当前用户安装、桌面快捷方式和安装后启动。
- Windows 系统托盘和 macOS 菜单栏常驻：关闭主窗口后继续录音、补传和纪要整理，点击托盘/菜单栏重新打开。
- 退出仍检查录音与未发送音频，避免把关闭窗口当成结束会议。升级或卸载前需先退出常驻聆记，安装器不会强制结束录音进程。
- 修复 Windows 音频落盘时目录同步返回 EPERM、导致音频上传失败的问题。
- Windows 安装包内置 Node 24 和 WebView2 离线安装组件。FunASR、SenseVoice 的服务与模型仍按现有说明单独部署。

## 安装与后台常驻

macOS 使用 Apple Silicon DMG，Windows 使用 x64 setup.exe；下载对应平台的安装说明与 SHA256 校验文件。macOS 测试包为 ad-hoc 签名且未公证，Windows 测试包未代码签名。

安装前先暂停/结束会议并等待音频补传，备份数据，从菜单栏或托盘选择退出。安装器关闭后启动聆记，在「设置与诊断」配置语音和纪要服务。关闭主窗口后录音会继续；如需结束录音，请使用会议中的暂停/结束操作。后台常驻不包含登录自启。

## 验证范围

自动验证覆盖同一源码构建、双平台 Rust 回归、原生双音源模拟采集、窗口隐藏期间的队列增长与恢复、包内独立后台、持久化和重启、Windows 静默安装/资源完整性/卸载。具体通过情况以本版 Actions 与发布回执为准。

未覆盖真实 Windows 麦克风/系统音频、全新电脑的权限与安全提示、真实服务质量以及长时间会议。安装器界面检查与自动安装通过不等于真实设备验收。
