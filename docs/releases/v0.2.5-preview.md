# v0.2.5 测试版

日期：2026-10-31。发布核验见[回执](../evidence/preview-v0.2.5-2026-10-31.md)，实现与验证见[本轮证据](../evidence/meeting-finish-windows-2026-10-31.md)。

## 版本改动与修复

- 重点速览使用综合主题节点生成的简洁标题，随整理结果更新；第一条重点恢复为正文条目，历史仍保留。
- 会议结束后持续显示尾段上传/转录、纪要与重点速览的后台收尾状态和节点进度；完成后才显示收好，失败保留已有结果并提示重试。
- 封存后新转录立即进入尾端总结，不等待会中刷新间隔；纪要调度优先结束的会议，保留正在处理的任务。
- Windows 新增默认关闭的 Chrome/Edge 与飞书共享音频会话监听，可按麦克风或扬声器调用触发自动会议，沿用取消与手动优先规则。

## 安装

[Release](https://github.com/RoyalLiang/LingJi-Meeting-Studio/releases/tag/v0.2.5)：[macOS Apple Silicon](https://github.com/RoyalLiang/LingJi-Meeting-Studio/releases/download/v0.2.5/Lingji-0.2.5-macos-arm64.dmg) · [Windows x64](https://github.com/RoyalLiang/LingJi-Meeting-Studio/releases/download/v0.2.5/Lingji-0.2.5-windows-x64-setup.exe) · [Linux amd64](https://github.com/RoyalLiang/LingJi-Meeting-Studio/releases/download/v0.2.5/Lingji-0.2.5-linux-amd64.deb)。

## 限制

Windows 仅覆盖可观察的 WASAPI 共享会话，独占音频不受完整监测；切换到独占模式可能不可观察，应使用手动控制。视频、音乐和其他标签页也可能触发或延长录制。Linux、Safari 监听暂不支持，退出应用后不监听。真实 Chrome/飞书会议、真实 ASR/LLM 质量与本机窗口恢复交互仍需独立验收；CI 与只读接口测试不替代这些试点。
