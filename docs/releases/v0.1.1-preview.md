# 聆记 v0.1.1：会议收尾与体验修复测试版

本次提供源码和 macOS Apple Silicon 测试安装包，标记为 GitHub pre-release。`v0.1.1` 不代表稳定版认证。

## 系统与下载

- Apple Silicon Mac（M 系列），macOS 14.6 或更新系统。
- 下载 `Lingji-0.1.1-macos-arm64.dmg`、`SHA256SUMS.txt`、`release.json` 和安装说明。
- 应用为 **聆记 Preview.app**，版本 0.1.1，macOS bundle 版本 0.1.23。内置 Node 24 后台，无需另装运行时。

将下载文件放在同一目录，运行 `shasum -a 256 -c SHA256SUMS.txt`。实际包哈希、冻结源码、Actions 运行及工作流 SHA 以附件 `release.json` 为准。

## 本版变化

- 修复会议收尾被后台上传或刷新阻塞：本机保存与封存成功后即可结束，剩余音频继续补传；接入与收尾状态分别显示。
- 优化语音处理受阻提示：紧凑布局、说明与按钮分组，可直接检查配置和重新处理，适应窄窗口与深色主题。
- 新会议按创建时间倒序显示；忽略过期的目录/搜索响应，防止旧请求覆盖新会议列表。
- 优化启动：跳过未变化历史会议的重复写入，并发加载首屏记录权限与工作目录。100 场合成历史场景的后台就绪中位数约 60→27 ms；这不代表完整 App 冷启动加速幅度。

## 安装、升级与数据

1. 先结束录音并等待补传清空，再完全退出旧版。退出后备份整个 `~/Library/Application Support/com.tts.meeting` 目录；不要在应用运行时只复制 SQLite 文件。
2. 打开 DMG，将 **聆记 Preview.app** 拖到 Applications；替换旧 Preview 后从 Applications 打开。
3. 核对显示版本为 0.1.1，保留并检查自己的语音和纪要服务配置。若系统要求重新授权，按实际麦克风/系统声音来源分别处理。

测试包采用 **ad-hoc 签名，未进行 Developer ID 签名或 Apple 公证**。首次打开如被系统阻止，按 Apple 对未知开发者应用的说明操作，不关闭系统安全机制。

Preview 与 Alpha 使用相同标识 `com.tts.meeting`，可能共享数据与权限，请勿同时运行。升级不会恢复已经过期清理的音频；回退前保留备份。卸载应用不会自动删除会议数据。本次发布不会自动替换你当前安装的 App，也不建立正式签名自动更新基线。

## 验证与边界

CI 在冻结源码上执行 Node/Rust 回归、ESLint、类型检查、文档检查与 Web 构建；验证 DMG、arm64、签名结构、包内独立后台及隔离启动/重启。实际执行结果以本次 Actions 和附件回执为准；不能用上一版 CI 结果替代。

修复前后的本地验证见[四项修复证据](https://github.com/RoyalLiang/LingJi-Meeting-Studio/blob/v0.1.1/docs/evidence/meeting-lifecycle-startup-2026-10-22.md)。隔离合成会议已验证：上传仍挂起时可以结束，释放后尾段补齐且水位一致。

尚未验证实体设备断开、真实 ASR/LLM 质量、长会议、全新 Mac 首次安装、完整 App 冷启动、真实 PostgreSQL/S3 或 Windows/Linux 安装。打包及烟雾检查不采集真实音频、不调用供应商。

English: Public preview 0.1.1 fixes meeting completion waiting on background work, clarifies processing recovery actions, keeps newly created meetings first, rejects stale list responses, and removes redundant startup writes. The Apple Silicon installer is ad-hoc signed and not notarized. Full native cold startup and real-device acceptance remain unverified.
