# 聆记 v0.1.21 测试版

本轮改善 Windows 覆盖升级、录音控制与异常纪要恢复。发布状态以[交付回执](../evidence/preview-v0.1.21-2026-10-26.md)为准。

- Windows 同位置升级跳过旧版维护/卸载页面，在一个安装窗口完成覆盖。安装器按 SHA256 跳过未变化的资源（包括本地模型），替换变化文件；下载的仍是完整安装包。不同目录、降级和旧 MSI 安装保留原维护流程。已有会议数据保留。
- 原音播放进度逐帧读取真实媒体时钟，波形支持点击和拖动定位，播放控件与下方内容留出间距。
- 整理失败或卡住后可手动重新整理；新任务会隔离旧任务结果，保留人工编辑与来源版本约束。新会议默认每 2 分钟自动整理，已有明确配置保持不变。
- 开始录音并准备就绪后自动收起主窗口，显示极简胶囊。胶囊可暂停/继续、返回主窗口，或打开“结束并整理”确认；结束仍会排空录音与补传。
- 失败提示在页面内显示，可关闭；同一整理事件关闭后不再每次启动重现，新失败仍会提示。设置可用 Esc 关闭并重新打开。
- 按钮和输入框使用细中性色焦点指示；备份记录改为设置同行的图标，悬浮提示统一样式。

## 安装与使用

从 [Releases](https://github.com/RoyalLiang/LingJi-Meeting-Studio/releases) 下载对应平台安装包并核对同版本 SHA256SUMS。Windows 正常升级请选择原安装位置；取消安装本地模型仍可使用已配置的云端服务。请先结束录音并完成补传，再从托盘或菜单栏退出旧客户端；关闭窗口会继续后台常驻。安装器不会强行终止会议。

胶囊左侧可以拖动；暂停键变为继续键。若暂停后仍有音频等待补传，继续键暂不可用；可返回主窗口查看进度，或结束并等待整理。右侧停止图标打开结束确认，展开图标回到主窗口。关闭胶囊也会恢复主窗口。异常提示关闭不会取消后台补传；需要恢复整理时使用提示中的“重新整理”或纪要设置内的手动整理。

## 验证范围

本地 Node、Rust、类型、代码规范与 Web 构建已通过；独立 Standards/Spec 源码评审已通过。完整 Windows 覆盖升级、胶囊原生交互和正式发布检查正在执行，结果补入回执。

实体 Windows 音频设备、蓝牙切换、高 DPI 与长会议尚未验收。macOS 透明胶囊启用了 Tauri 的 macOS private API，仅用于当前桌面预览分发，未验证 App Store 分发兼容性。Windows 安装包未签名，macOS 包未经 Apple 公证。
