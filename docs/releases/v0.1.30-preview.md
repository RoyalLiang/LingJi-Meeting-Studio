# 聆记 v0.1.30 公开测试版

本版整理发布说明和附件，增加 Linux x64 DEB。当前为发布准备；构建、安装验证和公开下载状态以对应 Actions 与发布回执为准。

## 版本改动与修复

- 修复原生回归探针按按钮序号误点新增麦克风的问题，改用无障碍按钮名称定位；补齐 Tauri Linux 打包器需要的 appindicator 构建依赖。保留隐藏录音、重启补传和真实安装验证门禁。
- Release 正文优先显示本版改动与修复，兼容已有“本版变化”和“修复与设置”标题；缺少变更说明时停止发布，避免出现只有通用安装文案的版本说明。
- Release 附件仅发布 macOS DMG、Windows EXE 和 Linux DEB 成品安装包。Source code (zip / tar.gz) 由 GitHub 按版本标签生成；校验值直接写入正文，安装文档、源码清单和测试报告保留在 Actions artifacts。
- 新增 Linux x64 DEB 后台构建，包含 Node 24、SenseVoiceSmall INT8、Silero VAD 和原生推理库。发布前在 Ubuntu 24.04 检查包版本、架构、安装资源、原生应用启动与重启、公开样例离线推理及卸载。
- 补齐 Linux 离线转录依赖及 `.so`/版本化 `.so` 资源识别；发布器要求三个平台来自同一冻结源码和同一 Actions run，校验通过后才公开安装包。

## 安装

升级前结束录音、等待补传、退出旧版并备份会议数据。

| 系统 | 成品安装包 | 安装方式 |
| --- | --- | --- |
| macOS 14.6+ Apple Silicon | `Lingji-0.1.30-macos-arm64.dmg` | 打开 DMG，将应用拖入 Applications |
| Windows 10/11 x64 | `Lingji-0.1.30-windows-x64-setup.exe` | 运行安装器，选择位置、快捷方式及是否安装本地模型 |
| Linux x64，验证基线 Ubuntu 24.04 | `Lingji-0.1.30-linux-amd64.deb` | 在下载目录执行下方命令，由 apt 安装系统依赖 |

```bash
sudo apt install ./Lingji-0.1.30-linux-amd64.deb
```

Linux 安装后从应用菜单打开 Lingji Preview，或运行 `tts-client`；卸载使用 `sudo apt remove lingji-preview`。卸载保留用户目录中的会议数据。其他发行版和旧系统兼容性尚未验证，本版不包含 Linux ARM64 或 RPM/AppImage。

校验值在 Release 正文中；macOS 使用 `shasum -a 256 <文件>`，Linux 使用 `sha256sum <文件>`，PowerShell 使用 `Get-FileHash <文件> -Algorithm SHA256`。

macOS 仍为 ad-hoc 签名且未公证，Windows 未代码签名；[macOS 系统信任说明](macos-trust.md)继续适用。macOS/Windows 关闭窗口后常驻托盘；Linux 关闭窗口进入退出确认流程。Linux PipeWire 系统音频、麦克风和文件导入需在目标设备验收。

## 验证范围

本轮不修改会议业务逻辑。Node、静态检查及各平台安装包验证结果写入发布回执；CI 和虚拟显示上的启动验证不代表真实设备采音、全新电脑交互安装、真实供应商质量、长会议或 PG/S3 验收。

Linux 构建依赖与兼容范围参考 [Tauri Debian 打包](https://v2.tauri.app/distribute/debian/)及[系统依赖](https://v2.tauri.app/start/prerequisites/)；在 Ubuntu 24.04 构建不等于已支持较旧的 Debian/Ubuntu。
