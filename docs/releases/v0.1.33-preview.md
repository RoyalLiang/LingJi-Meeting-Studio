# v0.1.33 Preview：多语种与词表纠错

发布准备日期：2026-10-28。源码与后台构建结果以本版发布回执为准；CI 发布完成前，以下安装链接不可视为已可下载。

- 新建记录默认自动识别；内置 SenseVoice 保留中、英、日、韩、粤语种标签，混语完整原文按本场目标语言翻译。
- 翻译支持已配置通用文字模型及专用豆包 Seed，自动选择避免向非豆包端点固定请求 Seed 模型。
- 设置新增按账户/目录隔离的常见词语集、名称集；支持正确词形与已知别名，辅助支持的识别接口。
- 逐字记录提供本地别名候选、显式模型校对和人工确认；保留识别原文，修订后重译，保护普通人工编辑。

[使用与限制](../engineering/multilingual-vocabulary.md)。原始音频标识、持久化确认、重传幂等与停止排空协议未变；旧记录缺少语种时保持未知。
