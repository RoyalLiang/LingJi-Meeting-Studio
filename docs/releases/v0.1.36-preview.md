# 聆记 v0.1.36 公开测试版

日期：2026-10-28。优化文字纪要的重复结构与请求开销，修复模型服务基址请求、主题标题连线和底部处理状态。五项 CI 与四个公开附件核验通过，见[发布回执](../evidence/preview-v0.1.36-2026-10-28.md)。

## 版本改动与修复

- 纪要请求采用紧凑引用和短标识，返回后还原原始引用及修订版本；精简重复指令，保留原文、历史条件、否定与更正校验，不强制降低用户推理设置。
- 文字纪要使用更长但仍受原有字节预算约束的分窗，减少重复请求；自动刷新频率不变，音频分窗限制不变。跨窗口语义整合继续保留，汇总预算按实际发送的紧凑载荷计算。
- 用量增加供应商返回的缓存输入和推理输出明细，它们属于已有输入/输出的子集，不重复计入总量。
- 服务地址支持不带查询参数的根级 `/v1` 等版本基址，按所选协议补全请求路径；完整自定义接口保持原行为，避免重复追加路径。
- 修复纪要主题标题与树形连线交叠，连线从标题下方开始，长标题和窄屏正常换行。底部处理时仅显示一次“正在处理AI纪要”，移除原位置的重复状态，保留重要错误提示。
