# 聆记 v0.2.2 Beta 测试版

日期：2026-10-30。本版修正桌面保存状态、设置重绘和录音悬浮条，并减少三端默认启动的重复加载。已通过 GitHub Actions 发布，[完整发布核验](../evidence/preview-v0.2.2-2026-10-30.md)与[实现及平台边界](../evidence/desktop-reliability-2026-10-30.md)分别记录。

## 版本改动与修复

- 修正迟到的记录详情或结束响应覆盖较新保存状态，避免已保存或已清理的会议又显示原音保存中；新建、结束、刷新和订阅使用同一快照入口。
- macOS、Windows、Linux 共用启动链复用首批默认会议列表，减少一次请求及对应等待；搜索、目录切换和手动刷新保持正常加载。
- 设置表单跳过无关录音信号、时钟和转录引起的父级重绘，保留表单输入、加载与保存更新。
- 录音悬浮条缩短为 340×42 逻辑像素，按主窗口所在显示器的工作区顶部居中，保持 16 逻辑像素间距和置顶。修正麦克风开关图标，超过一小时仍显示完整计时。
- 保留原音落盘确认、停止排空、授权和留存策略。已清理原音不会恢复；合成长录音波形测量不代表用户真实会议已经验收。
