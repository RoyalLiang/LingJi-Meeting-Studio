# 聆记 v0.2.0 Beta 测试版

日期：2026-10-30。按 Beta 计划进入首个实现版本；本地已验证，后台构建和 Cloudflare 发布状态待回执核验。

## 版本改动与修复

- 增加官网、仅 RoyalLiang 可登录的 GitHub 发布门户和可撤销的 24 小时在线纪要快照。桌面导出后在浏览器预览并确认，默认仅纪要及引用原文，全部转录需另选，不上传原音。官网目标 rookiecode.com，快照存入 D1，本版不启用 R2；在线文件上限 1 MiB。
- 接入通用场景词表及有来源的汉字读音包，为账户/目录词表提供同音候选，明确已检查范围，保留人工确认与修订保护。
- 修复同步密码派生、伪造签名、Unicode 截断、分享全集扫描、无效令牌无界查询、空闲任务重复事务和桌面 Realtime 排空边界。
- 继承 v0.1.49 的设置、学习、翻译与纪要修复，保留既有仅纪要正文分享默认。
