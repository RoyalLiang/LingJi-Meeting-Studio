# 聆记 v0.1.39 公开测试版

日期：2026-10-28。修复长录音缓存与原生持久化确认，统一处理进度、提示和纪要来源入口。构建与公开附件核验待 CI 完成，结果补记在发布回执。

## 版本改动与修复

- 修复连续刷新时重复出现纪要块的问题；纪要、逐字记录、笔记和翻译使用独立组件标识，切换会议时仍正确清理状态。
- 保持原有纪要树形卡片、字号、配色、圆角和间距，只压缩原文入口并补齐可靠的发言归属；以完整会话页复核样式。

- 在 v0.1.37 链路改进基础上，补充修复缓存满时错误等待停止排空才显示的问题：立即显示停录原因，同时继续保留并重试未确认音频。

- 本机待补传预算从 48 MiB 调整为按空间计算、最高 512 MiB；新会议先检查容量，不清空旧会议音频。真正满缓存时准确提示未开始采集；空会议不会循环生成纪要。
- 原生音频在写入本机队列后才释放读取片段，失败保留尾部并重试；上传挂起有期限，恢复提示合并显示。纪要预览合并写入，不再等待每轮预览写盘后才继续读模型流。
- 分别显示原音、已保存、最新转录及纪要依据；时长跟随实际收到的采样，不再在无音频时持续累加。
- 纪要可从已有身份与同修订转录恢复说话人 1/2，无身份则明确显示未区分。原文计数行改为来源图标，保留引用查看。
- 提示统一顶部居中、紧凑样式；重要错误优先，普通提示可见后约两秒关闭。修复反复恢复主窗口后不能再次进入悬浮窗的问题。
- 安装前再次确认退出并安装，等待旧进程及自有服务退出；macOS 预备替换和备份，新应用就绪后再清理备份。
