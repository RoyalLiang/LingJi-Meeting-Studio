# 聆记 v0.1.17 测试版

本轮将本地语音转录引擎与模型随应用交付，并按已确认的三屏设计重做 Windows 安装器。

- Windows x64 与 macOS Apple Silicon 包内包含 SenseVoiceSmall INT8、Silero VAD 和原生 ONNX 推理运行时；无需安装 Python、手动启动服务器或首次下载模型。
- 未配置独立云端转录服务的新安装默认使用“本地 SenseVoice”。已有云端配置和自定义 FunASR 服务保留；原默认无鉴权本机 FunASR 配置升级到内置引擎，并恢复未过期的失败音频。升级恢复可在中断后继续。
- 本地引擎由应用按需启动，空闲三分钟释放；失败后可重新启动，显式退出时回收。关闭主窗口仍保留菜单栏／系统托盘常驻。
- Windows 安装器使用暖白全幅背景、玉绿主按钮，安装位置与桌面快捷方式合并到首屏，后续展示进度与完成页。原生控件保留键盘和辅助技术操作。
- 保留逐字稿、原音定位、版本引用和人工修改保护；纪要继续使用配置的豆包等模型。本地离线能力仅覆盖语音转录，云端纪要仍需要网络与模型密钥。

在设置中选择“本地 SenseVoice”即可使用。需要自有服务时选择“FunASR（外部服务，高级）”，参见[转录配置](../engineering/funasr.md)。模型权重、运行时和第三方许可随包提供，权重协议与代码许可分别适用。

验证与限制：发布前由后台工作流验证源码、构建、安装／卸载、原生生命周期及包内中文／英文／静音样本推理；最终结果以发布回执为准。公开短样本仅验证链路，不代表会议准确率验收。INT8 转换存在已观察到的识别差异；真实 Windows 音频设备、长会议和新电脑仍需单独验证。Windows 包未代码签名；macOS 为 ad-hoc 测试签名，尚未经过 Apple 公证。
