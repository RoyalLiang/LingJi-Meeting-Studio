# v0.2.4 测试版

日期：2026-10-31。本版基于 v0.2.3，保留悬浮会议重点与桌面细节更新。发布状态见[本轮验证记录](../evidence/rolling-summary-2026-10-30.md)。

## 版本改动与修复

- 滚动总结携带最近五分钟原文与累计摘要，在请求预算内按相关性和新近程度选择历史；智能标题跟随新一轮总结更新，人工修订继续受保护。
- 会议重点保留多轮历史，终稿生成后可展开会中重点历史；结束会议后继续处理排队、正在运行的纪要和尾段转录，失败时保留有效的部分结果。
- 移除学习与评审的默认主机和目录，在设置页自行填写；移除该设置下方的说明小字，清空配置后不再访问旧服务。
- 新增默认关闭的后台会议联动：macOS 桌面端监听 Chrome、Edge 和飞书的输入/输出音频调用，持续约十秒后自动录音，全部停止约三十秒后结束由联动创建的记录，倒计时可以取消。

## 验证边界

音频调用只是会议的启发信号，音乐、视频和其他标签页可能误触发。首版不覆盖 Safari、Windows/Linux 音频监听；退出应用后不运行。真实 Chrome/Edge/飞书会议启停、设备切换、锁屏与耗电尚待实机试点，自动化回归不代替这些验收。真实 ASR/LLM 输出质量和学习服务连接未在本轮调用验证。

本机额外窗口全流程冒烟在恢复主窗与迟到 ready 场景未通过，窗口逻辑沿用 v0.2.3；详见本轮验证记录。
