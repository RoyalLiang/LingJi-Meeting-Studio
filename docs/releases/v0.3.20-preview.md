# v0.3.20 测试版

## 本版变化

- 修复手机导航底部菜单偏移，使其保持在侧栏抽屉内。

- 主题、备份和退出按钮统一到侧栏顶部；工作空间管理收拢到顶部入口，移除重复菜单。
- 首页搜索框加宽，最近七天图表使用柔和玉色渐变。

- 优化首页最近七天趋势图，移到周期统计上方；压缩欢迎区，让首屏优先展示讨论节奏。
- 优化细圆角柱、贴柱数值与日期轴，减轻边框，突出今天；保留日／周／月／年场次与纪要 Token。
- 修复更多会议操作的遮挡与键盘关闭，保持纪要树、手记预览、并读与重点速览。
- 优化三栏工作台、固定项目导航与版本入口，飞书／Git 任务在第三栏查看。
- 改进 Chrome／Edge 自动录音的双向活动判定，兼容输入与输出分时上报。

## 使用说明

Token 按北京时间的会议创建日期汇总各场会议已报告的纪要用量，使用 K／M 等缩写；未报告部分不作估算。安装与平台要求见 [客户端安装说明](github-client.md)。
