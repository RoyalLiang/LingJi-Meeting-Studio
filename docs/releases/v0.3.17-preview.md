# v0.3.17 测试版

## 本版变化

- 修复会议“更多”菜单被内容遮挡的问题，统一菜单、弹窗与按钮样式。
- 优化三栏布局：版本移至顶部，项目导航固定，飞书和 Git 任务在第三栏查看。
- 优化首页搜索，保留日、周、月、年会议统计，增加纪要 Token 用量及最近七天柱状图。
- 压缩模型与同步配置的间距，连接检测与模块选择同行显示，修复会议联动选项的布局。
- 改进 Chrome／Edge 自动录音的双向音频活动判定，兼容输入与输出分时上报。

## 使用说明

Token 按北京时间的会议创建日期汇总各场会议已报告的纪要用量，使用 K／M 等单位缩写；未报告部分不作估算。

测试版安装与平台要求见 [客户端安装说明](github-client.md)。
