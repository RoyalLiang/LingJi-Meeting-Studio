# 聆记 v0.1.50 公开测试版

日期：2026-10-30。发布候选，远端基线与未使用的 v0.1.50 标签已核对；最终发布状态以后台工作流和发布回执为准。

## 版本改动与修复

- 会后重点采用已确认的方案 A：顶部横向悬浮卡片，支持收起为一行、关闭与重新打开；结束会议后自动展开，会中可手动查看。
- 重点卡片不占正文横向空间，翻译面板切换与窗口缩放保留收起状态；移除底部来源说明和空行动占位文字。
- “整理未完成”改为独立的窗口顶部居中悬浮 Toast，采用用户指定的浅黄色背景；桌面将图标、说明、重试与关闭横向单行显示，窄屏自然换行。关闭、收起重点卡片时，Toast 继续显示，不嵌入重点卡片或纪要正文。
- Toast 使用浅黄色警告背景并适配深色主题，保留失败原因、“重新整理”和关闭操作；同一失败关闭后不会因卡片变化或刷新重新弹出，新的失败任务可显示新提示。
- 重试期间保留上次整理的重点，并明确显示它是上次结果；整理未完成时不会误称已有最终重点。

## 下载与安装

安装包须由现有 GitHub Actions 后台工作流生成。此前直连通道被重置，使用既有本机代理的命令级通道后已恢复。按已核对基线推送 main 和新标签，等待后台 verify/build/publish 完成；请勿将候选版本号视为已发布证据。

发布后将在本页补充 Actions、Release、三平台安装包和更新清单的核验回执。已发布版本可从[版本列表](https://github.com/RoyalLiang/LingJi-Meeting-Studio/releases)查看。

## 验证边界

本轮仅调整重点阅读与警告展示，不修改录音起止、供应商调用、模型超时或纪要生成协议。真实模型超时、长会议及实体 WebView 的表现仍需分别验证。
