日期：2026-10-30。本标签 Windows 安装器因 C4324 严格编译失败，发布步骤跳过。标签保留，修复后改用 [v0.1.48](v0.1.48-preview.md) 发布。安装包地址须在 GitHub Actions 完成后核验，不能据此文档认定已有附件。

## 版本改动与修复

- 设置一级配置标题恢复绿色，纪要标题下移除状态与版本标识整行。
- 设置页标题右侧及首页侧边栏底部显示版本；配置读取期间保留服务模块，音频单模型模式下仍可查看独立转录服务选择器。
- AI纪要合并输入方式与对应模型配置，保留纪要模型和专用翻译模型的区分；简化选项文字，转录词表固定全局范围。
- 自动纪要默认每两分钟；修复文字多窗终稿把真实邻窗误判成旧证据的问题，主题结构失败采用有上限的自动重试。
- 同主题细项归组，保留完整讨论过程；主干连续连接各组，表格与图表作为分支内容展示，移除纪要阅读区的引用原文控件。
- 会议重点移至记录页右上方独立栏位，窄屏使用底部抽屉，仅在会议结束后自动展开；终稿完成前展示等待或失败状态，不把会中草稿当作最终重点。
- Windows 安装器遇到后台占用时可在同一次安装中重试，提示框沿用安装器背景和配色，安全退出后台后继续安装；静默安装与录音、补传保护保留。
