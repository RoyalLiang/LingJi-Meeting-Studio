# 聆记 v0.1.3：录音跳转与倍速测试版

提供源码和 macOS Apple Silicon 测试安装包，通过后台 GitHub Actions 构建并发布 GitHub pre-release。

## 系统与下载

- Apple Silicon Mac（M 系列），macOS 14.6 或更新系统。
- 下载 `Lingji-0.1.3-macos-arm64.dmg`、`SHA256SUMS.txt`、`release.json` 和本安装说明。
- 应用为 **聆记 Preview.app**，版本 0.1.3，macOS bundle 版本 0.1.25，内置 Node 24 后台。

将附件放在同一目录，运行 `shasum -a 256 -c SHA256SUMS.txt` 核对。源码 SHA、Actions 运行和实际包哈希见 `release.json`。

## 本版变化

- 按已确认的 A「一行完整控制」版式，将会议录音放在一体会议头部，常驻显示后退 15 秒、播放/暂停、快进 15 秒、进度、时间与倍速；窄屏换行以保留可操作尺寸。
- 两条已保存音轨统一跳转并在首尾截断；暂停时跳转保持暂停，播放时向后跳转能恢复此前已经结束的短音轨。
- 拖动时只预览位置，释放后统一定位；支持键盘方向键、Home/End 与 Escape 取消，避免拖动过程中反复请求媒体定位。
- 支持 0.75×、1×、1.25×、1.5×、2×，同时调整两条音轨并保持音高；播放失败通过气泡提供重试。
- 明确 Apple 开发者验证提示的原因与官方单应用授权步骤，详见[安全提示说明](https://github.com/RoyalLiang/LingJi-Meeting-Studio/blob/v0.1.3/docs/releases/macos-trust.md)。当前缺少 Apple Developer Program 账号，**本版仍未完成 Developer ID 签名与 Apple 公证，安全提示尚未消除**。

## 安装与升级

结束或暂停录音，等待待传队列排空，退出旧应用并备份 `~/Library/Application Support/com.tts.meeting`，再替换应用。Preview 与 Alpha 使用相同应用标识，不要同时运行。升级不恢复已过期清理的音频，也不改变会议留存授权。

将应用拖入“应用程序”。若显示无法验证开发者或无法检查恶意软件，核对来源及摘要后，可按[官方单应用授权步骤](https://support.apple.com/en-us/102445)从“系统设置 → 隐私与安全性 → 仍要打开”继续测试。无需关闭全局安全检查。出现恶意软件或损坏提示时不要强行打开。

## 验证边界

本版是 **ad-hoc 签名测试包，未经 Apple 公证**。构建与发布是否完成，以 Release 五附件和 Actions 回执为准。

播放器已用实际 React 组件和两条合成 WAV 在隔离浏览器验证，不等于在用户 Mac、Tauri WebKit、蓝牙设备或真实会议长录音上验收。当前改动不重构多次暂停/恢复音源的历史时间线。详见[本地验证](https://github.com/RoyalLiang/LingJi-Meeting-Studio/blob/v0.1.3/docs/evidence/playback-a-trust-2026-10-22.md)。
