# v0.2.7 测试版

日期：2026-11-01。候选已完成本地验证，待 GitHub Actions verify/build/publish 成功后补记发布回执。

## 版本改动与修复

本版合入已验证的 Pi 会议 agent 底座，修复全屏纪要高度、随手笔记位置、扩展中心改变整套外壳样式、导航文字不齐和 workspace 菜单挤占页面的问题。Windows 修复 WASAPI 跨进程成功返回被误判为失败；后台联动仍默认关闭，需要用户在设置中启用。详见[能力与验证边界](../engineering/workbench-capabilities-2026-11-01.md)。

远程 Skill 安装、MCP 插件、定时自动化和飞书云文档直发尚未接通。会议助手当前支持选择会议、内置复盘和带来源的独立结果。

## 下载与安装

发布后安装包入口：[macOS Apple Silicon](https://github.com/RoyalLiang/LingJi-Meeting-Studio/releases/download/v0.2.7/Lingji-0.2.7-macos-arm64.dmg)、[Windows x64](https://github.com/RoyalLiang/LingJi-Meeting-Studio/releases/download/v0.2.7/Lingji-0.2.7-windows-x64-setup.exe)、[Linux amd64](https://github.com/RoyalLiang/LingJi-Meeting-Studio/releases/download/v0.2.7/Lingji-0.2.7-linux-amd64.deb)。这些链接在 Release 发布前可能不可用。

macOS 14.6+；Windows 10/11。Mac 使用 ad-hoc 签名，正式 Developer ID/公证边界见[安装与信任](macos-trust.md)。实体 Chrome 后台启停、锁屏、真实长会议及安装行为未在本轮验证；发布后仅核对 CI、源码 SHA、标签、Release 和附件元数据，不下载、解包或安装附件。
