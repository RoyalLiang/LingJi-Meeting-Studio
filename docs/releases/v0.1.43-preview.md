# 聆记 v0.1.43 公开测试版

日期：2026-10-29。本轮修复录音保存状态与队列排空，恢复纪要小结背景并收紧设置布局。发布核验待 CI 完成后补记。

## 版本改动与修复

- 修复队列反复被唤醒时待上传音频无法推进的问题；结束会议后原音完成保存即可播放，无需等待转录和纪要。
- 修复空队列扫描被误报为正在保存音频、阻止安装更新的问题；真实未保存音频仍保留安装保护。
- 恢复树形纪要的小结和标题背景，保留说话人编号与来源图标；只有空标题的结果显示明确空状态。
- 逐字记录与纠错入口移入纪要标题栏，折叠后不单独占行；保留编辑草稿，减少隐藏转录的重复渲染。
- 移除会话顶部的原音、待保存、最新转录与纪要依据详情行；纪要和转录服务故障改用顶部浮层提示，不再挤占正文。
- 设置中的更新说明改为独立弹窗，减少版本更新区域高度，移除手动检查下方小字；统一版本、模型与转录、音频设置标题样式。
