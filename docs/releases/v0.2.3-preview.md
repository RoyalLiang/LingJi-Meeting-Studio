# 聆记 v0.2.3 Beta 测试版

变更日期：2026-10-30；发布核验：2026-10-31（北京时间）。本版按用户追加要求优化重点卡片、纪要阅读与桌面细节。五项 CI 及完整安装包校验通过，见[发布回执](../evidence/preview-v0.2.3-2026-10-31.md)和[验证记录](../evidence/ui-followups-2026-10-30.md)。

## 版本改动与修复

- 重点速览改为阅读区顶部居中的宽幅悬浮卡片，开关不再挤占正文空间；入口改为右侧中部图标按钮，并按开关状态淡出、淡入。
- 自动纪要默认刷新间隔改为 90 秒，保留已有会议的显式选择和停止排空规则。
- macOS 菜单栏图标缩至 18pt；版本号移到侧栏顶部品牌旁，去掉正常状态说明和“当前已是最新版本”文字行。
- 稳定备份待传音频入口；空队列只提示，不产生空备份文件，已有待传数据保留。
- 纪要阅读隐藏讨论过程留证项；补齐旧纪要缺少快照时的精确修订说话人映射，缺少身份时不再反复显示未知标签。
