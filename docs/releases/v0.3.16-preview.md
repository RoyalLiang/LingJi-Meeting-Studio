# 聆记 v0.3.16 测试版

## 本版变化

- 新增三栏工作台：项目导航、悬浮阅读画布与项目／本场会议上下文；窄屏使用抽屉。
- 优化浅色与柔和暗色、按钮、胶囊、卡片和过渡；扩展 Tab 固定显示。
- 支持纪要树与原文引用，提供纪要／转录并读和 Markdown 手记实时预览。
- 调整设置保存至右上角，连接检查按模块显示；MCP 探测保留已有批准与启用状态。
- 优化所有提示为统一高度的悬浮 Toast，长消息可展开，不推动正文。

## 下载与安装

从 [v0.3.16 发布页](https://github.com/RoyalLiang/LingJi-Meeting-Studio/releases/tag/v0.3.16) 选择对应平台安装包。发布状态与附件以该页为准，安装与配置见[桌面测试版说明](github-client.md)。
