# v0.3.37.0 测试版

## 本版变化

- 新增转录片段原音试听，可从时间旁直接播放该段保留的录音。
- 新增转录内的说话人标注，可仅保存本场称谓，也可在授权后将合格片段加入人物声音。
- 修复多人使用同一麦克风时，匹配结果过于接近或发言重叠仍被自动标名的问题。
- 修复同一人物反复学习同一片段时产生重复声音样本的问题。
- 人物与声音按人物查看声音来源，支持逐段试听和按需展开来源原文。
- 修复标注说话人后，已有原文草稿与片段版本冲突的问题。

## 下载与安装

支持 macOS 14.6+ Apple Silicon、Windows 10/11 x64、Ubuntu 22.04/24.04 x64。安装包与摘要以本版 Release 为准。

升级前结束录音、完成待保存音频、退出应用并备份完整数据目录（包含原音）。界面的 JSON 记录导出不含原音，不能用于旧版回退；会后原音归档后，回退须恢复升级前的完整数据目录。macOS 拖入 Applications；Windows 运行安装器；Ubuntu 使用 `sudo apt install ./Lingji-0.3.37.0-linux-amd64.deb`。

macOS 测试包使用 ad-hoc 签名，独立 Windows 安装包尚无商业 CA 签名。真实音频设备、供应商服务与旧数据迁移需分别验收。商店认证与独立安装包发布是不同渠道。
