# 聆记 v0.1.0：首次公开测试版

本次发布源码和 **macOS Apple Silicon 测试安装包**，用于试用与反馈。GitHub 标记为 pre-release；`v0.1.0` 是源码标签，不代表稳定版认证。

## 系统与下载

- Apple Silicon Mac（M 系列），macOS 14.6 或更新系统。
- 下载 `Lingji-0.1.0-macos-arm64.dmg`、`SHA256SUMS.txt`、`release.json` 和安装说明。
- 应用为 **聆记 Preview.app**，版本 0.1.0，macOS bundle 版本 0.1.23。内含 Node 24 后台，无需另装运行时。

将下载文件放在同一目录，再运行：

```bash
shasum -a 256 -c SHA256SUMS.txt
```

`release.json` 记录冻结源码 SHA、文件哈希、运行时与验证边界，请以实际附件为准。

## 安装与数据

1. 先结束现有录音，等待补传清空，再退出旧版。应用完全退出后，备份整个 `~/Library/Application Support/com.tts.meeting` 目录，避免复制使用中的 SQLite 文件得到不一致备份。
2. 打开 DMG，将 **聆记 Preview.app** 拖到 Applications，然后从 Applications 打开。
3. 首次授权麦克风和屏幕/系统音频，在设置中填写自己的 ASR/纪要服务配置。

此包采用 **ad-hoc 签名，未进行 Apple Developer ID 签名和公证**。若系统阻止打开，请核对来源和校验值，再按 [Apple 的未知开发者应用说明](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac)处理。不要关闭系统安全机制。

Preview 与 Alpha 的 bundle identifier 同为 `com.tts.meeting`，可能共享数据和授权状态，请勿同时运行。升级不会恢复已清理的原音；回退前保留本轮数据备份。卸载只移除应用即可，数据目录不会自动删除。

## 本版变化 / Changes

- 会议操作区采用紧凑同行布局，移除播放器右上角悬浮重置按钮。
- 停止录制后等待补传排空并刷新媒体，完整保存的原音可在转录未完成时播放。
- 增加纪要 Markdown 与分音源 WAV 导出；自动标题优先采用纪要名称，保护人工标题。
- 纪要分窗结合近期两分钟已确认转录，引用保持版本约束。
- 豆包识别显式关闭顺滑改写，按端点处理语言字段，支持用户填写术语及中英二遍识别背景。
- 增加离线 CER/WER 工具与核听标注方案；没有人工金标准时，不声明准确率提升百分比。

English: This first public preview includes a compact meeting toolbar, earlier playback of fully saved audio, Markdown/WAV exports, minutes-based automatic naming, two-minute confirmed-transcript context, explicit verbatim-oriented ASR settings, optional domain context, and offline evaluation tools. The macOS installer is ad-hoc signed and not notarized.

## 验证边界

源码的 Node 回归、ESLint、Web 类型检查/构建、文档检查及原生测试分别执行。打包检查 DMG、arm64、签名结构、源码冻结、包内后台及隔离数据启动/重启；数量与 SHA 以发布页及附件为准。

没有验证全新 Mac 的 Gatekeeper 首次安装、实体设备长会议、真实 ASR/LLM 质量、Postgres/S3 或 Windows/Linux 安装。本轮打包不替换现有 Alpha，不采集真实音频、不调用供应商。测试包不提供正式签名更新基线；本地签名校验通过不等于 Apple 公证通过。

## 从源码构建

```bash
npm ci
TTS_RELEASE_SOURCE_REF=<完整提交号> npm run release:macos:preview
```

同版本产物已存在时拒绝覆盖。构建复用本机安装的依赖，不宣称独立环境可复现。正式签名工作流仍使用 `client-v*` 标签及专用密钥，与本次测试版分开。见[项目首页](../../README.md)、[原生客户端](../engineering/native-client.md)和[正式发版流程](github-client.md)。
