# 聆记 v0.1.31 公开测试版

本版优化原音回放、会议计时和顶部布局。当前为发布准备，公开下载与后台安装验证以发布回执为准。

## 版本改动与修复

- 移除“点击加载回放”前置步骤，结束会议后直接显示播放与定位控件。原音使用 `preload=none`，点击播放才读取 WAV；后台读取精简波形，利用已保存时长在加载前定位。
- 状态和录音时长移到会议标题同行；创建日期、转录版本、留存与目录信息移到悬浮提示，移除独立元信息行。窄屏保留标题/状态同行，操作图标另占一行。
- 移除播放器中的“会议录音”“双音轨同步”文字，压缩波形与控制区，时间刻度和波形两侧增加内边距。播放、键盘定位和双轨控制保留。
- 扩展低频媒体时间更新时的进度插值窗口，覆盖0.75–2倍速的一秒采样，保留独立游标与静态波形。双轨开始播放前先对齐，并为重叠声音预留音量余量，保留标准音高校正及 WebKit 兼容字段。
- 重新整理只禁用本次提交按钮，不再将全页操作置灰；设置入口与失败提示共用防重复提交控制，成功、失败后均释放状态。
- 主窗与小窗会中计时采用单调时钟按秒显示，批量 PCM/上传回传不改变流速；暂停与结束显示实际保存音频时长，切换会议重置计时。
- 修复暂停续录与会中晚接入音源的起点错位：新音源以当前已保存会议时间为起点，回放 WAV 与波形虚拟补齐前导静音，支持共享时间定位；原 PCM、幂等标识和音频用量不变。Range 跳过无关音频块，虚拟静音按64KB有界输出。顺序片段不按总片段数降低音量。
- 首次定位后播放会等待各源真实媒体时长，排除已结束的短轨；暂停可取消等待，迟到加载不自动播放。失败后重试保留所选定位。
- 顶部连接文字与图标作为同一居中行，待保存数量放在独立定位行，保持连接主行与搜索框居中。

## 安装与验证边界

沿用三平台后台构建、同源清单、原生录音/重启与安装器门禁；安装包为 Windows x64 EXE、macOS Apple Silicon DMG、Ubuntu 24.04 x64 DEB。具体安装方式与未签名边界见[v0.1.30安装说明](v0.1.30-preview.md)。

浏览器验收使用合成会议和双轨正弦 WAV。音高与削波检查能验证所测数字输出，不能代表用户 Windows 音频设备、真人语音或所有倍速下的主观音质；浏览器原生拉伸算法仍可能产生音色变化。本版未更改历史音频或纪要内容。

晚接入音源使用服务端已持久化 PCM 进度，亚批次/网络延迟下的物理同步精度未在真机验收。已有会议保留原来的源起点元数据，不回写猜测的历史起点。
