# 聆记 v0.1.45 公开测试版

日期：2026-10-29。本轮在 v0.1.44 的 8 项修复之上继续调整树形连接层级与用量区文字。五项 CI 与四个公开附件核验通过，见[发布回执](../evidence/preview-v0.1.45-2026-10-29.md)。

## 版本改动与修复

- 树形主干从带背景的主题标题下方连续延伸，子卡片增加缩进；分支放在卡片背景后方重叠，消除贴边空隙，最后一支不再拖出多余主干。
- 保留主题标题和小结背景、正文垂直居中及说话人角落位置；说话人旁不显示来源图标。
- 移除供应商回传相关说明与“用量明细”文字，保留已保存录音、模型总量、输入/输出以及缓存、推理 token 数值。
