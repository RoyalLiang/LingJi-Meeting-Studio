# 安装聆记 macOS Alpha

此版本为 **0.1.0-alpha.14**，适用于 **Apple Silicon（M 系列）Mac，macOS 14.6 或更新版本**。安装包包含界面、原生音频采集及独立客户端后台；打开应用即可启动本机 Record API 和 worker，无需运行 Web 开发服务或安装 Node。

本版改用独立本机账户和数据目录，SQLite 与音频使用带校验的无损压缩。已有 Web 或旧 Alpha 的账户、会议、密钥和待补传队列不会自动迁入。升级前请结束旧会议并等补传完成，再替换应用；保留原后台及旧数据目录，以便查阅原有会议。

## Alpha 14：轻弹三点与麦克风直接接入

“当前正在聊”采用已选定的 6px 三点弹跳，仅在新发言或状态更新时播放，外框固定高度。快速更新不反复重启动画；暂停、离开会议和减少动态效果设置会停止动效。

新会议默认自动接入麦克风与系统音频。点击开启麦克风时不再因接入失败被强制带到音频来源选择框，错误原因直接显示，已接入的音源继续记录。macOS 首次使用或权限撤销仍由系统询问，不能自动接受授权。

## Alpha 13：会后学习评审

会议结束且转录排空后，自动生成意图与转录候选待标注结果。打开会议详情的“学习评审”，同一发言的五类意图和候选集中核对，原始转录可随时展开。口语重复仅做简洁显示，不改写保存的转录或引用。

训练须先保存人工标注，再核对训练计划并确认。界面只使用人工确认标签；缺失原音的转录候选不能作为已核听标签。后续结果保留新轮次供再次标注和回测。学习服务沿用已配置供应商和现有私有 wgs 环境，连接失败会保留错误供重试。

新录音默认保留原音。已经清理的旧原音无法恢复。安装新版本前结束现有录音并等待补传；本轮构建不会替换当前运行应用。操作和限制见[学习说明](../engineering/alpha-learning.md)。

## 安装并配置客户端

1. 打开 `Lingji-0.1.0-alpha.14-macos-arm64.dmg`。
2. 将 **聆记 Alpha.app** 拖到 **Applications**，从应用程序目录打开。
3. 应用自动使用本机账户。在 **设置** 中填写转录、纪要及翻译所需的服务地址、模型与密钥。
4. 完成配置后再开始需要云端识别或 AI 纪要的录音测试。

安装包不含开发环境的密钥、配置或会议数据；正式包也不使用旧 `client.json` 中的后台地址。关闭 Web 开发后台不会影响客户端本地保存与历史读取；云端转录和 AI 纪要仍需要网络及有效的供应商配置。

当前包采用 ad-hoc 签名，尚未完成 Developer ID 签名与公证。首次打开可能被 Gatekeeper 拦截；请按 [Apple 的首次打开说明](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac)处理，不要关闭系统安全机制。

## 保存本机数据

macOS 默认数据目录为 `~/Library/Application Support/com.tts.meeting`。独立后台在其 `backend/` 下保存 SQLite、音频对象和供应商配置；内置运行时为 Node 24.21.0，SQLite 3.53.4。关闭应用后，会议数据仍保留在本机。

SQLite 使用 WAL 与 FULL 同步保存记录、转录、纪要和任务；大段记录 JSON 与音频按收益使用无损压缩，无法有效压缩的内容保留原样。音频标识与校验仍依据原始 PCM，读取兼容旧原始对象。WebView IndexedDB 的 48 MiB 待传队列继续保留，收到本地后台持久 ACK 后移除已确认片段。

后台目录权限为 `0700`，供应商配置文件权限为 `0600`。密钥在 `backend/providers.json` 中以明文保存；压缩不等于加密。本版没有 Keychain 集成、跨设备同步或自动备份。不要删除数据目录来解决安装或启动问题。

原 Web/旧 Alpha 的数据与 profile 保留，独立后台使用单独的稳定 profile；后台端口改变不会更换新 profile。原环境的历史仍需通过原服务查看，本版不执行自动迁移。

## 开始测试录音

新会议默认接入系统播放音频与麦克风，可分别关闭。第一次采集可能触发 macOS 系统音频或麦克风权限提示；拒绝后会明确报错，后续由系统复用授权。应用不再重复弹出自有采集确认框；权限撤销或 ad-hoc 跨构建身份变化仍可能触发系统询问。系统音频可能包括其他应用声音。

暂停、继续与结束会议沿用现有协议。网络暂不可用时，音频可先保存到本机后台，供应商任务等待恢复；若本机后台不可用，待传队列仍有 48 MiB 上限，达到上限会明确停止并提示。应用重开会恢复中断任务；恢复能力不能替代长会话、设备拔插与休眠实测。

## 核对安装包

安装包旁的 `SHA256SUMS.txt` 保存文件校验值。在该目录运行：

```sh
shasum -a 256 -c SHA256SUMS.txt
```

`release.json` 记录版本、构建源文件哈希、Git 基线、内置运行时与验证范围。当前工作区模式可能包含未提交输入，不能仅凭 Git 提交号复现；按指定提交构建的模式会排除其他会话尚未提交的改动。

## 重新构建本地 Alpha

在项目根目录运行：

```sh
node scripts/release-macos-alpha.mjs
```

需要只打包指定已提交版本时，运行：

```sh
TTS_RELEASE_SOURCE_REF=<提交号> node scripts/release-macos-alpha.mjs
```

命令冻结构建输入，校验并准备随包 Node 与后台资源，在隔离目录构建 Web 和正式 Tauri 应用，再生成 DMG。安装验证使用临时应用副本和独立数据目录，不访问现有会议、重启已有服务、采集真实音频或调用真实供应商。同版本输出已存在时会停止，避免覆盖；下次发版需更新 `tauri.alpha.conf.json` 的 Alpha 版本、数字构建号和本说明。

产物位于 `dist/releases/0.1.0-alpha.14/`。验收需核对 DMG 完整性、arm64 架构、签名、权限描述、内置后台独立启动与重启持久化；本轮具体结果以产物及验证记录为准。合成压缩基准不代表真实语音的压缩率或模型总耗时。真实会议软件采音、长会话、全新 Mac 安装及 Gatekeeper 首次授权仍需实测。

退出应用后，可把 **聆记 Alpha.app** 移到废纸篓。配置、会议与待补传数据保留在应用支持目录，卸载时不要顺手删除。

## 菜单栏与安装界面

安装磁盘使用固定窗口、翡翠色背景和左右拖拽布局。将聆记拖到 Applications 后，从应用程序目录打开；安装说明与校验文件随下载提供。安装包图标由 `apps/desktop/assets/lingji-app-icon.svg` 生成；PNG/ICO 按文件哈希核对，ICNS 按内部图片块哈希核对。

macOS 顶部菜单栏使用随系统明暗变化的单色图标。左键打开聆记，右键查看会议、录音、后台连接与待上传音频数量，并使用暂停、继续本场、结束本场、设置、隐藏和退出操作。退出复用录音与补传保护；页面状态超过 5 秒未更新时，菜单标记待确认并停用会议操作。隐藏窗口会保留记录。

布局采用 [Tauri DMG 配置](https://v2.tauri.app/distribute/dmg/)，菜单使用 [Tauri 原生系统托盘](https://v2.tauri.app/learn/system-tray/) 和 [Apple 菜单设计规范](https://developer.apple.com/design/human-interface-guidelines/menus)。

## Alpha 7 会议页改进

- 默认显示树形 AI 纪要；生成过程可在整理设置中主动开启。
- 表格行按片段与修订引用放入对应主题；跨主题或无法唯一归属的内容保留在补充表格分支。主题卡片纵向留白约减少 10%。
- 登录请求防重入，等待会议空间初始化时保留登录表单。
- 回到顶部位于顶部工具栏；弹窗采用固定标题和独立滚动内容，优化小屏与明暗主题。
- 会议标题右侧新增原音入口；只播放已留存且处理完成的音轨，关闭弹窗会停止播放。不改变原音留存选择。
- 移除录音区重复的默认音源和自动纪要说明。

本轮 185 项 Node 回归、lint、类型检查与 Web 构建通过；隔离页面使用合成会议和 WAV 验证交互，未打开真实音频设备或调用外部供应商。详见[会议页验收](../evidence/client-ui-refinement-2026-10-13.md)。

## Alpha 8 界面细节

客户端左上角使用与应用图标同源的紧凑 SVG，移除小尺寸柔化滤镜并提高图形占比。弹窗与翻译、纪要侧栏统一使用中央关闭符号和旋转齿轮外圈；鼠标悬停和键盘焦点触发动效，减少动态效果偏好会关闭旋转。选择框增加短暂展开、收起过渡，区分悬停与选中并保留键盘操作。

185 项 Node 回归、ESLint、类型检查和 Web 构建通过；明暗主题、1x/2x Logo、关闭按钮及选择框交互已在隔离 Chromium 验证。WebKit 版本不匹配，原生动效尚未实测；无过渡的降级交互已验证。详见[本轮验收](../evidence/client-ui-polish-2026-10-13.md)。

## Alpha 9 修订

关闭齿轮放大并持续旋转，普通反馈自动消失，系统 WebKit 选择框焦点与收起闪影已修复。纪要表格增加明确主题归属，页面统计使用索引；后台减少会中重复计算并并行独立分窗。旧纪要不自动重写，需重新整理后获得新表格归属格式；当前运行客户端不自动替换。详见[原生动效与纪要验收](../evidence/native-ui-minutes-2026-10-13.md)。

## Alpha 10 修订

- 新会议录制前可选择“保留原音供回放”，记住本机偏好；默认关闭。历史原音已清理时提前显示不可恢复，不再提供误导的播放动作。
- 关闭齿轮默认和悬停保持透明边框，键盘焦点仍可见；整理失败提示保留但禁止选中文字。
- 更新策略改三档下拉，菜单栏支持检查更新、后台下载开关与手动重启更新。旧自动安装偏好关闭；当前本地 Alpha 没有可信更新源，需手动安装。
- 修复摘要汇总误用转录分窗上限，独立汇总预算最高96KB；保留所有正文、表格和引用，确实超限时明确失败。

验收结果见[Alpha 10 修订证据](../evidence/client-controls-alpha10-2026-10-13.md)。

## Alpha 11 修订

- 新录音默认保存原音，移除留存勾选与重复说明；原音入口固定简洁按钮。历史已清理文件不会回补。
- 修复空白关闭弹窗后的大焦点边框，跟随按钮独立占流且无正文时隐藏。
- 会后默认阅读智能纪要，隔离旧会中失败；暂时性终稿失败有限重试。
- 未命名记录提取关键词自动命名，人工标题受保护。
- 引用来源显示精确版本的上下文，分享支持草稿及客户端文件导出。

详见[Alpha 11 会议体验验收](../evidence/client-meeting-alpha11-2026-10-13.md)。

本版另移除音源接入前重复自有授权确认，保留macOS系统首次与撤销权限；对齐连接状态、备份间距、弹窗标题/字段和单层候选边界。纪要底部新增实际供应商token及音轨累计时长，未知与实报零明确区分。

## Alpha 12 修订

- 向上阅读纪要时保持暂停跟随，后续整理更新不再把页面拉回底部。
- 原生快速记录自动使用仍可用的已保存麦克风，失效时回到安全默认输入；保留真实系统授权与设备错误。已有音源成功时不强制打开选择弹窗，失败音源仍提示。
- 菜单栏移除冗长更新说明，无可信源时隐藏自动下载项；重启更新仅在新包完成下载、验签并完整暂存后显示，录音与补传安装门禁保留。
- 合并重复的纪要整理入口，保留右上整理设置，减少空态和正文遮盖。

Alpha11对应WebKit组件已追加14项真实前台动效验证；macOS系统授权窗口的整体模糊仍未确认修复，跨版本授权复用仍受当前ad-hoc身份限制。
