# 聆记 v0.1.28 公开测试版

本轮优化小窗麦克风控制、纪要回显和阅读布局，并修复结束会议丢失已显示内容。Windows原生冒烟选择器失配，未发布安装包。失败[Actions 40490847501](https://github.com/RoyalLiang/LingJi-Meeting-Studio/actions/runs/40490847501)与标签保留；由[v0.1.30](v0.1.30-preview.md)重新验证发布。

## 本版行为

- 悬浮录音窗增加麦克风按钮，复用主窗的关闭/开启控制。关闭麦克风仍可继续记录会议音轨；只有麦克风时按原流程暂停；暂停/忙碌时禁用小窗麦克风按钮。
- 结束会议前先把仍在运行任务中的已校验分窗保存为会中纪要，保留原文版本、人工保护与更正检查，再让终稿替换。留空名称不会让已显示内容变空；未校验的流式文字仍不能作为正式纪要。
- 原音改为点击“打开原音回放”后再读取音频与波形；结束时不立即触发全源读取。展开后沿用原有播放、定位和倍速，更名不重新加载；尾部字节定位仅读取命中的原音块，避免遍历读取前面的音频。
- 修复流式正文在200ms节流窗口内到达、随后模型长暂停时未回显的问题，补齐尾部发布。切换窗口流、完成、失败与取消时清理定时器，保留任务栅栏。
- 所有讨论详情默认展开，移除主题与细节折叠按钮。每段右上角显示冻结引用片段的说话人，支持多人；没有标注时明确显示“说话人未标注”，引用缺失显示“来源待核对”。不按音轨猜人名。
- 学习评审、导出和删除统一放在顶部工具栏，移除底部操作块与重复导出；到期日期保留在留存天数提示中。
- 底部整理状态改为44px单行，长文字省略；清除纪要标题下的会中更新标签和重复说明。
- 保存每场纪要的阅读位置与跟随意图；重新打开保留上次位置，主动回到最新内容后继续跟随。只在本机浏览器存储记录ID对应的位置，不保存正文。
- 连接图标与标签同排对齐，队列数量继续独立显示。
- 新会议默认每60秒整理；已有会议保存的间隔保持原值。首次有转录时仍最多等待30秒。生成过程默认关闭；已校验分窗结果仍可提前显示，用户可以在整理设置中开启未校验生成过程。

## 关于等待约五分钟

已确认超时按单次模型请求计算：会中120秒，终稿或暂停补齐240秒；多窗口及最终汇总可有多次调用，加上转录、调度与重试，总耗时可能超过上述数值。没有会议五分钟硬截止。已复现并修复收到正文后节流不发布的路径，不能据此断言用户真实Kimi的全部等待均由该原因造成。关闭生成过程时，要等窗口结果校验后才显示内容。

## 安装与验证边界

本地完整回归、浏览器和独立复核结果将在发布回执中记录。

Windows x64 和 macOS Apple Silicon 测试安装包由现有 GitHub Actions 后台构建。当前没有替换用户安装或读取原会议数据；真实Kimi首字/完整结果耗时、真实Windows麦克风/缩放仍需现场验证。Windows测试包未代码签名，macOS ad-hoc签名且未公证。
