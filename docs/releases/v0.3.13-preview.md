# v0.3.13 测试版

从 [v0.3.13 发布页](https://github.com/RoyalLiang/LingJi-Meeting-Studio/releases/tag/v0.3.13) 选择对应平台安装包：macOS Apple Silicon DMG、Windows x64 安装器或 Linux amd64 DEB。发布状态和附件以该页为准。

## 本版变化

- 恢复玉色渐变背景、录音区域的玻璃底色和紧凑工具布局。
- 翻译侧栏在窄窗口中切换为弹窗，阅读区域与底部状态条保持对齐。
- 优化长会议流式纪要、单句翻译和录音连续写入的响应。
- 保留录音计时、说话人浮置标签、扩展中心吸顶菜单和统一提示高度。

## 使用说明

系统权限、真实声卡和云端供应商响应仍取决于设备及服务配置。安装与使用见[桌面测试版说明](github-client.md)。
