## 系统与安装包

- Apple Silicon Mac（M 系列），macOS 14.6 或更新系统。
- 下载 `Lingji-0.1.7-macos-arm64.dmg`、`SHA256SUMS.txt`、`release.json` 和安装说明。
- 应用为 **聆记 Preview.app**，版本 0.1.7，macOS bundle 0.1.29，内置独立 Node 24 后台。

附件放在同一目录，运行 `shasum -a 256 -c SHA256SUMS.txt`。源码 SHA、Actions 和包哈希见 `release.json`。

## 本版变化

新增“仅豆包音频模型 · 转录＋纪要，无需 ASR”：同一方舟模型和密钥短批次转录留证，再结合原音生成带版本引用的纪要。无需独立语音识别服务，不会受到原 ASR 的时长配额拒绝影响；方舟自身额度和计费仍适用。原三种模式继续保留。

继承 v0.1.6 的免填资料快速记录、双音轨会议时长修正与独立 ASR 配额提示。原音授权、人工修订保护、停止尾段排空、持久确认与重传身份保留。独立 ASR 失败历史只在用户显式重新处理后补识别。

## App 配置方式

打开“设置与诊断 → 模型与转录服务”：

| 设置项 | 值 |
| --- | --- |
| 会议理解 | 仅豆包音频模型 · 转录＋纪要，无需 ASR |
| 模型协议 | Responses |
| 模型服务地址（完整接口） | `https://ark.cn-beijing.volces.com/api/v3/responses` |
| 模型 / 接入点 ID | `doubao-seed-2-1-lite-260915` |
| 方舟 / 兼容模型 API Key | 填写自己的方舟密钥 |

点击“保存服务配置”，再测试转录和纪要。无需再填写独立 ASR 语音密钥；原配置保留供切回使用。密钥保存在自己的 App 后端，留空保存会保留已有密钥。

快速记录直接开始未命名会议。录音后打开“整理设置”，开启“自动 AI 纪要”，允许本场原音用于豆包转录与纪要；授权前只保存采集内容。此模式约每 15 秒形成短批，停止或暂停会排空尾段，不属于供应商流式 partial。关闭自动纪要只停止纪要更新，已授权的模型转录继续；结束录音停止采集。

**之前显示语音配额错误的会议**：切换并保存新模式后，先在整理设置允许本场原音处理，再在语音处理提示中点击“重新处理”。保存期内仍存在的原音可以补识别，已经清理的音频不能恢复。完整说明见[仅豆包模式](https://github.com/RoyalLiang/LingJi-Meeting-Studio/blob/v0.1.7/docs/engineering/doubao-audio-only.md)。

## 升级

暂停或结束录音并等待上传排空，退出旧应用，备份 `~/Library/Application Support/com.tts.meeting` 后替换。Preview 与 Alpha 使用相同标识，不要同时运行。升级不会自动改为新模式或批量重放失败会议。

应用拖入“应用程序”。本版仍为 **ad-hoc 签名、未经 Apple 公证的测试包**，信任提示见[macOS 安全说明](https://github.com/RoyalLiang/LingJi-Meeting-Studio/blob/v0.1.7/docs/releases/macos-trust.md)。
