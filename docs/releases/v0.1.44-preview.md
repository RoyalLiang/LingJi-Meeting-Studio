# 聆记 v0.1.44 公开测试版

日期：2026-10-29。本轮修复专家评审确认的 8 项问题，减少后台空转、长会议排队和重复渲染。发布状态以发布回执为准。

## 版本改动与修复

- 修复原生录音出现设备错误或输入缓冲溢出时，已接收的尾音没有写入保存队列的问题；错误仍明确上报，尚未确认的音频仍受保护。
- 为豆包流式发送加入超时和取消处理，连接卡住后释放处理占用，保留待处理音频并重试。
- 按转录、纪要及学习任务独立轮转待办，避免前 100 条旧任务长期阻塞后续会议。
- 将长会议音频前序检查改为一次索引；目录分析只读取轻量输入，避免反复解压已完成会议。
- 转录水位、预览和纪要计时更新时复用历史内容；按片段与修订索引主题，减少重复扫描。
- 纪要编辑只更新发生修改的章节和条目，保留原有引用及未修改内容，避免每次输入复制整份纪要。
- 恢复树形主题标题的背景与圆角分支连线，保留小结背景和居中正文；说话人编号置于卡片角落，移除其旁的来源图标。
- 统一模型与转录设置的标题颜色、输入和下拉框边界；版本仅显示一个胶囊，有更新时在右上角显示升级箭头。
