# 聆记 v0.1.32 公开测试版

本版修复 Preview 的自动检查与自动下载，精简设置界面。当前为待发布源码；Actions、安装包和校验结果将在发布回执中记录。

## 版本改动与修复

- Preview 原先因缺少正式签名更新源而一直禁用更新。现在从本仓库公开 Release 订阅源发现新版本，读取版本固定的 preview-update.json，自动检查或后台下载安装包。客户端不使用 GitHub 公共 API 配额，也不需要 GitHub 登录。
- 下载安装包时核对固定仓库 URL、HTTPS、文件大小和 SHA-256。中断或校验失败会丢弃临时文件，按 15 分钟间隔重试；变更更新策略立即生效。缓存复用一个安装包文件，避免逐版占用磁盘。
- 下载完成后由你点击“打开安装包”，打开前再校验文件并核对录音、暂停和补传状态。Preview 的完整性校验不等于独立更新签名；现有正式签名更新链路仍使用原有验签流程。
- 移除设置页重复说明，保留错误、保存反馈、缺失模型和安装阻止状态。保存、测试、更新和诊断按钮固定在底部，空间足够时同排显示，只有设置字段区域滚动。
- 音频设置标题、设备选择与测试按钮在桌面同一行显示。“本次同步翻译”改为“自动翻译”，补齐翻译图标，标题和目标语言同一行；仍按当前会议保存，不会自动替后续会议开启。
- macOS 状态栏图标由底层默认 18 pt 调整为 22 pt，保持比例和系统模板色，弥补原图透明留白造成的视觉偏小。
- 推理强度统一显示“自动 / 低 / 中 / 高 / 更高”。旧界面“模型默认 / 最高”分别在设置中归为“自动 / 更高”，显式保存后采用新选择；后端保留旧 API 值兼容。
- 移除豆包 AST 旧版双密钥选项、识别实现、旧协议资源和独占依赖。原已配置 AST 的客户端读取设置时切到新版豆包配置入口，旧 App Key/Access Key 不会被当作 API Key；请配置新版语音 API Key 或选择其他已安装服务。会议数据与原有转录保留。
- 增加[多语种识别与目标语言翻译研究](../research/multilingual-auto-translation-2026-10-27.md)，区分模型实际支持范围、当前实现与待验方向；本版不宣称完成多语种模型改造。

## 安装与升级

旧 Preview 包没有可用更新通道，需要手动安装一次本版，之后才可使用修复后的自动检查与下载。结束录音、等待补传完成、备份重要记录，并从托盘菜单退出客户端后再覆盖安装。Windows 安装器会拒绝覆盖正在运行的程序及后台。

- macOS Apple Silicon，macOS 14.6+：`Lingji-0.1.32-macos-arm64.dmg`，将应用拖入 Applications。
- Windows x64，Windows 10/11：`Lingji-0.1.32-windows-x64-setup.exe`，默认安装本地模型。
- Linux x64，Ubuntu 24.04：`Lingji-0.1.32-linux-amd64.deb`，使用 `sudo apt install ./Lingji-0.1.32-linux-amd64.deb`。

Release 还包含 `preview-update.json`，供客户端自动下载校验；它不是安装包。SHA-256 在 Release 正文中。macOS 包仍为 ad-hoc 签名、未公证，Windows 未代码签名；[macOS 系统信任说明](macos-trust.md)继续适用。

## 验证边界

本地 Node 24 回归、Rust 单测、类型检查、lint 与 Web 构建，以及隔离浏览器设置保存、滚动和目标语言保存分别记录。三平台构建与包内验证由现有后台 GitHub Actions 执行；只有成功后才记录为已发布。

真实会议、多语种混说质量、付费 ASR/LLM、全新电脑安装和实体三平台跨版本升级仍需单独验收。本版不会自动安装或静默重启，也不更改用户会议数据。
