## 已验证范围

- 158 项 Node 回归及 7 项 Rust 测试通过。首次沙箱运行因禁止监听本地端口失败，在允许隔离本机端口的环境重跑后全部通过。
- ESLint、TypeScript 和 Web 生产构建通过；文档链接及代码围栏检查通过。
- DMG 完整性校验通过。只读挂载后，把应用复制到临时安装目录，arm64 架构、严格签名校验、系统最低版本及两项音频权限描述检查通过。
- 安装副本成功启动内置 React，并向隔离 API 请求 bootstrap。正式二进制不含测试探针标记，也忽略模拟环境变量；本次没有打开真实音频设备或调用真实供应商。
- 应用使用本机 ad-hoc 签名，未使用 Developer ID，未公证。包内不包含 Record API、worker、模型密钥或用户会议数据。

安装包声明最低 macOS 14.6，但这次仅在 15.7.4 上运行；不能把元数据检查视为 14.6 实机兼容证据。
