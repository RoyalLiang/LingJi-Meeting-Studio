# 聆记 v0.1.6：快速记录与时长修复测试版

提供源码和 macOS Apple Silicon 测试安装包，由后台 GitHub Actions 构建并发布 GitHub pre-release。实际发布状态以 Release 和 Actions 回执为准。

## 系统与下载

- Apple Silicon Mac（M 系列），macOS 14.6 或更新系统。
- 下载 `Lingji-0.1.6-macos-arm64.dmg`、`SHA256SUMS.txt`、`release.json` 和本安装说明。
- 应用为 **聆记 Preview.app**，版本 0.1.6，macOS bundle 版本 0.1.28，内置 Node 24 后台。

将附件放在同一目录，运行 `shasum -a 256 -c SHA256SUMS.txt` 核对。源码 SHA、Actions 运行和实际包哈希见 `release.json`。

## 本版变化

- 修复豆包音频与 OpenAI Realtime 模式的“快速记录”跳转到建会表单：现在点击即可创建未命名会议并申请音源权限，无需填写会议名称等资料。
- 快速记录的原音发送独立授权：音频模式先录音和转录，在“整理设置”开启自动 AI 纪要后才允许原音进入纪要模型；空状态提示该入口。
- 会议头部改用统一音频时间轴，不再将平行麦克风与会议音轨时长相加：22 分钟麦克风加 18 分钟会议音轨显示 22 分钟，暂停后续录继续衔接。多音轨累计用量另列于诊断。
- 对豆包语音服务 `45000292` 明确显示配额超限，帮助区分独立 ASR 与方舟纪要模型连接。
- 原 ASR＋LLM 模式保持快速记录自动纪要。豆包接口、识别服务、溯源与人工修订保护保留。

## 豆包配置

打开“设置与诊断 → 模型与转录服务”：

| 设置项 | 值 |
| --- | --- |
| 会议理解 | 豆包音频 · 直接理解＋转录留证 |
| 模型协议 | Responses |
| 模型服务地址（完整接口） | `https://ark.cn-beijing.volces.com/api/v3/responses` |
| 模型 / 接入点 ID | `doubao-seed-2-1-lite-260915` |
| 方舟 / 兼容模型 API Key | 填写已开通该模型的方舟密钥 |

点击“保存服务配置”，再点击“测试纪要”。密钥在你自己的 App 服务端配置，不随安装包分发。转录服务继续使用原 ASR 地址和语音密钥，方舟模型密钥不能代替语音 ASR 密钥。

快速记录无需填写资料。开始后，打开“整理设置”并开启“自动 AI 纪要”，允许本场原音发送。使用“提前准备会议”时仍可勾选“自动生成 AI 纪要”。既有会议可在“整理设置”中开启或明确选择手动 AI 整理。音频已过期或已清理的会议不能重放为音频纪要。完整说明见[豆包音频配置](https://github.com/RoyalLiang/LingJi-Meeting-Studio/blob/v0.1.6/docs/engineering/doubao-audio.md)。

## 安装与升级

结束或暂停录音，等待待传队列排空，退出旧应用并备份 `~/Library/Application Support/com.tts.meeting`，再替换应用。Preview 与 Alpha 使用相同应用标识，不要同时运行。升级不恢复已过期清理的音频，也不改变会议留存授权。

将应用拖入“应用程序”。本版仍为 **ad-hoc 签名测试包，未经 Apple 公证**。核对来源和摘要后，可按[Apple 官方单应用授权步骤](https://support.apple.com/en-us/102445)继续测试；安全提示说明见[macOS 安全提示](https://github.com/RoyalLiang/LingJi-Meeting-Studio/blob/v0.1.6/docs/releases/macos-trust.md)。

## 验证边界

本轮 391 项 Node 回归、ESLint、TypeScript 和 Web 生产构建通过；两条新增回归直接执行快速记录函数，覆盖豆包音频、OpenAI Realtime 的免填表启动及独立授权。规范和需求独立审查无发现。

当前安装配置的合成会话诊断证实，独立 ASR 返回 `45000292`，详情为 `quota exceeded for types: audio_duration_lifetime`。方舟纪要模型的合成静音测试通过。此服务配额故障需要在语音服务控制台处理，安装更新不会增加供应商额度。额度恢复后可在语音处理提示中点击“重新处理”，补处理保存期内的原音。实体 App 的真实采音和长会议仍需独立验收。包体、签名、完整性与隔离启动结果以本版 Actions 和 `package-smoke.json` 为准。
