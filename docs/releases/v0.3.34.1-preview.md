# v0.3.34.1 测试版

## 本版变化

- 修复深色模式下录音悬浮框未跟随主题及边角白底的问题。
- 修复 Windows、Linux 窗口底色与工作台主题不同步的问题。
- 统一表单、按钮和状态标签的文字对齐与尺寸，设置页签改用轻量胶囊样式。

## 下载与安装

支持 macOS 14.6+ Apple Silicon、Windows 10/11 x64、Ubuntu 22.04/24.04 x64。安装包与摘要以本版 Release 为准。

升级前结束录音、完成待保存音频、退出应用并备份完整数据目录（包含原音）。界面的 JSON 记录导出不含原音，不能用于旧版回退；会后原音归档后，回退须恢复升级前的完整数据目录。macOS 拖入 Applications；Windows 运行安装器；Ubuntu 使用 `sudo apt install ./Lingji-0.3.34.1-linux-amd64.deb`。

macOS 测试包使用 ad-hoc 签名，独立 Windows 安装包尚无商业 CA 签名。真实音频设备、供应商服务与旧数据迁移需分别验收。商店认证与独立安装包发布是不同渠道。
