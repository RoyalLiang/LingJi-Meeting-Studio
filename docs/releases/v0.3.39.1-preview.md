# 聆记 v0.3.39.1 预览版

## 本版变化

- 修复 macOS TestFlight 安装包中的资源访问权限，确保普通用户可以验证应用签名。

## 下载与安装

支持 macOS 14.6+ Apple Silicon、Windows 10/11 x64、Ubuntu 22.04/24.04 x64。独立安装包与摘要以本版 Release 为准，TestFlight 可用性以 Apple 的处理和测试组状态为准。

升级前结束录音、完成待保存音频、退出应用并备份完整数据目录（包含原音）。界面的 JSON 记录导出不含原音，不能用于旧版回退。

macOS 独立版拖入 Applications；Windows 运行安装器；Ubuntu 使用 `sudo apt install ./Lingji-0.3.39.1-linux-amd64.deb`。从 DMG 切换到 TestFlight 会改用沙盒数据目录，不会自动迁移旧数据，先阅读 [TestFlight 安装与数据说明](../engineering/macos-testflight.md#使用商店版)。
