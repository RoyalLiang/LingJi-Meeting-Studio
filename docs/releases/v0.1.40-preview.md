# 聆记 v0.1.40 公开测试版

日期：2026-10-29。修复纪要内容过少及部分结果替换完整文档的问题，保持既有树形卡片，仅展示说话人编号。五项CI与四个公开附件核验通过，见[发布回执](../evidence/preview-v0.1.40-2026-10-29.md)。

## 版本改动与修复

- 已有完整纪要在新任务运行时继续显示；修改笔记后停止会议，不再用首窗结果替换完整文档。
- 多窗汇总保留分段讨论、原主题和表格关系，避免只剩少量概要；历史过程不会变成当前待办。
- 本地提取保留普通事实，修复前12段限制、命中行动后漏掉其他事实以及多窗行动数量溢出。
- 修复把模型长度截断的JSON当成完整结果提交的问题。
- 纪要正文、表格、发言人总结统一显示“说话人1、说话人2、说话人3…”，保持原有树形卡片、字号和间距；表格来源图标不再重叠。

## 安装与旧纪要恢复

- [macOS Apple Silicon DMG](https://github.com/RoyalLiang/LingJi-Meeting-Studio/releases/download/v0.1.40/Lingji-0.1.40-macos-arm64.dmg)：macOS 14.6+。
- [Windows x64 安装程序](https://github.com/RoyalLiang/LingJi-Meeting-Studio/releases/download/v0.1.40/Lingji-0.1.40-windows-x64-setup.exe)：Windows 10/11。

旧纪要需打开对应会议并重新整理，才能生成修复后的完整版本。有效分段缓存可以复用；缓存缺失或输入变化时需要模型重新生成。结束录音、完成补传并退出旧客户端后安装。macOS ad-hoc及Windows未签名限制不变，见[信任说明](macos-trust.md)。
