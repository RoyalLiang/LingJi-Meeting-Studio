# 聆记 v0.2.1 Beta 测试版

日期：2026-10-30。Beta 测试版已通过 GitHub Actions 发布，官网已上线。三平台安装包已完整下载核对 SHA-256；[线上核验回执](../evidence/preview-v0.2.1-2026-10-30.md) 列出源码、工作流、真实登录与分享检查，以及浏览器上传和真实会议验收缺口。

## 版本改动与修复

- 补齐 Pages 创建的正式/预览环境配置；服务端 5xx 最多重试三次，每次先读回项目并核对所有权，403 等权限错误不重试。Cloudflare 错误详情输出前屏蔽已知密钥。保留 v0.2.0 标签，其首次官网部署在创建项目时返回 HTTP 500。

- 增加官网、仅 RoyalLiang 可登录的 GitHub 发布门户和可撤销的 24 小时在线纪要快照。桌面导出后在浏览器预览并确认，默认仅纪要及引用原文，全部转录需另选，不上传原音。官网目标 rookiecode.com，快照存入 D1，本版不启用 R2；在线文件上限 1 MiB。
- 接入通用场景词表及有来源的汉字读音包，为账户/目录词表提供同音候选，明确已检查范围，保留人工确认与修订保护。
- 修复同步密码派生、伪造签名、Unicode 截断、分享全集扫描、无效令牌无界查询、空闲任务重复事务和桌面 Realtime 排空边界。
- 继承 v0.1.49 的设置、学习、翻译与纪要修复，保留既有仅纪要正文分享默认。
