# v0.3.36.0 测试版

## 本版变化

- 新增逐人授权的声纹自动深化。会后可从保留原音且已人工确认的发言中补充声音样本。
- 新增按内容选用的纪要总结卡片，涵盖决策、行动、风险、待确认事项、时间节点与数据对比。
- 新增飞书纪要人物标记，随选定的原文引用带入已匹配或已确认的参会人。
- 修复 Windows 商店版任务栏和开始菜单可能显示额外图标底板的问题。
- 修复 Windows 首次启动遇到系统占用的本机端口时退出的问题。

## 下载与安装

支持 macOS 14.6+ Apple Silicon、Windows 10/11 x64、Ubuntu 22.04/24.04 x64。安装包与摘要以本版 Release 为准。

升级前结束录音、完成待保存音频、退出应用并备份完整数据目录（包含原音）。界面的 JSON 记录导出不含原音，不能用于旧版回退；会后原音归档后，回退须恢复升级前的完整数据目录。macOS 拖入 Applications；Windows 运行安装器；Ubuntu 使用 `sudo apt install ./Lingji-0.3.36.0-linux-amd64.deb`。

macOS 测试包使用 ad-hoc 签名，独立 Windows 安装包尚无商业 CA 签名。真实音频设备、供应商服务与旧数据迁移需分别验收。商店认证与独立安装包发布是不同渠道。
