# 聆记 0.3.9 测试版

从 [v0.3.9 发布页](https://github.com/RoyalLiang/LingJi-Meeting-Studio/releases/tag/v0.3.9) 选择对应平台安装包：macOS Apple Silicon DMG、Windows x64 安装程序或 Linux amd64 DEB。发布状态和附件以该页为准。

安装包自带本机后台，无需另装 Node 或启动开发服务。Windows 可选择是否安装本地语音模型；跳过后需自行配置可用的云端识别服务，应用不会自动替你上传录音。

## 本版变化

- 本地字幕先显示实时草稿，再校正为正式原文；相同说话人的连续发言保留上下文。
- 改进长会议保存、搜索、录音补传和长音频导入，长原文滚动保持流畅。
- 桌面录音支持关闭主窗口后继续、恢复工作台，以及在支持的系统选择应用声音。
- 麦克风增加降噪，并使用已选择的会议声音进行回声消除。
- 说话人区分支持主动登记、撤销目录声纹，并由用户确认姓名。
- 目录知识支持跨会议提问、查看准确出处，来源变化后提示重新提问。
- 飞书与 Git 任务使用统一的预览、确认、进度和恢复约定。

- 统一界面字号与按钮点击区域，补齐错误提示和窄屏显示。

## 开始记录

在音频设置选择会议声音范围和麦克风。macOS 与支持版本 Windows 可以选择应用；Windows 按应用录音需要 build 20348 或更高版本，Linux 需要正在运行的 PulseAudio 或 PipeWire Pulse 服务。应用退出或选择失效时会要求重新选择，不会改采系统所有应用。

录制时可独立关闭麦克风。关闭主窗口后可通过原生控件暂停或结束，重新打开会恢复工作台。系统权限、录音告知、原音留存和云端发送是分别控制的事项。

## 本地字幕与目录知识

本地中文、英文字幕先显示草稿，再形成正式原文。说话人区分是模型估计；跨会议姓名声纹需要主动登记，并人工使用候选。目录首页可确认知识、查看出处和提问；回答仅依据命中的相关会议，来源更新后需要重新提问。

支持格式的长音频按片段导入。缺少 AudioDecoder 的内核有额外文件、时长和内存边界，提示超限时请拆分文件或使用支持的内核，见[存储与性能边界](../engineering/storage-and-performance.md)。

## 数据与使用边界

升级时会在数据目录创建迁移前数据库备份。回退旧版需要停止后台，并恢复与旧版本匹配的完整备份，不要用旧版直接修改升级后的数据库。

平台构建、自动化检查和公开语音样例不能代替真实会议、物理设备或声学校准。首次安装、系统权限及应用声音隔离仍应在实际使用环境核对。macOS 测试包的签名与更新条件见[安装测试版](github-client.md)。
