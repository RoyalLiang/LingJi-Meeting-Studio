# 聆记 v0.1.42 公开测试版

日期：2026-10-29。修复纪要在汇总、显示、修订与导出中丢失内容的问题，保持既有树形卡片与说话人编号。三平台CI与发布附件核验进行中。

## 版本改动与修复

- 完整纪要在新任务运行期间继续显示；修改笔记后停止会议，不再用首窗结果替换完整内容。
- 保留分段讨论、原章节与项目上下文，不再因共用原文或文字相同而合并丢失；保留待确认、风险和撤回等语义。
- 正文与修订包含表格、主题和时间线中的独有内容；无改动保存保留原结构，实际修订保留正文与引用，用户删除后不再自动补回。
- 行动候选保留项目标签、主题及待确认状态，正文、表格和导出使用一致上下文；完整长行动文本不截断。
- 修复长正文保存失败及长文本分块损坏扩展汉字的问题；修订不再重复上传冻结原文。
- 纪要、发言人总结和Markdown统一显示“说话人1、说话人2、说话人3…”，保留冻结修订的归属；树形卡片的字体、配色和间距不重新设计。
- 本地提取保留普通事实；模型长度截断不再被当作完整结果提交，历史过程不重新成为当前待办。

## 安装与旧纪要恢复

- [macOS Apple Silicon DMG](https://github.com/RoyalLiang/LingJi-Meeting-Studio/releases/download/v0.1.42/Lingji-0.1.42-macos-arm64.dmg)：macOS 14.6+。
- [Windows x64 安装程序](https://github.com/RoyalLiang/LingJi-Meeting-Studio/releases/download/v0.1.42/Lingji-0.1.42-windows-x64-setup.exe)：Windows 10/11。
- [Linux amd64 DEB](https://github.com/RoyalLiang/LingJi-Meeting-Studio/releases/download/v0.1.42/Lingji-0.1.42-linux-amd64.deb)：Ubuntu 24.04。

旧短纪要需要打开对应会议，在“整理设置”中重新整理。有效窗口缓存可以复用；缓存缺失或输入变化时需要模型重新生成。结束录音、完成补传并退出旧客户端后安装。macOS ad-hoc及Windows未签名限制不变，见[信任说明](macos-trust.md)。
