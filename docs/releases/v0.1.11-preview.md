# 聆记 v0.1.11：C 波形回放与采集连续性测试版

已通过现有 GitHub Actions 发布 Apple Silicon 测试包，verify、build、publish 全部成功；五附件与 227 个源码摘要已核对。见[发布核验回执](../evidence/preview-v0.1.11-2026-10-23.md)。v0.1.8～v0.1.10 均未发布，保留旧标签。

本版恢复用户确认的 C 波形布局：真实原音波形、时间刻度、居中圆形播放与前后 15 秒、校验后的时间跳转和统一倍速菜单。继承前轮采集输出改为磁盘缓冲的修复，前端短暂积压不再触发八包队列停止。

已有模型配置保留；仅豆包音频模式见 [v0.1.7 配置说明](v0.1.7-preview.md)。本轮未修改模型接口或调用真实供应商。

本地 411 项 Node 测试、ESLint、类型检查、Web 构建、文档检查通过；原生 debug App 构建通过，唯一隔离窗口下合成波形、08:36 跳转、1.25× 倍速和浅深主题已核对。详见[C 版设计与证据](../evidence/playback-c-2026-10-23.md)及[暂停修复依据](../evidence/pause-speed-2026-10-23.md)。没有使用浏览器调试；实体会议核听、后台长录制仍待独立验证，安装包发行核验见上述回执。

CI 已确认的阻塞是新增回归对实时合成推进设定了 30 秒预算。v0.1.11 改用有限帧与同步屏障，仍由真实停止路径排空尾包，保留全部断言并增加精确样本核对；公开 smoke 合成源仍按实时节奏运行。CI 使用官方 macos-15 Apple Silicon 运行器，失败日志限制为六条末尾片段，不跳过原生检查。
