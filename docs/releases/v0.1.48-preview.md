# 聆记 v0.1.48 公开测试版候选

日期：2026-10-30。学习评审与翻译界面已按用户确认的设计实现；本地检查通过，发布状态以后台工作流及附件核验回执为准。

## 版本改动与修复

- 学习评审在后台探测服务，未连接时禁用入口与写入操作，恢复后自动启用。
- 评审弹窗统一到现有配色、控件与关闭行为，覆盖样本准备、人工标注、训练确认和结果查看；支持窄屏及深色主题。
- 待标注准备先提供冻结原文、原音和五类意图问题，移除人工标注前的教师及基线推理等待。训练与测试仍采用已核实的人工标签。
- 翻译按句呈现原文与译文，独立处理当前发言，提供暂停、跟随和失败句重试；原文修订、切换语言及停止后不写回过期结果。
- 分享弹窗移除说明小字和草稿字样。导出与新旧分享链接仅提供纪要，接口不再返回共享转录及引用快照。
- 原音波形固定绘制，通过裁切推进已播区域；统一游标、时间标签与进度时钟，抑制小幅负向采样抖动。
