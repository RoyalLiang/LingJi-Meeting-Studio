# v0.2.6 测试版

日期：2026-10-31。当前候选，验证见[实现证据](../evidence/fullscreen-performance-2026-10-31.md)。

## 版本改动与修复

- 解除应用容器1720px宽度限制，随窗口与全屏宽度变化，保留桌面边距和窄屏布局。
- 重点速览移除“下一步”区域；正式纪要与导出的行动候选仍保留。
- 会中快照校验使用索引匹配，减少长转录重复扫描，继续保护引用、人工编辑和失效任务。
- 汇总终稿一开始就上报真实阶段；节点全部完成时仍显示后台收尾。处理提示在会议标题区完整换行，窄屏也不再用省略号隐藏进度。ASR重试耗尽显示待重试，仍在运行的纪要继续显示进度。

继承v0.2.5的滚动标题、封存后立即/优先调度，以及Windows Chrome/Edge/飞书共享音频会话监听。

## 边界

合成回归的读取次数改善不代表真实ASR/LLM服务同比提速；供应商响应仍需独立测量。实际Windows全屏、GPU与真实会议音频未验。Windows自动联动默认关闭，只覆盖共享会话；独占流和其他音视频误触发限制见[后台会议联动](../engineering/background-meeting.md)。
