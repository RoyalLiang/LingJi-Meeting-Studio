# 聆记 v0.1.23 公开测试版

本版合并纪要上下文优化和 SenseVoice 持续纪要修复，保留 v0.1.22 的安装、录音控制和手动纪要重试改进。发布状态与附件校验见[证据记录](../evidence/preview-v0.1.23-2026-10-26.md)。

## 修复与改进

- 会中整理结合有界历史主题、决定、行动与待确认事项，处理迟到转录、跨窗口更正和撤回，保留来源及转录版本。
- 修复累计纪要超过单次输出上限后停止更新的问题，包括同一长转录片段拆成多个窗口的情况；单次模型输出仍严格校验。
- 临时失败在 15 秒、30 秒后重试，合计最多 3 次；关闭自动纪要、人工编辑和永久错误仍阻止自动重试。
- 历史上下文总量仍限制在 12KB，提纲最多占 6KB，为可更正的旧事实留出空间；主题 ID 重用不会改变旧项目行动的归属。
- 长纪要支持人工保存，容量与引用仅依据服务端冻结证据，客户端不能扩充证据预算。

## 安装与验证范围

通过 [GitHub Release](https://github.com/RoyalLiang/LingJi-Meeting-Studio/releases/tag/v0.1.23) 下载 macOS Apple Silicon DMG 或 Windows x64 NSIS 安装包，并核对同一 Release 的 SHA-256 清单。[GitHub Actions 40251719525](https://github.com/RoyalLiang/LingJi-Meeting-Studio/actions/runs/40251719525) 的 verify、两平台构建及 publish 已全部成功；十公开附件、SHA-256 与源码来源核验通过。

专项冒烟使用 12 分钟合成时间线，连续完成 24 次转录与纪要更新；本地识别器和模型输出为注入夹具。包内 SenseVoice 已用固定公开中英和静音样例完成原生推理；真实会议准确率、真实 LLM、实体录音长会话及用户设备表现仍需独立验收，不能以夹具通过代替。
