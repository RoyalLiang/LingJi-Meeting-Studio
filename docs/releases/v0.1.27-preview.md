# 聆记 v0.1.27 公开测试版

本版增加推理强度设置，修复失败提示占位、回放跳动、平行音轨时长重复累计和连接标签闪烁。已发布，四项 CI 与十个公开附件核验通过，见[发布回执](../evidence/preview-v0.1.27-2026-10-27.md)。

## 修复与设置

- 模型设置增加推理强度：自动、模型默认、低、中、高、更高、最高。自动延续 Kimi 会中优先响应策略；模型默认不附加推理参数。显式选择同时用于 HTTP 纪要与分析请求，两种协议分别发送 reasoning.effort 或 reasoning_effort。供应商可能映射档位，强度越高通常等待越久。依据[火山方舟文档](https://docs.volcengine.com/docs/ark/deep-thinking?lang=zh)。
- 推理强度进入分窗缓存策略，修改设置后对相同转录重试也会使用新参数，避免复用旧强度结果。人工版本保护与来源引用保持原规则。
- 整理失败改为可关闭、可重试的浮动提示，显示及关闭不挤占纪要正文；其他处理提示保留原布局。
- 波形使用固定波形和移动裁剪层；时间标签和游标只做位移，减少逐帧布局。游标等待真正开始播放，以有界投影容忍粗采样和设备起播延迟；暂停、缓冲、结束及定位仍以真实媒体为准。
- 页头与纪要底部统一显示共享时间线的录音时长，平行音轨不重复计时；原有 samples 用量账本不改。
- 本机连接标签与待保存数量分别显示，音频排队和落盘不再替换连接文字；真实服务故障与云端离线状态仍显示。
