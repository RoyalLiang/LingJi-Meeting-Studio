# 聆记 v0.1.35 公开测试版

发布日期：2026-10-28。本轮优化设置、通知、系统托盘图标和长会议转录的渲染开销。五项 CI 与三平台公开附件核验通过，详见[发布回执](../evidence/preview-v0.1.35-2026-10-28.md)。

## 版本改动与修复

- 设置中的“客户端更新”改为“版本更新”，标题、版本、检查方式和更新按钮在宽窗口中同行显示。转录服务、纪要输入方式的选项也与对应标题对齐，移除重复标签；模型接口地址统一为“服务地址”。
- 更新说明采用统一的正文列表，仅展示版本改动；隐藏发布页中的安装指引、校验和与构建信息。下载采用全宽进度条，展示下载量和百分比；总量未知时保留已下载字节数，下载完成后明确区分校验状态。
- 普通提示置于顶部居中，2 秒后关闭，悬停、聚焦与后台时暂停计时。错误与需要操作的提示保留手动关闭入口。历史“整理未完成”提示放回纪要区域，保留重新整理入口。
- Windows 和 Linux 使用专用、较少留白的系统托盘标志；macOS 保持上一版 22pt 模板图标。
- 纪要下方的逐字记录与纠错入口改为图标按钮，悬停可见片段数量，保留键盘展开操作。收起的逐字记录首次展开时才加载；展开后保留挂载，收起不会丢失未保存的编辑草稿。与转录无关的计时与音量刷新跳过历史转录重绘，减轻 WebView2 等浏览器引擎的 DOM 与 CPU 开销。
