# 聆记 v0.1.24 公开测试版

本版修复小窗切换、纪要长时间等待与录音播放进度跳动。当前处于本地验证完成、等待后台构建阶段；发布完成后补充附件回执。

## 修复与改进

- 录音胶囊窗口从 84px 缩至 42px，移除外层背景和原生阴影，保留胶囊内的录音状态、时间和控制按钮。
- 提前隐藏加载小窗，渲染完成后直接切换；显示小窗前隐藏主窗，恢复主窗时关闭小窗并取消迟到的切换。
- AI 流式响应收到完成标记后立即结束读取，不再因 HTTP 连接保持打开而超时；中断任务耗尽重试后明确失败，避免永久显示整理中。
- 首次纪要生成时显示已有的实时草稿，完整结果仍校验引用与转录版本，人工内容仍受保护。
- 播放进度使用独立绘制时钟平滑移动，暂停、拖动和定位使用实际音频时间；静态波形不再每帧重建。

## 安装与验证范围

计划通过 [GitHub Actions](https://github.com/RoyalLiang/LingJi-Meeting-Studio/actions/workflows/preview-release.yml) 构建 macOS Apple Silicon DMG 和 Windows x64 安装包，附件将在 [v0.1.24 Release](https://github.com/RoyalLiang/LingJi-Meeting-Studio/releases/tag/v0.1.24) 发布。当前还不能将这些计划描述为已发布。

本地完整 Node 回归 510/510，纪要专项 52/52；浏览器验证透明背景、42px 边界、焦点以及播放的平滑、暂停、拖动、键盘定位和倍速。macOS 原生隔离冒烟通过冷就绪、恢复互斥、迟到就绪取消、42px 高度、隐藏录音及重启补传；Rust 胶囊状态 3/3。测试使用合成音频。用户反馈环境为 Windows；用户设备、真实供应商与该场六分钟会议尚未复测。

升级后若原任务已进入失败状态，可在纪要界面手动重新整理。本版不改变本场 AI 分析授权及后端 LLM 配置。
