# 聆记 v0.1.18 测试版

本轮修复 Windows 系统音频因缓冲波动自动停止，并增加安装器本地模型选择。

- 系统音频出现 `A buffer underrun or overrun occurred` 时继续接收可用音频。CPAL 标为可恢复的设备路由、实时优先级通知同样不会终止录音；设备不可用、权限拒绝、流失效和持续积压仍会停止并报错。缓冲波动可能留下短暂音频缺口。
- Windows 安装首页默认勾选“安装本地 SenseVoice 离线转录模型（推荐）”，可取消。取消只跳过新模型文件，安装包下载大小不变；没有本地模型时，需在设置中选择并配置云端转录服务。不会自动切换已有服务或外发录音。
- 在原安装位置升级时，如取消模型且已有模型，使用覆盖升级保留旧模型；更换安装位置属于新安装。安装器完成页与设置页会说明模型是否已安装。

## 验证范围

本地 Node、Rust、ESLint、TypeScript 与 Web 构建结果见本轮交付记录。音频回调回归覆盖可恢复通知后同次可用缓冲仍入队、致命故障及持续积压停止保护。

后台构建须验证 Windows 实际安装器的默认模型、取消模型、较旧版本注册信息升级并逐文件核对模型保留，以及云端模式已安装 App 启动。升级夹具由当前候选包安装后设置较旧的注册版本生成，不等同于实体 Windows 的旧版本升级验收。既有模型仍由本机原生引擎运行，无需启动独立服务。

实体 Windows 音频设备、蓝牙/多设备切换、长会议和高 DPI 尚未验收。macOS 包为临时签名、未经 Apple 公证；Windows 包未签名。最终构建与发布结果以 GitHub Actions 和发布回执为准。
