# 聆记 v0.1.8：采集连续性与播放倍速测试版

通过现有 GitHub Actions 构建并发布的 Apple Silicon 测试包。后台结果以发布回执为准。

- [Release](https://github.com/RoyalLiang/LingJi-Meeting-Studio/releases/tag/v0.1.8)
- [Lingji-0.1.8-macos-arm64.dmg](https://github.com/RoyalLiang/LingJi-Meeting-Studio/releases/download/v0.1.8/Lingji-0.1.8-macos-arm64.dmg)
- 系统：macOS 14.6 及以上，Apple Silicon（M 系列）；App 版本 0.1.8，bundle 0.1.30。
- 下载同页 `SHA256SUMS.txt`，在下载目录执行 `shasum -a 256 -c SHA256SUMS.txt` 核对安装包。

打开 DMG，将 **聆记 Preview.app** 拖入“应用程序”。本版为 ad-hoc 签名、未公证的测试包，信任提示见[macOS 安全说明](macos-trust.md)。

原生采集不再因前端暂时慢于生产、填满八包缓冲就自动停止。待消费音频进入私有临时磁盘文件，前端追上后回收，正常停止会排空尾音频；设备、磁盘和原始采集故障仍会明确报错。临时缓冲不提供崩溃恢复，不承诺操作系统休眠期间录制。

播放器右侧的倍速使用统一下拉菜单、选中态和键盘操作，保留五档倍速，两条音轨同步切换。

已有模型配置继续保留。仅豆包音频模式的地址、模型、每场原音授权和旧失败会议重试方式见[v0.1.7 配置说明](v0.1.7-preview.md)。

405 项 Node 回归、27 项原生测试、lint、类型检查、Web 构建和独立评审通过。没有使用浏览器调试、真实音频设备或用户会议；历史暂停事件缺少错误原因，不能追溯归因每一次暂停。实体设备后台录制与视觉效果仍需验收。见[诊断及测试证据](../evidence/pause-speed-2026-10-23.md)。
