# ADR 0009：离线预标、可追溯审核与按会议隔离的训练数据

状态：proposed。日期：2026-10-12。用户已授权实现本地离线生成器；本 ADR 记录供推广评审的数据边界，不代表真实语料质量或正式训练规模已验收。

从用户显式选择、声明允许训练的 Record JSON 备份构建数据，生成器只输出独立文件。现有模型分析授权不自动转为训练授权。按来源版本冻结窗口，使用前文和焦点发言，不从会后结果反推当时决定。五类讨论语义分别形成二选一问题，以保留多标签且兼容现有单 Choice 训练格式。

规则、已有模型候选和离线教师结果是弱监督来源；缺失候选表示弃标，不作为负例。默认只导出明确人工审核的标签；可显式接收规则与独立教师一致的正例到训练集，仍标为 silver。验证和测试集只使用人工标签。审核和教师文件绑定输入哈希与片段版本，引用校验不被视为语义正确性证明。

同一 Record 的所有 Session、窗口、问题及精确重复内容共同分组，固定分组后导出训练／验证／测试集。保留审计与拒绝原因；标注记录不写入业务纪要，也不构成行动确认或外发授权。独立离线文件牺牲即时自动训练，换取可复核来源、稳定数据版本和评测隔离。
