# ADR 0007：来源级持续识别与有界匿名身份

状态：proposed。日期：2026-10-12。当前已实现本地及合成语音验证，长期生产策略待试点批准。

问题：短批次识别每块新建声学上下文，丢弃供应商分句和说话人 ID；直接按块或新连接编号会制造无限“新人”。

选择：默认豆包中英文 Source/epoch 使用持续连接；域层维护 Record Speaker 与 connection-local provider ID 映射，最多 10 个身份。分句提前提交但音频完成仍等待停止排空确认；同一来源通过租约和 fence 保护。重连从耐久原音重播，凭相同音频范围锚定已有身份；无法锚定时保持待确认。人工修订不被后台覆盖。

代价：连接与原音恢复占用后端资源；重播成本随来源时长增加。独立来源无法保证自动认出同一人；真实姓名、声纹注册和跨会议身份库不在本次实现范围。长会话、交叠发言和供应商超时需要进一步验收。详见[实现边界](../engineering/speaker-continuity.md)。

补充决策：会内匿名身份采用持久化 SHA-256 标识；重连仍依赖原音锚点，不以哈希推断声学身份。一遍文字保留为独立的实时草稿，确认稿才参与纪要。
