# ADR 0022：进一步隔离原音、转录与纪要

- 状态：proposed
- 日期：2026-10-28

## 问题

长会议发生转录落后、服务恢复提示及全局缓存阻塞。v0.1.37 修正本机预算、原生 ACK、上传期限与预览写放大，但记录 API、worker 和同步聚合写入仍可能争用事件循环及数据库。

## 建议

先以可恢复的原音追加日志作为事实源，按 record/source/epoch/sequence 确认持久化；转录按水位独立消费并保留片段修订；纪要按转录修订与冻结引用生成。各阶段报告自身位置、缺口和失败原因。原生未确认文件需增加崩溃恢复清单，才能覆盖进程终止。

若将 worker 移到独立进程，必须先把领取、租约、fence、CAS 提交及修订事件改成数据库事务；不能直接让多个进程读取并覆盖整份记录。人工编辑保护、重复投递幂等、补历史游标与结束排空都是迁移验收条件。

## 验收目标

双路实际 90 分钟会议加断网、慢 ASR、慢 LLM、WebView 重载、应用重启、磁盘不足；逐片核对原始样本数、连续序列、确认水位和最终引用，保证不丢尾、不重复且不覆盖人工修改。同时测量 API 延迟、队列增长与进程内存。

本 ADR 尚未批准为独立进程重构，不以合成回归替代真实长会议验收。
