# ADR 0008：工作目录与有来源的跨会议分析

状态：proposed。日期：2026-10-12。用户已授权并确认本轮目录功能与首页视觉；本 ADR 记录架构取舍，作为后续推广评审材料，不代表生产容量或模型质量已验收。

## 当前问题

会议记录长期独立存放，缺少项目维度的归档和历史进展视图。直接把所有原文交给模型会混淆权限、保留期与成本，也难以说明统计和推断分别覆盖了哪些内容。

## 本轮已实现的切片

采用独立 Workspace 和可选的会议归属；保留所有会议、未归档两种虚拟范围。先以现有纪要与转录做可核对的统计和历史摘要，再由用户按需发起跨会议模型分析。

归档是保持录音身份不变的元数据事务。跨会议分析使用独立任务与 worker lane，限定输入预算，校验会议版本引用，支持取消和旧结果隐藏；不修改人工纪要，不增加分享或团队权限，不自动执行行动。

## 取舍及后续退出条件

首版复用 JSON 聚合，无独立报表数据库，最多 200 条记录和 50 个目录。主题名称按精确规则归并；模型语义归纳位于单独的洞察区域。前端通过概览轮询展示供应商流式草稿，避免另建未经验证的持久 SSE 游标协议。

后续需以真实 PG 并发事务、长历史性能、远程模型质量和删除后的供应商数据保留规则验证是否适合推广。若规模扩大，考虑增量投影和分页，保留统计口径与来源版本；不能直接用当前本地结果声称多租户团队权限或生产容量成立。
