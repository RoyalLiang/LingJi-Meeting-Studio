# ADR 0023：有界任务轮转与轻量目录输入

- 状态：proposed
- 日期：2026-10-29

## 当前实现边界

用户已授权修复固定前 100 项饥饿、后台空转和长会议存储扫描。v0.1.44 保持现有事务和音频标识，通过进程内按 lane 的 keyset 游标轮转，不持久化新队列；feed meta 增加轻量分析输入，旧记录按 meta 内容变化惰性读取并缓存，不启动全库迁移。worker 和安装安全继续使用原有 ACK、租约与排空语义。

## 后续建议

仅在真实长会议量测确认完整聚合压缩仍为主要瓶颈时，继续 ADR 0022 的追加日志与独立进程设计。该方向需要先具备事务领取、fence/CAS 和崩溃恢复，不能把本轮局部优化当作已完成架构迁移。PostgreSQL、重启后轮转和真实设备长会话需分别验收。
