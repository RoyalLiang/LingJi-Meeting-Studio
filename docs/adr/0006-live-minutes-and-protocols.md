# ADR 0006：增量会议纪要与双模型协议

状态：proposed。日期：2026-10-12。实现已按本轮请求落地；长期架构选型仍待进一步运行证据评估。

问题：此前模型只走 Chat Completions，纪要必须等录音结束才能显式生成，模型等待与 ASR 共用循环，无法满足会中自动归纳和流式显示。

选择：统一 Chat Completions/Responses 适配；每记录显式开启自动纪要；会中近窗结果与会后完整版本分开；持久化受控文本预览，最终引用校验后发布；ASR、纪要、意图、翻译独立轮询；主题与原文版本关联。

约束：人工修订不被覆盖；停止排空后生成终稿；取消和删除隔离迟到结果；不把设备来源作为说话人身份；流式草稿不直接进入分享和导出；不执行模型返回的任意渲染代码。

取舍：聚合内保存预览增加 SQLite/PG 写入，通过 200 ms 节流控制；SSE 增量采用事件通知后 GET，增加一次读请求；会中最多 120 个片段，完整终稿仍有输入大小限制，尚无长会话分层归纳。未来以实际延迟、成本和质量指标决定是否拆分事件/任务存储。

证据与用法见[实现说明](../engineering/live-minutes.md)和[飞书研究](../research/feishu-minutes-analysis-2026-10-12.md)。
