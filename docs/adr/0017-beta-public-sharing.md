# ADR 0017：Beta 官网与可撤销的共享快照

状态：proposed。日期：2026-10-28。决策范围：官网托管与会议内容公开分享；尚未批准实施或完成部署。

## 背景

Beta 需要官网和可在其他设备浏览器打开的会议 URL。当前桌面账户与数据在本机，URL 分享被禁用，HTML 导出可用；已部署的 Web 分享链接则指向随会议变化的内容。官网上线本身不能把本机会议变成可公开访问的数据。

## 建议

使用 Cloudflare Workers Static Assets 托管官网；Worker 验证分享访问，D1 存储发布身份关联与分享元数据，私有 R2 存储已发布的内容快照。Node/SQLite/本地 ASR 维持现有职责。既有 Web 动态分享语义保留，新增快照发布流程单独标识。

发布者明确选择内容、范围与版本，默认只发布纪要及其引用原文，首轮沿用 24 小时有效期、不分享原音。发布服务接受版本化 JSON，校验并调用白名单投影，再使用受信模板生成 HTML。客户端不能上传任意可执行 HTML 到产品 origin。

分享令牌只读；发布、撤销和更新需要独立的云端发布身份，不复用设备本地账户的会话密钥。读取按令牌 hash 索引定位，校验撤销/到期后读取快照。静态资产缓存与私人正文策略分别配置，禁止直接公开 R2 或以 SPA fallback 绕过校验。

## 取舍

- 相比直接暴露本机服务，快照发布能让发布者离线后接收者仍可读，避免将设备 API 开放到公网；代价是新增云端身份、存储、发布确认和删除联动。
- 相比部署完整云端工作台，窄范围发布服务不需要迁移录音、模型密钥、任务和原生识别；代价是官网只能访问已授权发布的内容。
- 相比动态读取最新会议，固定快照不会因后续生成或编辑意外扩大分享范围；代价是更新需要显式重新发布。原有 Web 动态链接不静默改变语义。
- 相比 R2 公开 HTML 对象，Worker 校验可实施有效期和撤销；代价是正文请求需要执行访问检查。撤销阻止后续服务端读取，不能收回已被接收者保存的副本。

## 实施前冻结的事项

1. 正式域名、Cloudflare 账户/资源权限、预览环境与费用上限。
2. 邀请制云端发布身份及桌面授权回调；上传/撤销的所有权校验。
3. 快照 schema、修订引用、幂等发布协议、删除联动与离线待撤销提示。
4. 公开入口限流、无效令牌和缓存绕过测试，正文及日志中的敏感信息处理。

这些前置项未确定前，不能对外开放发布写入接口。它们不阻止先完成官网静态预览与合成分享验收。

## 2026-10-30 实施收窄

用户授权落实 Beta 并选择既有 Cloudflare 账户及初始 pages.dev 域名。实现使用 Pages 高级模式 Worker（仍使用 D1/私有 R2），独立 Access 发布身份，首版采用结构文件导出与浏览器预览确认，没有桌面 OAuth 或自动删除联动；删除前需手动撤销，界面明确提示。v0.1.49 既有仅纪要正文隐私默认保留，新增在线范围单独确认。[实施证据](../evidence/beta-implementation-2026-10-30.md)区分本地验证与待完成线上验收；本 ADR 的后续扩展仍是 proposed。

## 验证与回退

先在隔离预览环境使用虚构会议验收：异机打开、引用版本、只读权限、撤销/到期、XSS、重复上传、失败回滚、缓存失效和删除联动。正式发布由后台 Actions 绑定源码 SHA 与部署版本；回退优先关闭发布写入，分享读取继续执行撤销/到期校验。数据库迁移与对象删除不能通过回退旧前端隐式撤销。

代码与验证事实见 [Beta 体检和计划](../design/beta-plan-2026-10-28.md)。Cloudflare 官方依据：[Static Assets](https://developers.cloudflare.com/workers/static-assets/)、[D1](https://developers.cloudflare.com/d1/worker-api/prepared-statements/)、[R2 Worker 访问](https://developers.cloudflare.com/r2/api/workers/workers-api-usage/)、[Workers 文件系统边界](https://developers.cloudflare.com/workers/runtime-apis/nodejs/fs/)。上述依据证明平台接口可用，不表示本项目已部署或验收。
