# ADR 0015：Alpha 双任务学习与人工回测

- 状态：proposed
- 日期：2026-10-13
- 范围：Alpha 数据的私有旁路学习；部署到主产品的决策仍待验收

## 背景与当前事实

用户已授权当前 Alpha 数据接入、测试和相关训练，并明确允许沿用已有 ASR/LLM 供应商生成转录候选及教师弱标签。用户要求同时训练意图判断和语音候选文字决策，每轮提供可标注结果，用于再训练和回测。

现有备份以 ASR 转录为主，缺少人工标签和真正的 N-best；部分原音已清理。NeoHorse-Jev-4B 是第三方文本决策模型，不直接读取波形。首轮已完成真实私有训练，但尚无人工金标准，不能据损失下降声称识别更准确。

## 设计建议

采用独立的学习伴随服务：只读 Alpha SQLite 快照与留存原音，通过已有供应商补充候选和弱标签，在 wgs 进行双任务 LoRA 与旁路预测，通过本地浏览器核听、标注、再次训练。主产品的录音、转录、纪要和行动仍由原流水线持有写权限。

两类任务共用一个适配器：五类讨论意图采用二分类 Choice，转录采用候选选择与 none。训练更新在两类任务间轮换。候选选择只能判断文本证据的适配程度；原音真实性来自人工核听，声学模型微调需要另立范围。

按会议固定 train/dev/test 分组，禁止相同请求跨组进入数据集。教师标签明确为 silver，只有显式允许才进入 train；其余分组仅统计教师一致率。人工 ASR 标签必须核听且关联音频哈希才可成为 gold。dev/test 首次标注隐藏预测；看过预测后的修订保留为诊断数据，不当独立金标准。

每条反馈绑定 sample_id 与 input_hash。补入正确文字会生成新的候选与样本身份，并保留原反馈引用；过期反馈拒绝导入。跳过标签覆盖教师结果。每轮保留输入、标签审计、预测、评分、适配器、重载报告和可标注 JSONL。后续轮次冻结运行脚本及 SHA256。

## 已验证范围与后果

已验证 Alpha 数据只读接入、既有供应商候选/弱标、wgs 双任务训练与继承重载、旁路回测、本地标注页面和反馈构造器。主应用没有启用 NeoHorse 自动改写，也未重新打包客户端。

代价包括人工核听、少量 ASR 候选重复采样及弱标签偏差。训练分组中的 ASR 样本较少，轮换更新可能过拟合；须用人工独立测试确认后再讨论进入主流程。学习副本有独立生命周期，源记录删除或代次变化会阻止继续取音及复用训练，但不会自动擦除历史副本或已训练参数。
