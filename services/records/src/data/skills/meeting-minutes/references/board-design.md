# 原生画板设计契约

参考 taste-skill 的 `achromatic-ledger` 报告方向（seed 2073092189）及 finesse-ui 的 product 原则，将层级、克制用色和间距落实为飞书原生图形；安装本技能无需安装额外设计技能。

- 顶部依次为会议标题、元信息和决策摘要。缺失摘要不编造。
- 用字号和留白组织章节，减少编号、装饰图标和彩色边框。
- 1040px 内容轨道，24px 内边距，分栏间距 24/48px；标题 22–32px、正文 16px、KPI 当前值 32px。
- 浅灰画布、近白内容、深墨正文、单一数据强调色；状态同时有文字和语义色。
- KPI 并列显示基线和当前值，原样保留 delta，不自动推断升降好坏。
- 两列流程和时间线按行延伸；分支独立排列；表格按内容分配列宽、数值右对齐，状态表同组首列可合并。
- 长中文自动增高，不能靠省略号、截断或缩小字号隐藏事实。

`feishu_board_drawer.py` 是原生布局和样式的唯一来源。HTML 的画板 SVG 读取相同坐标、文本和样式，不用 CSS 重染伪装效果。原生文字使用飞书支持的主题色表；字体替换、平台换行及原生显示仍需真实租户验收。

静态会议画板不使用阴影、模糊、玻璃、渐变、滚动动效或网站导航。HTML 中的缩放、平移、PNG/SVG 下载是预览工具，不冒充飞书原生交互。

调整后运行 `scripts/test_meeting_minutes.py`，重新生成 `examples/`。检查 12 类卡片、长中文、较多流程节点、合并单元格、空内容和原生字段。浏览器检查桌面、手机和独立 SVG 下载。未连接真实租户时，明确保留实际写入、字体和权限验收缺口。
