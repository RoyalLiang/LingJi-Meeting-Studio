# 聆记 logo 候选

打开 [对比页](index.html)，比较三种方向，并下载独立图形。

| 方向 | 文件 | 用意 |
| --- | --- | --- |
| 倾听成环 | [01-listening.png](01-listening.png) | 耳廓与连贯线条，强调专注倾听 |
| 对话留痕 | [02-dialogue.png](02-dialogue.png) | 交错的对话印记，强调多人交流 |
| 声音成章 | [03-voice-page.png](03-voice-page.png) | 声音展开为记录，强调转录与整理 |

三个文件均为 AI 生成的 1254 × 1254 透明底 PNG，主色参考松绿 #286249。它们保留生成原稿，带有轻微色调变化，当前不是 SVG 矢量定稿。对比页的「聆记」文字由浏览器排版，不在 PNG 内。

可直接用于概念预览和页面图形。选定方向后再做光学校正、纯色矢量化、深浅背景版本及小尺寸图标适配。当前产品标识保持原样，便于先比较再选择。
