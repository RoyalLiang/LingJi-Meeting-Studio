本地会议与账户

聆记桌面客户端在本机保存账户配置、会议记录、原始音频、转录、笔记和纪要。创建本地账户不等于注册云端账户。录音需由你选择音源并获得相应系统权限；自动录音也需要先在设置中开启。

本地转录可使用随客户端提供的语音模型。本地转录不代表 AI 纪要、翻译或会议助手全部离线，后者取决于你选择的模型服务。

云端模型与外部工具

启用云端转录、翻译、纪要或会议助手后，完成任务所需的音频、文字和上下文会发送到你配置的服务。提供商会按其自身条款处理数据；使用前请核对服务地址、账户和数据政策。

连接 MCP 工具、导出到飞书或启用 Git 同步时，相关内容会发送到你选择的外部服务或仓库。工具执行和分享范围分别确认；外部服务保存的副本需要在对应服务中单独管理。

声音学习

声音学习用于后续会议中的说话人匹配，需要单独同意。相关声音特征与称谓由客户端管理，匹配结果可复核。录音授权、原音保留、声音学习和云端发送是不同的设置。

官网与加密分享

使用加密分享时，客户端按你选择的范围加密内容，官网保存密文，接收者使用完整链接在浏览器中解密。该分享流程不会上传原始音频。完整链接包含解密密钥，应只交给需要阅读的人。

分享链接 24 小时有效，可以在客户端撤销。删除本机会议不会自动撤销链接；撤销或过期也无法收回接收者已经保存的副本。过期内容按服务端清理流程移除。

独立安装包会为检查或下载更新访问官网或 GitHub 发布服务；商店版的安装与更新由 Microsoft 服务处理。

官网及其基础设施会处理提供访问、统计和防滥用保护所需的请求信息，例如网络地址、浏览器信息和访问路径。需要登录的分享管理入口使用 GitHub 身份验证。

Windows 浏览组件

商店版包含 Microsoft WebView2 运行时。其默认 SmartScreen 安全检查会向 Microsoft 发送信息；处理方式见 Microsoft 隐私声明与 Microsoft Edge 隐私白皮书。微软组件适用随包提供的独立许可条款。

管理与删除

你可以在客户端管理会议、原音保留、模型服务、声音学习和分享链接。工作目录备份、Git 远端、飞书文档以及接收者保存的内容需要分别处理；卸载客户端不能代替撤销分享或删除这些外部副本。

联系与反馈

可通过 项目反馈入口提出问题，或按内容举报指引报告不当 AI 输出及分享内容。公开反馈中请勿包含录音、会议原文、密钥或完整分享链接。
