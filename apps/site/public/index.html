分享，范围由你选。

在客户端选择范围，一键生成加密链接，无需登录。官网保存密文，接收者在浏览器中解密阅读；链接 24 小时有效，可提前撤销，原音不上传。

了解加密分享 ↗

完整链接包含解密密钥，请只分享给需要阅读的人。删除本机记录不会自动撤销链接；撤销无法收回接收者已保存的副本。

采集、原音保留、云端发送和分享，也分别确认。

想在本机转录。

桌面测试版可使用内置 SenseVoice，在本机把声音转成文字。Windows 安装时可选择是否安装模型。

本地转录不等于 AI 纪要全部离线。AI 整理使用你配置的纪要模型，数据去向取决于对应服务。

想选自己的模型。

使用 ASR＋文字模型整理，或配置 OpenAI Realtime、豆包音频方式理解音频，同时保留独立转录留证。

云端转录、翻译或纪要会向对应服务发送音频或文字，需要服务账户、密钥及相应额度。

再多了解一点。

聆记适合什么场景？

团队周会、需求讨论、客户访谈、课程与个人复盘：需要把长对话整理成可阅读、可核对记录的场景，都可以先用非敏感内容试一试。转录、说话人区分和纪要质量受环境与模型影响。

需要安装吗？官网能直接录音吗？

官网用于了解产品、下载和阅读共享纪要。记录会议可安装 macOS、Windows 或 Linux 桌面测试版；开发者也可以从源码启动或自建 Web 版。浏览器采集需运行服务并完成相应授权。

AI 纪要能代替人工确认吗？

纪要、翻译和行动候选都应复核。聆记保留引用和转录版本，帮助核对原话，但不能保证模型永远理解正确。负责人、时间或结论不明确时，仍需要会议参与者确认。

模型服务和桌面版怎么配置？

下载安装包后，在“设置 → 模型与转录服务”中配置并测试服务。桌面包包含运行后台；源码启动不自动附带本地模型。系统要求、系统信任提示与安装步骤见 README 安装说明。

测试版目前验证到了哪里？

各版本的本地测试、CI、真实模型、设备与长会议验证范围分别记录，不能互相替代。完整能力与未验范围见 当前状态与版本证据；遇到问题可通过 GitHub 反馈。
